
## Overview

This document describes the function prototypes and data type definitions in the FTS emergency landing module header file `dji_fts.h`. This module is used to select and manage the FTS PWM trigger port of the aircraft. Developers can enable a specified PWM trigger port while the aircraft is on the ground, and send a motor shutdown signal through external PWM hardware to perform an emergency landing.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiFts_SelectFtsPwmTrigger

- Function: Select the FTS PWM trigger port.
- Supported aircraft models: M400 series (only supports DJI_MOUNT_POSITION_EXTENSION_PORT_V2_NO4)

::: tip Note:
* This interface must be called when the aircraft is on the ground. Calling it during flight will fail or be rejected.
* This interface only selects/enables the PWM trigger port on the flight controller side. It will not emit a PWM signal or perform a motor shutdown action. Actual motor shutdown requires sending a PWM signal to this port through an external PWM controller.
* Recommended workflow: 1) Call DjiFts_SelectFtsPwmTrigger(position) on the ground to enable the port; 2) Send a motor shutdown PWM signal to this port through an external PWM controller.
:::

```c
T_DjiReturnCode DjiFts_SelectFtsPwmTrigger(E_DjiMountPosition position);
```

- Parameters
  - position: Payload mount position.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiFts_GetFtsPwmTriggerStatus

- Function: Get the FTS PWM trigger status.
- Supported aircraft models: M4 series

::: tip Note:
* This interface is deprecated and will be removed in a future version. It is not recommended for use.
* Recommended alternative: Use DJI_FC_SUBSCRIPTION_TOPIC_ESC_DATA data subscription to confirm the motor shutdown (FTS) effect.
:::

```c
T_DjiReturnCode DjiFts_GetFtsPwmTriggerStatus(T_DjiFtsPwmEscTriggerStatus *trigger_status);
```

- Parameters
  - trigger_status: Pointer to the memory space for storing the FTS PWM ESC trigger status.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### E_DjiFtsStatus

FTS trigger status.

```c
typedef enum {
    DJI_FTS_NOT_TRIGGERD = 0,    Not triggered
    DJI_FTS_TRIGGERD = 1,        Triggered
} E_DjiFtsStatus;
```

### T_DjiFtsPwmTriggerStatus

FTS PWM trigger status.

```c
typedef struct {
    E_DjiMountPosition fts_select;    Mount position selected by FTS
    E_DjiFtsStatus fts_status;        FTS trigger status
    uint8_t fts_pwm_cnt;              Number of correct PWM signals received
} T_DjiFtsPwmTriggerStatus;
```

### T_DjiFtsPwmEscTriggerStatus

FTS PWM ESC trigger status.

```c
typedef struct {
    T_DjiFtsPwmTriggerStatus ESC[4];    Trigger status of 4 ESCs
} T_DjiFtsPwmEscTriggerStatus;
```
