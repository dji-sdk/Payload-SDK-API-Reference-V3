

## Overview

This document describes the function prototypes and data type definitions in the custom widget module header file `dji_widget.h`. This module is used to display developer-defined custom widget interfaces on DJI Pilot or MSDK-based mobile apps, supporting widget types such as buttons, switches, range bars, lists, input boxes, as well as floating window message display functionality.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiWidget_Init

- Function: Initialize the custom widget module.

::: tip Note:
When using the custom widget feature, please initialize the custom widget module first.
:::

```c
T_DjiReturnCode DjiWidget_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegDefaultUiConfigByDirPath

- Function: Register the default path of the custom widget configuration file.

::: tip Note:
* Only payload devices developed based on Linux support this interface.
* On Linux operating systems, you can use the DjiWidget_RegDefaultUiConfigByDirPath() and DjiWidget_RegUiConfigByDirPath() functions to set the path of the custom widget configuration file.
* When multi-language support and adaptation to different screen sizes are not required for the custom widget configuration, you only need to use the DjiWidget_RegDefaultUiConfigByDirPath() interface to register the widget configuration file.
* When multi-language support and adaptation to different screen sizes are required, use the DjiWidget_RegUiConfigByDirPath() interface to specify widget configurations for specific languages and screen sizes. If the App language and screen size do not have a corresponding widget configuration, the widget configuration file registered via DjiWidget_RegDefaultUiConfigByDirPath() will be used.
:::

```c
T_DjiReturnCode DjiWidget_RegDefaultUiConfigByDirPath(const char *widgetConfigDirPath);
```

- Parameters
  - widgetConfigDirPath: Path of the custom widget configuration file.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegUiConfigByDirPath

- Function: Register the path of the custom widget configuration file.

::: tip Note:
* Only payload devices developed based on Linux support this interface.
* Widget configurations for different languages and screen sizes must have the same widget types, indices, and quantities.
:::

```c
T_DjiReturnCode DjiWidget_RegUiConfigByDirPath(E_DjiMobileAppLanguage appLanguage,
                                               E_DjiMobileAppScreenType appScreenType,
                                               const char *widgetConfigDirPath);
```

- Parameters
  - appLanguage: Language type of the MSDK-based mobile app.
  - appScreenType: Screen type of the terminal device.
  - widgetConfigDirPath: Path of the custom widget configuration file.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegDefaultUiConfigByBinaryArray

- Function: Register default widget configuration through a binary array widget file.

::: tip Note:
* On operating systems without a file management system (e.g., RTOS), please call this interface and the DjiWidget_RegUiConfigByBinaryArray() interface to set widget configuration parameters.
* If no widget configuration corresponding to the system language and screen size has been registered using DjiWidget_RegUiConfigByBinaryArray(), the configuration from this function will be used.
:::

```c
T_DjiReturnCode DjiWidget_RegDefaultUiConfigByBinaryArray(const T_DjiWidgetBinaryArrayConfig *binaryArrayConfig);
```

- Parameters
  - binaryArrayConfig: Binary array widget configuration file.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegUiConfigByBinaryArray

- Function: Register widget configuration through a binary array widget file.

::: tip Note:
Widget configurations for different languages and screen sizes must have the same widget types, indices, and quantities.
:::

```c
T_DjiReturnCode DjiWidget_RegUiConfigByBinaryArray(E_DjiMobileAppLanguage appLanguage,
                                                   E_DjiMobileAppScreenType screenType,
                                                   const T_DjiWidgetBinaryArrayConfig *binaryArrayConfig);
```

- Parameters
  - appLanguage: Language type of the MSDK-based mobile app.
  - screenType: Screen type of the terminal device.
  - binaryArrayConfig: Binary array widget configuration file.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

```c
T_DjiReturnCode DjiWidget_RegHandlerList(const T_DjiWidgetHandlerListItem *widgetHandlerList, uint32_t itemCount);
```

- Parameters
  - widgetHandlerList: Custom widget handler function list.
  - itemCount: Number of list items.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidgetFloatingWindow_ShowMessage

- Function: Send a message to the floating window of DJI Pilot or an MSDK-based mobile app.

::: tip Note:
* The message length must not exceed the value set in DJI_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN.
* The maximum bandwidth for sending messages to the floating window on DJI Pilot or an MSDK-based mobile app is 2KB/s.
:::

```c
T_DjiReturnCode DjiWidgetFloatingWindow_ShowMessage(const char *str);
```

- Parameters
  - str: Pointer to the message to be sent to the floating window of DJI Pilot or an MSDK-based mobile app.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidgetFloatingWindow_GetChannelState

- Function: Get the channel state for sending messages to the floating window on DJI Pilot or an MSDK-based mobile app.

```c
T_DjiReturnCode DjiWidgetFloatingWindow_GetChannelState(T_DjiDataChannelState *state);
```

- Parameters
  - state: Pointer to the state of the floating window message sending channel.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegSpeakerHandler

- Function: Register the handler function for the speaker feature interface.

::: tip Note:
This interface is used to register the speaker feature interface, including speaker settings, playback operations, and speaker state interfaces.
:::

```c
T_DjiReturnCode DjiWidget_RegSpeakerHandler(const T_DjiWidgetSpeakerHandler *widgetSpeakerHandler);
```

- Parameters
  - widgetSpeakerHandler: Pointer to the speaker feature handler function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiWidgetType

Widget type.

```c
typedef enum {
    PSDK_WIDGET_TYPE_BUTTON = 1,        Button type
    PSDK_WIDGET_TYPE_SWITCH = 2,        Switch type
    PSDK_WIDGET_TYPE_SCALE = 3,         Range bar type
    PSDK_WIDGET_TYPE_LIST = 4,          List type
    PSDK_WIDGET_TYPE_INT_INPUT_BOX = 5, Integer input box
} E_DjiWidgetType;
```

### E_DjiWidgetButtonState

State of the button widget.

```c
typedef enum {
    PSDK_WIDGET_BUTTON_STATE_PRESS_DOWN = 1,        Button pressed down
    PSDK_WIDGET_BUTTON_STATE_RELEASE_UP = 0,        Button released
} E_DjiWidgetButtonState;
```

### E_DjiWidgetSwitchState

State of the switch widget.

```c
typedef enum {
    PSDK_WIDGET_SWITCH_STATE_OFF = 0,        Switch off
    PSDK_WIDGET_SWITCH_STATE_ON = 1          Switch on
} E_DjiWidgetSwitchState;
```

### T_DjiWidgetFileBinaryArray

Binary array widget file.

```c
typedef struct {
    char *fileName;                   Name of the widget file
    uint32_t fileSize;                Size of the widget file, unit: bytes
    const uint8_t *fileBinaryArray;   Binary array of the widget file (C language)
} T_DjiWidgetFileBinaryArray;
```

Custom widget binary configuration file.

```c
typedef struct {
    uint16_t binaryArrayCount;                           Number of binary array widget files
    T_DjiWidgetFileBinaryArray *fileBinaryArrayList;    List of binary array widget files
} T_DjiWidgetBinaryArrayConfig;
```

### T_DjiWidgetHandlerListItem

- Function: Collection of widget item handler functions, including the widget index, type, and callback functions for setting/getting widget values.

```c
typedef struct {
    Index of the custom widget item, starting from 0 and must be unique
    uint32_t widgetIndex;

    Type of the custom widget, for details please refer to: E_DjiWidgetType
    E_DjiWidgetType widgetType;

    @brief Callback function for setting the value of a custom widget, called when the user triggers the widget
    @param widgetType: Type of the custom widget, for details please refer to: E_DjiWidgetType.
    @param index: Index of the custom widget
    @param value: Value of the custom widget set by the developer. For the value range of button type widgets,
    please refer to: E_DjiWidgetButtonState; for the value range of switch type widgets, please refer
    to: E_DjiWidgetSwitchState; for the value range of range bar type widgets, please refer
    to: PSDK_WIDGET_TYPE_SCALE, range is 0~100; for list type widgets, the value range is 0~N-1;
    for input box type widgets, the value is an integer
    @param userData: User data pointer
    @return Execution result
    T_PsdkReturnCode (*SetWidgetValue)(E_DjiWidgetType widgetType, uint32_t index, int32_t value, void *userData);

    @brief Callback function for getting the value of a custom widget
    @param widgetType: Type of the custom widget, for details please refer to: E_DjiWidgetType.
    @param Index of the custom widget
    @param value: Value of the custom widget set by the developer. For the value range of button type widgets,
    please refer to: E_DjiWidgetButtonState; for the value range of switch type widgets, please refer
    to: E_DjiWidgetSwitchState; for the value range of range bar type widgets, please refer
    to: PSDK_WIDGET_TYPE_SCALE, range is 0~100; for list type widgets, the value range is 0~N-1;
    for input box type widgets, the value is an integer
    @param userData: User data pointer
    @return Execution result
    T_PsdkReturnCode (*GetWidgetValue)(E_DjiWidgetType widgetType, uint32_t index, int32_t *value, void *userData);

    User data pointer to be used in SetWidgetValue and GetWidgetValue;
} T_DjiWidgetHandlerListItem;
```

### T_DjiWidgetTransDataContent

Data transmission content.

```c
typedef struct {
    union {
        When the event is DJI_WIDGET_TRANSMIT_DATA_EVENT_START, contains file name, UUID, and decode bitrate
        struct {
            uint8_t fileName[32];            File name
            uint8_t fileUuid[32];            File UUID
            uint32_t fileDecodeBitrate;      File decode bitrate
        } transDataStartContent;

        When the event is DJI_WIDGET_TRANSMIT_DATA_EVENT_FINISH, contains file MD5 checksum
        struct {
            uint8_t md5Sum[16];              File MD5 checksum
        } transDataEndContent;
    };
} T_DjiWidgetTransDataContent;
```

### T_DjiWidgetSpeakerHandler

- Function: Collection of speaker feature callback functions.

Please construct callback functions for speaker-related features based on the functions in this structure, including:
* Get speaker state
* Set speaker work mode
* Set speaker play mode
* Set volume
* Start playback
* Stop playback
* Receive TTS data
* Receive voice data

::: tip Note:
To prevent this function from blocking the PSDK main thread, which may cause slow program response, payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {

    @brief Callback function for getting the current speaker state
    @param speakerState: Pointer to the memory space for storing the speaker state
    @return Execution result
    T_DjiReturnCode (*GetSpeakerState)(T_DjiWidgetSpeakerState *speakerState);

    @brief Callback function for setting the speaker work mode
    @param workMode: Speaker work mode
    @return Execution result
    T_DjiReturnCode (*SetWorkMode)(E_DjiWidgetSpeakerWorkMode workMode);

    @brief Callback function for setting the speaker play mode
    @param playMode: Speaker play mode
    @return Execution result
    T_DjiReturnCode (*SetPlayMode)(E_DjiWidgetSpeakerPlayMode playMode);

    @brief Callback function for setting volume
    @param volume: Volume
    @return Execution result
    T_DjiReturnCode (*SetVolume)(uint8_t volume);

    @brief Callback function for starting playback
    @return Execution result
    T_DjiReturnCode (*StartPlay)(void);

    @brief Callback function for stopping playback
    @return Execution result
    T_DjiReturnCode (*StopPlay)(void);

    @brief Callback function for receiving TTS data
    @param event: Data transmission event type
    @param offset: Data offset
    @param buf: Data buffer pointer
    @param size: Data size
    @return Execution result
    T_DjiReturnCode (*ReceiveTtsData)(E_DjiWidgetTransmitDataEvent event,
                                      uint32_t offset, uint8_t *buf, uint16_t size);

    @brief Callback function for receiving voice data
    @param event: Data transmission event type
    @param offset: Data offset
    @param buf: Data buffer pointer
    @param size: Data size
    @return Execution result
    T_DjiReturnCode (*ReceiveVoiceData)(E_DjiWidgetTransmitDataEvent event,
                                        uint32_t offset, uint8_t *buf, uint16_t size);
} T_DjiWidgetSpeakerHandler;
```
