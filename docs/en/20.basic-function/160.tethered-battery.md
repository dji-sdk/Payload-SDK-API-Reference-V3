
## Overview

This document describes the function prototypes and data type definitions in the tethered battery module header file `dji_tethered_battery.h`. This module is used to push real-time tether line length information to DJI Pilot 2, enabling pilots to view the tether line usage status on the mobile app interface.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiTetheredBattery_Init

- Function: Initialize the tethered battery module.

::: tip Note:
Users should call this function before using the tethered battery feature.
:::

```c
T_DjiReturnCode DjiTetheredBattery_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiTetheredBattery_DeInit

- Function: Deinitialize the tethered battery module.

```c
T_DjiReturnCode DjiTetheredBattery_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiTetheredBattery_PushTetherLineStatus

- Function: Push real-time tether line length information to DJI Pilot 2.

::: tip Note:
* It is recommended that the push frequency does not exceed the data update frequency.
* The maximum push frequency should not exceed 10Hz.
:::

```c
T_DjiReturnCode DjiTetheredBattery_PushTetherLineStatus(T_DjiTetherLineStatus tetherLineStatus);
```

- Parameters
  - tetherLineStatus: Tether line status.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### T_DjiTetherLineStatus

Tether line status.

```c
typedef struct {
    dji_f32_t totalLength;    Total length of the tether line, range: 0–300, unit: meters
    dji_f32_t usedLength;     Used length of the tether line, range: 0–300, unit: meters. This value must be less than or equal to the total length of the tether line
} T_DjiTetherLineStatus;
```
