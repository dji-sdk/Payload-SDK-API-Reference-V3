


## Overview

This document describes the function prototypes and data type definitions in the power management module header file `dji_power_management.h`. This module is used to manage the power supply and shutdown process of payload devices. Developers can use this module to apply for high-power supply, register high-power pin control callback functions, and register shutdown notification callback functions to respond to aircraft shutdown events.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiPowerManagement_Init

- Function: Initialize the power management module.

::: tip Note:
Users should call this function before using the power management feature.
:::

```c
T_DjiReturnCode DjiPowerManagement_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_DeInit

- Function: Deinitialize the power management module.

::: tip Note:
Users should call this function when the power management feature is no longer needed.
:::

```c
T_DjiReturnCode DjiPowerManagement_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_ApplyHighPowerSync

- Function: Apply for high-power supply from the aircraft in a synchronous (blocking) manner.

::: tip Note:
* Before applying for high power, users should first use the DjiPowerManagement_RegWriteHighPowerApplyPinCallback() function to register a callback function for setting the level state of the high-power application pin.
* After applying for high power, the power pin of the DJI adapter will output high power according to the predefined specifications.
* The maximum execution time of this function is slightly greater than 600ms.
:::

```c
T_DjiReturnCode DjiPowerManagement_ApplyHighPowerSync(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_ApplyHighPowerSyncV2

- Function: Apply for high-power supply at a specified voltage from the aircraft in a synchronous (blocking) manner.

::: tip Note:
* Before applying for high power, users should first use the DjiPowerManagement_RegWriteHighPowerApplyPinCallback() function to register a callback function for setting the level state of the high-power application pin.
* After applying for high power, the power pin of the DJI adapter will output high power at the specified voltage.
* The maximum execution time of this function is slightly greater than 600ms.
:::

```c
T_DjiReturnCode DjiPowerManagement_ApplyHighPowerSyncV2(E_DjiHighPowerVoltage voltage);
```

- Parameters
  - voltage: Voltage value to be applied to the VCC pin, refer to <a href="power-management.html#e-djihighpowervoltage">E_DjiHighPowerVoltage</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_RegWriteHighPowerApplyPinCallback

- Function: Register a callback function for setting the level state of the high-power application pin.

::: tip Note:
Must be called before applying for high power.
:::

```c
T_DjiReturnCode DjiPowerManagement_RegWriteHighPowerApplyPinCallback(DjiWriteHighPowerApplyPinCallback callback);
```

- Parameters
  - callback: Pointer to the callback function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_RegPowerOffNotificationCallback

- Function: Register a power-off notification callback function to notify the payload device that the aircraft is about to shut down and get the power-off preparation state of the payload device.

::: tip Note:
* After registration, the callback function will be called at a fixed frequency when the aircraft shuts down.
* Users fill in the power-off preparation flag in the callback function. Once the payload device is ready to shut down, the callback function will no longer be called.
* After the specified time (10s), if the payload is not ready to shut down, the aircraft will shut down immediately.
:::

```c
T_DjiReturnCode DjiPowerManagement_RegPowerOffNotificationCallback(DjiPowerOffNotificationCallback callback);
```

- Parameters
  - callback: Pointer to the callback function for notifying the aircraft shutdown message and getting the payload device power-off preparation flag.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_OutputHighPower

- Function: Manifold 3 outputs high voltage to external devices.

::: tip Note:
* Before requesting high voltage output, the gpio12 of Manifold 3 needs to be pulled low.
* This interface is only supported on DJI Manifold 3.
:::

```c
T_DjiReturnCode DjiPowerManagement_OutputHighPower(bool stat);
```

- Parameters
  - stat: true indicates outputting high voltage, false indicates outputting low voltage.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### E_DjiPowerManagementPinState

State of the high-power pin.

```c
typedef enum {
    DJI_POWER_MANAGEMENT_PIN_STATE_RESET = 0,    Pin is at low voltage
    DJI_POWER_MANAGEMENT_PIN_STATE_SET = 1,      Pin is at high voltage
} E_DjiPowerManagementPinState;
```

### E_DjiHighPowerVoltage

High-power output voltage level.

```c
typedef enum {
    E_DJI_HIGH_POWER_VOLTAGE_13V6 = 0,    Output voltage 13.6V
    E_DJI_HIGH_POWER_VOLTAGE_17V = 1,     Output voltage 17V
    E_DJI_HIGH_POWER_VOLTAGE_24V = 2,     Output voltage 24V
} E_DjiHighPowerVoltage;
```

### DjiWriteHighPowerApplyPinCallback

- Function: Callback function for setting the high-power pin state.

```c
typedef T_DjiReturnCode (*DjiWriteHighPowerApplyPinCallback)(E_DjiPowerManagementPinState pinState);
```

- Parameters
  - pinState: State of the high-power pin.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerOffNotificationCallback

- Function: Callback function for notifying the payload device that the aircraft is about to shut down and getting the power-off preparation state of the payload device.

::: tip Note:
To prevent this function from blocking the PSDK main thread, which may cause slow program response, camera-type payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef T_DjiReturnCode (*DjiPowerOffNotificationCallback)(bool *powerOffPreparationFlag);
```

- Parameters
  - powerOffPreparationFlag: Pointer to the memory space for storing the power-off preparation state.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
