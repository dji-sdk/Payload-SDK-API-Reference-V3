


## Overview

This document describes the function prototypes and data type definitions in the time synchronization module header file `dji_time_sync.h`. This module is used to synchronize the local time of a payload device with the aircraft system time. Developers can achieve precise time alignment between the payload device and the flight platform by registering a PPS trigger time callback function and calling the time conversion interface.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiTimeSync_Init

- Function: Initialize the time synchronization module.

::: tip Note:
* The maximum execution time of this function is slightly greater than 2000ms.
* This function must be called in a user task rather than in the main() function, and must be called after the scheduler has started.
:::

```c
T_DjiReturnCode DjiTimeSync_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiTimeSync_RegGetNewestPpsTriggerTimeCallback

- Function: Register a callback function to get the latest timestamp in the local time system when a PPS rising edge signal is detected.

```c
T_DjiReturnCode DjiTimeSync_RegGetNewestPpsTriggerTimeCallback(DjiGetNewestPpsTriggerLocalTimeUsCallback callback);
```

- Parameters
  - callback: Pointer to the callback function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiTimeSync_TransferToAircraftTime

- Function: Convert the local time of a payload device to the time on the aircraft.

::: tip Note:
When using this interface, please call DjiTimeSync_RegGetNewestPpsTriggerTimeCallback() to register a callback function for getting the latest local timestamp of the payload device when the PPS signal rising edge is detected.
:::

```c
T_DjiReturnCode DjiTimeSync_TransferToAircraftTime(uint64_t localTimeUs, T_DjiTimeSyncAircraftTime *aircraftTime);
```

- Parameters
  - localTimeUs: Local time in the payload device, unit: microseconds.
  - aircraftTime: Pointer to the memory space for storing the aircraft system time.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### DjiGetNewestPpsTriggerLocalTimeUsCallback

- Function: Callback function for getting the latest PPS trigger timestamp.

::: tip Note:
Users must not execute blocking operations or functions within the callback function, as this will block the DJI root thread, causing slow system response, payload disconnection, or infinite loops.
:::

```c
typedef T_PsdkReturnCode (*GetNewestPpsTriggerLocalTimeUsCallback)(uint64_t *localTimeUs);
```

- Parameters
  - localTimeUs: Pointer to the memory space for storing the PPS trigger timestamp.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### T_DjiTimeSyncAircraftTime

Data structure of the time system in the aircraft.

```c
typedef struct {
    uint16_t year;          Year
    uint8_t month;          Month, 1~12
    uint8_t day;            Day, 1~31
    uint8_t hour;           Hour, 0~23
    uint8_t minute;         Minute, 0~59
    uint8_t second;         Second, 0~59
    uint32_t microsecond;   Microsecond, 0~999999.
} T_DjiTimeSyncAircraftTime;
```
