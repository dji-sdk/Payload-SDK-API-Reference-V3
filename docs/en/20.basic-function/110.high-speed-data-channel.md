
## Overview

This document describes the function prototypes and data type definitions in the high-speed data channel module header file `dji_high_speed_data_channel.h`. This module is used for high-speed data transmission between payload devices and mobile devices through the network channel, supporting bandwidth proportion configuration for data streams, video streams, and download streams, as well as data stream sending and state querying.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiHighSpeedDataChannel_SetBandwidthProportion

- Function: Set the bandwidth proportion of data stream, video stream, and download stream for the high-speed channel.

::: tip Note:
* The custom bandwidth allocation mechanism allows users to freely control bandwidth limits. The system multiplies the total bandwidth limit of the high-speed channel by the proportion of the corresponding stream to obtain the real-time bandwidth limit of a specific stream.
* If the user does not set the bandwidth proportion for each stream, the default proportions are 33% (data stream), 33% (video stream), and 34% (download stream).
* The bandwidth proportion takes effect after a period of time, with a maximum delay of 1s. If the user wants to use this interface, they need to call the PsdkPlatform_RegHalNetworkHandler() interface first, otherwise the interface will not work.
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_SetBandwidthProportion(
    T_DjiDataChannelBandwidthProportionOfHighspeedChannel bandwidthProportion);
```

- Parameters
  - bandwidthProportion: Bandwidth proportion of each stream in the high-speed channel. The sum of bandwidth proportions must be 100.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_GetDataStreamRemoteAddress

- Function: Get the network remote address for sending data streams.

::: tip Note:
* Users can obtain this information for performing certain operations through other subsystems in heterogeneous systems.
* This interface should be used after calling PsdkCore_Init.
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_GetDataStreamRemoteAddress(char *ipAddr, uint16_t *port);
```

- Parameters
  - ipAddr: Remote IP address for sending data streams.
  - port: Remote port for sending data streams.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_SendDataStreamData

- Function: Send data to the mobile device through the data stream of the data channel.

::: tip Note:
* This feature is only available on Linux operating systems.
* The actual bandwidth must be guaranteed to be less than the bandwidth limit of the channel or stream. Users can get the dataStream channel state through the DjiHighSpeedDataChannel_GetDataStreamState() function. If the actual bandwidth exceeds the limit or the busy state is set, users should stop transmitting data or reduce the data volume, otherwise data will be discarded.
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_SendDataStreamData(const uint8_t *data, uint16_t len);
```

- Parameters
  - data: Pointer to the data to be sent.
  - len: Length of data to be sent through the data stream, must be less than or equal to 65000, unit: byte.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_GetDataStreamState

- Function: Get the data transmission state of the dataStream channel.

::: tip Note:
* Users can use this state as the basis for controlling data stream data transmission.
* This feature is only available on Linux operating systems.
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_GetDataStreamState(T_DjiDataChannelState *state);
```

- Parameters
  - state: Pointer to the dataStream channel state.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### T_DjiDataChannelBandwidthProportionOfHighspeedChannel

Bandwidth proportion of the high-speed data channel.

```c
typedef struct {
    uint8_t dataStream;       Bandwidth proportion of data stream, range 0~100
    uint8_t videoStream;      Bandwidth proportion of video stream, range 0~100
    uint8_t downloadStream;   Bandwidth proportion of download stream, range 0~100
} T_DjiDataChannelBandwidthProportionOfHighspeedChannel;
```
