

## Overview

This document describes the function prototypes and data type definitions in the information management module header file `dji_aircraft_info.h`. This module is used to obtain basic information about the aircraft system and mobile device App, including the currently connected aircraft type, adapter type, payload mounting position, aircraft version number, connection status, and enhanced image transmission status, etc.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiAircraftInfo_GetBaseInfo

- Function: Get basic information about the aircraft system.

::: tip Note:
Get basic information about the aircraft system, including the aircraft type and DJI adapter type.
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetBaseInfo(T_DjiAircraftInfoBaseInfo *baseInfo);
```

- Parameters
  - baseInfo: Pointer to the memory space used to store the basic information of the aircraft system.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetMobileAppInfo

- Function: Get basic information about the mobile device App.

::: tip Note:
If the remote controller or App is not connected to the aircraft system, the mobile device App language and screen type are unknown.
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetMobileAppInfo(T_DjiMobileAppInfo *mobileAppInfo);
```

- Parameters
  - mobileAppInfo: Pointer to the memory space used to store mobile App related information.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetConnectionStatus

- Function: Get the connection status between the payload device and the aircraft.

::: tip Note:
Update frequency is 1Hz.
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetConnectionStatus(bool *isConnected);
```

- Parameters
  - isConnected: Pointer to the connection status. true indicates connected, false indicates not connected.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetAircraftVersion

- Function: Get the version information of the aircraft.

```c
T_DjiReturnCode DjiAircraftInfo_GetAircraftVersion(T_DjiAircraftVersion *aircraftVersion);
```

- Parameters
  - aircraftVersion: Pointer to the aircraft version information.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetEnhancedTransmission

- Function: Get the enhanced image transmission status, which is configured in the image transmission settings of the mobile App.

```c
T_DjiReturnCode DjiAircraftInfo_GetEnhancedTransmission(E_DjiEnhancedTransmissionState *state);
```

- Parameters
  - state: Pointer to the enhanced image transmission status.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### T_DjiMobileAppInfo

Mobile device App related information.

```c
typedef struct {
    E_DjiMobileAppLanguage appLanguage;      Mobile device App system language
    E_DjiMobileAppScreenType appScreenType;  Mobile device App screen size type
} T_DjiMobileAppInfo;
```

### T_DjiAircraftInfoBaseInfo

Basic information of the aircraft system, mainly including some constant parameter information of the system.

```c
typedef struct {
    E_DjiAircraftSeries aircraftSeries;      Aircraft series
    E_DjiMountPositionType mountPositionType; Mount position type
    E_DjiAircraftType aircraftType;          Aircraft type
    E_DjiSdkAdapterType djiAdapterType;      DJI adapter type
    E_DjiMountPosition mountPosition;        Payload mount position
} T_DjiAircraftInfoBaseInfo;
```

### T_DjiAircraftVersion

Aircraft version information.

```c
typedef struct {
    uint8_t debugVersion;     Debug version number
    uint8_t modifyVersion;    Patch version number
    uint8_t minorVersion;     Minor version number
    uint8_t majorVersion;     Major version number
} T_DjiAircraftVersion;
```

### E_DjiEnhancedTransmissionState

Enhanced image transmission status.

```c
typedef enum {
    DJI_ENHANCEED_TRANSMISSION_STATE_DISABLED = 0,    Enhanced image transmission disabled
    DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED  = 3,    Enhanced image transmission enabled
} E_DjiEnhancedTransmissionState;
```
