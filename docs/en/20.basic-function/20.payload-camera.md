
## Overview

This document describes the function prototypes and data type definitions in the camera function module header file `dji_payload_camera.h`. This module is used to implement third-party camera payload devices based on PSDK. By registering camera control callback functions, developers can implement features such as photo capture, video recording, zoom, focus, metering, media file download and playback, video stream transmission, etc., to fully integrate third-party camera payload devices with the DJI flight platform.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiPayloadCamera_Init

- Function: PSDK camera module initialization.

::: tip Note:
* Before using camera functions, please call this interface to initialize the camera module first.
* Developers can construct and register callback functions according to the function prototypes in the camera module based on actual user needs. Before using camera functions, please call this interface to initialize the camera module first.
:::

```c

```

### DjiPayloadCamera_SendVideoStream

- Function: Send video to the mobile device through the data channel video stream.

::: tip Note:
* This function is only available on the Linux platform.
* You must ensure that the actual bandwidth is less than the bandwidth limit of the corresponding channel or stream. For details on bandwidth limits, please refer to the developer documentation and channel/stream status. Users can obtain the status of the videoStream channel through the DjiPayloadCamera_GetVideoStreamState() function. If the actual bandwidth exceeds the limit or the busy status is set, users should stop transmitting data or reduce the amount of data to be sent, otherwise data may be dropped.
:::

```c
T_DjiReturnCode DjiPayloadCamera_SendVideoStream(const uint8_t *data, uint16_t len);
```

- Parameters
  - data: Pointer to the data to be sent.
  - len: Length of data sent through the data stream, must be less than or equal to 65000, unit: bytes.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### E_DjiCameraVideoStreamType

Video stream format of the camera payload device.

```c
typedef enum {
    DJI_CAMERA_VIDEO_STREAM_TYPE_H264_CUSTOM_FORMAT = 0,    The camera video stream follows the custom H264 format, which must comply with the Custom-H264 video stream format standard in the user documentation. When sending video streams in this format, the video stream bitrate cannot exceed the real-time channel bandwidth limit, which can be obtained through the DjiPayloadCamera_GetVideoStreamState interface
    DJI_CAMERA_VIDEO_STREAM_TYPE_H264_DJI_FORMAT = 1,       The camera video stream follows the DJI-H264 format, which must comply with the DJI-H264 video stream format standard in the user documentation. ### T_DjiCameraCommonHandler
```

- Function: Collection of callback functions for basic functions of the camera payload device.

Construct callback functions for the camera payload device to perform basic functions based on the functions in this structure, including:
* Get the current state of the camera payload device
* Set the working mode of the camera payload device
* Get the current working mode of the camera payload device
* Control the camera payload device to start recording video
* Control the camera payload device to stop recording video
* Control the camera payload device to start taking photos
* Control the camera payload device to stop taking photos
* Set the photo capture mode of the camera payload device
* Get the current photo capture mode of the camera payload device
* Set the burst count in burst mode of the camera payload device
* Get the current burst count of the camera payload device
* Set the photo interval in interval shooting mode of the camera payload device
* Get the photo interval in interval shooting mode of the camera payload device
* Get the current SD card state in the camera payload device
* Control the camera payload device to format the SD card

::: tip Note:
* To prevent blocking the PSDK main thread, which may cause slow program response, camera payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
* When using the functions to control the camera payload device to perform basic actions, please develop the basic functions of the camera payload device according to the following function prototypes.
:::

```c
typedef struct {
    @brief Callback function to get the current state of the camera payload device
    @param systemState: Pointer to the memory space used to store the current state of the camera payload device
    @return Execution result
    T_DjiReturnCode (*GetSystemState)(T_DjiCameraSystemState *systemState);

    @brief Callback function to set the working mode of the camera payload device
    @note The working mode cannot be switched while the camera payload device is performing a task
    @param mode: Camera working mode
    @return Execution result
    T_DjiReturnCode (*SetMode)(E_DjiCameraMode mode);

    @brief Callback function to get the current working mode of the camera payload device
    @param mode: Pointer to the memory space used to store the working mode of the camera payload device
    @return Execution result
    T_DjiReturnCode (*GetMode)(E_DjiCameraMode *mode);

    @brief Callback function to control the camera payload device to start recording video
    @return Execution result
    T_DjiReturnCode (*StartRecordVideo)(void);

    @brief Callback function to control the camera payload device to stop recording video
    @return Execution result
    T_DjiReturnCode (*StopRecordVideo)(void);

    @brief Callback function to control the camera payload device to start taking photos
    @return Execution result
    T_DjiReturnCode (*StartShootPhoto)(void);

    @brief Callback function to control the camera payload device to stop taking photos
    @return Execution result
    T_DjiReturnCode (*StopShootPhoto)(void);

    @brief Callback function to set the photo capture mode of the camera payload device
    @param mode: Camera photo capture mode
    @return Execution result
    T_DjiReturnCode (*SetShootPhotoMode)(E_DjiCameraShootPhotoMode mode);

    @brief Callback function to get the current photo capture mode of the camera payload device
    @param mode: Pointer to the memory space used to store the photo capture mode of the camera payload device
    @return Execution result
    T_DjiReturnCode (*GetShootPhotoMode)(E_DjiCameraShootPhotoMode *mode);

    @brief Callback function to set the burst count in burst mode of the camera payload device
    @param burstCount: Camera burst count
    @return Execution result
    T_DjiReturnCode (*SetPhotoBurstCount)(E_DjiCameraBurstCount burstCount);

    @brief Callback function to get the current burst count of the camera payload device
    @param burstCount: Pointer to the memory space used to store the burst count of the camera payload device
    @return Execution result
    T_DjiReturnCode (*GetPhotoBurstCount)(E_DjiCameraBurstCount *burstCount);

    @brief Callback function to set the photo interval in interval shooting mode of the camera payload device
    @note The time interval for interval shooting ranges from 2 to 255. When the time interval is set to 255, the camera payload device will continuously take photos
    @param settings: Set the time interval for interval shooting of the camera payload device
    @return Execution result
    T_DjiReturnCode (*SetPhotoTimeIntervalSettings)(T_DjiCameraPhotoTimeIntervalSettings settings);

    @brief Callback function to get the photo interval in interval shooting mode of the camera payload device
    @param settings: Pointer to the memory space used to store the photo interval time in interval shooting mode of the camera payload device
    @return Execution result
    T_DjiReturnCode (*GetPhotoTimeIntervalSettings)(T_DjiCameraPhotoTimeIntervalSettings *settings);

    @brief Callback function to get the current SD card state in the camera payload device
    @param sdCardState: Pointer to the memory space used to store the SD card state of the camera payload
    @return Execution result
    T_DjiReturnCode (*GetSDCardState)(T_DjiCameraSDCardState *sdCardState);

    @brief Callback function to control the camera payload device to format the SD card
    @return Execution result
    T_DjiReturnCode (*FormatSDCard)(void);

} T_DjiCameraCommonHandler;
```
