
## Overview

This document describes the function prototypes and data type definitions in the low-speed data channel module header file `dji_low_speed_data_channel.h`. This module is used for low-speed data transmission between payload devices, onboard computers, and mobile apps through the command channel, supporting data sending, receive callback registration, and channel state querying.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

- Function: Initialize the low-speed data channel module.

::: tip Note:
`DjiLowSpeedDataChannel_Init` must be used after `DjiCore_Init`.

### DjiLowSpeedDataChannel_SendData

- Function: Send data to the selected channel address endpoint through the command channel.

::: tip Note:
* If the actual bandwidth is below the limit, data can be sent directly to the endpoint. If the limit is exceeded, data will be stored in the flow controller's buffer and sent to the endpoint after a period of time (an integer multiple of 1s, the exact time depends on the bandwidth limit and buffer size). If the buffer is full, data will be discarded. The capacity of the flow controller buffer is 512 bytes.
* The actual bandwidth must be guaranteed to be less than the bandwidth limit of the corresponding channel or stream. Users can get the command channel state through the DjiLowSpeedDataChannel_GetSendDataState() function. If the actual bandwidth exceeds the limit or the busy state is set, users should stop transmitting data or reduce the data volume.
* On the physical link of the command channel, the maximum size of a data packet sent to the selected channel address endpoint is 128. If the length of data to be sent is greater than 128, the data will be split into multiple packets for sending, and users will also receive multiple data packets at the selected channel address endpoint.
:::

```c
T_DjiReturnCode DjiLowSpeedDataChannel_SendData(E_DjiChannelAddress channelAddress, const uint8_t *data,
                                                uint8_t len);
```

- Parameters
  - channelAddress: Channel address of the low-speed data channel.
  - data: Pointer to the data to be sent.
  - len: Length of the data to be sent, unit: byte.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiLowSpeedDataChannel_GetSendDataState

- Function: Get the data transmission state of the command transmission channel.

::: tip Note:
Users can use this state as the basis for controlling communication between the selected channel address and the onboard computer.
:::

```c
T_DjiReturnCode DjiLowSpeedDataChannel_GetSendDataState(E_DjiChannelAddress channelAddress,
                                                        T_DjiDataChannelState *state);
```

- Parameters
  - channelAddress: Channel address of the low-speed data channel.
  - state: Pointer to the low-speed channel state.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiLowSpeedDataChannel_RegRecvDataCallback

- Function: Register a callback function to receive data from a specified channel address.

::: tip Note:
After the callback function is registered, it will be automatically called when the system receives data from the specified channel address.
:::

```c
T_DjiReturnCode DjiLowSpeedDataChannel_RegRecvDataCallback(E_DjiChannelAddress channelAddress,
                                                           DjiLowSpeedDataChannelRecvDataCallback callback);
```

- Parameters
  - channelAddress: Channel address of the low-speed channel.
  - callback: Pointer to the callback function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### DjiLowSpeedDataChannelRecvDataCallback

- Function: Callback function prototype for receiving data from a selected channel address.

::: tip Note:
Users must not execute blocking operations or functions within the callback function, as this will block the root thread, causing slow system response, payload disconnection, or infinite loops.
:::

```c
typedef T_DjiReturnCode (*DjiLowSpeedDataChannelRecvDataCallback)(const uint8_t *data, uint16_t len);
```

- Parameters
  - data: Pointer to the data.
  - len: Length of the data.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
