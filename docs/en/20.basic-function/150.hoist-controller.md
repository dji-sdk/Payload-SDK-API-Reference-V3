
## Overview

This document describes the function prototypes and data type definitions in the hoist controller module header file `dji_psdk_hoist_controller.h`. This module is used to control and monitor the aircraft's hoist system (including standard hoist, simple hoist, and smart hook). Developers can use this module to get hoist status, hook status, obstacle avoidance status, and send control commands such as reel in/out cable, open/close hook, and escape.

::: tip Supported Aircraft Models
This module applies to FlyCart 100 only. For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiHoistControllerManagement_Init

- Function: Initialize the hoist controller module.

::: tip Note:
Users should call this function before using the hoist controller feature.
:::

## Data Type Definitions

### E_DjiHoistControllerCmdStatus

Hoist control command.

```c
typedef enum {
    DJI_HOIST_CARGO_RELEASE_CMD     = 0,    Release cargo
    DJI_HOIST_CARGO_STOP_CMD        = 1,    Stop releasing or retrieving cargo
    DJI_HOIST_CARGO_RECEIVE_CMD     = 2,    Retrieve cargo
    DJI_HOIST_CARGO_MAINTENANCE_CMD = 4,    Maintenance mode
    DJI_HOIST_CARGO_ESCAPE_TROUBLE  = 6,    Escape
} E_DjiHoistControllerCmdStatus;
```

### E_DjiHookControllerCmdStatus

Hook control command.

```c
typedef enum {
    DJI_HOOK_CARGO_OLOSE_HOOK = 1,    Close hook
    DJI_HOOK_CARGO_OPEN_HOOK  = 2,    Open hook
} E_DjiHookControllerCmdStatus;
```

### E_DjiHoistCableStatus

Hoist cable status.

```c
typedef enum {
    DJI_HOIST_CABLE_UP_DONE        = 0,       Cable reel-in complete
    DJI_HOIST_CABLE_TAKING_UP      = 0x1,     Reeling in cable
    DJI_HOIST_CABLE_PAUSE          = 0x2,     Action paused
    DJI_HOIST_CABLE_TAKING_DOWN    = 0x3,     Reeling out cable
    DJI_HOIST_CABLE_DOWN_DONE      = 0x4,     Cable reel-out complete
    DJI_HOIST_CABLE_SYSTEM_PROTECT = 0xf,     System protection/abnormal
    DJI_HOIST_CABLE_UNKONW         = 0xFF,    Unknown status
} E_DjiHoistCableStatus;
```

### E_DjiHoistType

Hoist type.

```c
typedef enum {
    DJI_STANDARD_HOIST = 5,    Standard hoist
    DJI_SIMPLE_HOIST   = 4,    Simple hoist
    DJI_EEOR_LOAD      = 0,    Error/No hoist
} E_DjiHoistType;
```

### E_DjiSimpleHoistEscapeCmd

Simple hoist escape command.

```c
typedef enum {
    DJI_ESCAPE_CTR_DISABLE     = 0,    Disable escape
    DJI_ESCAPE_CTR_ENABLE      = 1,    Enable escape
    DJI_ROD_CTRL_CMD_OUT_ONLY  = 2,    Push out only (for rod-type simple hoist)
    DJI_ROD_CTRL_CMD_IN_ONLY   = 3,    Push in only (for rod-type simple hoist)
} E_DjiSimpleHoistEscapeCmd;
```

### psdk_receive_hoist_status_t

Hoist system status.

```c
typedef struct {
    E_DjiHoistCableStatus cable_state;    Current cable status
    uint8_t  can_status;                  bit0: Can reel out; bit1: Can reel in; bit7: Can control hoist
    int32_t  goods_weight;                Cargo weight, unit: g
    uint32_t max_goods_weight;            Maximum cargo weight, unit: g
    uint16_t cargo_swing_speed;           Cargo swing speed
    uint16_t cur_cable_length;            Current cable length, unit: m
    uint16_t cable_force;                 Cable tension, unit: g
    uint16_t cable_angle;                 Cable angle, unit: 0.1 degrees
    uint8_t  is_reach_top;                Whether cargo has reached the top, 1: Yes; 0: No
    uint8_t  is_reach_max_round;          Whether cable has reached the maximum number of rounds
    uint8_t  cable_direction_check_state; Cable check status: 0x00: Idle; 0x01: Checking; 0x02: Check result correct; 0x03: Check result incorrect
    uint16_t cable_speed;                 Current cable action speed, unit: cm/s
} psdk_receive_hoist_status_t;
```

### psdk_receive_hook_status_t

Smart hook status.

```c
typedef struct {
    uint8_t  version;          Version number
    uint8_t  steer_state;      Hook status: 0x0: Unknown; 0x1: Closed; 0x2: Open; 0x3: Middle position
    int16_t  cargo_weight;     Cargo weight, unit: 0.1 kg
    uint16_t cargo_warnig;     Hook warning: 0 means normal; bit0: Battery not in place; bit1: Low battery; bit2: Low voltage; bit3: Servo not in place; bit4: Servo stalled; bit5: Disconnected; bit14: Servo abnormal; bit15: Hook not activated
    uint16_t cargo_error;      Hook fault, 0 means normal
    uint8_t  ctrl_state;       Hook control status: 0: Normal; 1: Servo powering on; 2: Servo powered on; 3: Servo moving (open); 4: Servo stopped normally; 5: Servo moving (close)
} psdk_receive_hook_status_t;
```

### psdk_receive_simple_hoist_status_t

Simple hoist status.

```c
typedef struct {
    uint8_t  version;          Version number
    uint8_t  sensor_damage;    Sensor status: 0x0: Normal; 0x1: Damaged
    uint8_t  weight_k_err;     Weight calibration error: 0x0: Normal; Other: Error
    int16_t  force_kg;         Force value, force_kg / 100 = kg
    int16_t  angle_deg;        Angle value, angle_deg / 100 = degrees
} psdk_receive_simple_hoist_status_t;
```

### psdk_receive_avoid_status_t

Flight obstacle avoidance status.

```c
typedef struct {
    uint8_t is_cargo_avoid:1;        Cargo obstacle avoidance in progress
    uint8_t is_avoid_stop_finish:1;  Obstacle avoidance flight stopped
    uint8_t is_start_avoid:1;        Obstacle avoidance started, beginning to decelerate
    uint8_t reserve:5;               Reserved
} psdk_receive_avoid_status_t;
```
