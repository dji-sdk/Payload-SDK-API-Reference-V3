
## Overview

This document describes the function prototypes and data type definitions in the local upgrade module header file `dji_upgrade.h`. This module is used to implement firmware upgrade functionality for payload devices. Developers can use this module to configure firmware transfer methods, register upgrade handler functions, push upgrade status, and more, enabling payload devices to support firmware upgrades through DJI Assistant 2.

::: tip Note:
- Only payload devices developed using X-Port can use `dji_upgrade.h`. If you are developing a payload device using SkyPort, please use <a href="./gimbal.html">dji_gimbal.h</a>.
- For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiUpgrade_Init

- Function: Initialize the upgrade module. Users should call this function before using the upgrade functionality.

```c
T_DjiReturnCode DjiUpgrade_Init(const T_DjiUpgradeConfig *upgradeConfig);
```

- Parameters
  - upgradeConfig: Pointer to the upgrade configuration struct, which contains the current firmware version and firmware transfer information.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_EnableLocalUpgrade

- Function: Enable local upgrade mode. Once enabled, DJI Assistant 2 will display the payload upgrade interface, allowing users to select a firmware file to upgrade the payload device.

```c
T_DjiReturnCode DjiUpgrade_EnableLocalUpgrade(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_RegHandler

- Function: Register the handler functions for the upgrade process.

```c
T_DjiReturnCode DjiUpgrade_RegHandler(const T_DjiUpgradeHandler *upgradeHandler);
```

- Parameters
  - upgradeHandler: Pointer to the upgrade handler function struct.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_PushUpgradeState

- Function: Push upgrade status to the terminal App.

```c
T_DjiReturnCode DjiUpgrade_PushUpgradeState(const T_DjiUpgradeState *upgradeState);
```

- Parameters
  - upgradeState: Pointer to the upgrade state struct, which contains status information during the upgrade process.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiFirmwareTransferType

Firmware transfer type.

```c
typedef enum {  
    DJI_FIRMWARE_TRANSFER_TYPE_FTP = 0,  FTP firmware transfer type
    DJI_FIRMWARE_TRANSFER_TYPE_DCFTP,  DCFTP firmware transfer type
} E_DjiFirmwareTransferType;
```

### E_DjiUpgradeStage

Upgrade stage.

```c
typedef enum {
    DJI_UPGRADE_STAGE_IDLE = 0,  Idle stage, indicating the device is not currently in upgrade mode
    DJI_UPGRADE_STAGE_ONGOING = 3,  Upgrade ongoing stage, indicating the payload device is being upgraded
    DJI_UPGRADE_STAGE_DEVICE_REBOOT = 6,  Device reboot stage, indicating the device is rebooting
    DJI_UPGRADE_STAGE_END = 4,  Upgrade end stage, indicating the upgrade is complete and the result is reported to the terminal App
} E_DjiUpgradeStage;
```

### E_DjiUpgradeEndState

Upgrade end state.

```c
typedef enum {
    DJI_UPGRADE_END_STATE_SUCCESS = 1,  Upgrade succeeded
    DJI_UPGRADE_END_STATE_UNKNOWN_ERROR = 2,  Upgrade failed
} E_DjiUpgradeEndState;
```

### T_DjiUpgradeDcftpFileTransferOpt

- Function: Collection of DCFTP file transfer operation callback functions.

Construct callback functions for DCFTP file transfer based on the functions in this struct, including:
* Start file transfer
* Transfer file data
* Complete file transfer

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, camera payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {
    @brief Callback function to start file transfer
    @param fileInfo: Information about the file to be transferred
    @return Execution result
    T_DjiReturnCode (*start)(const T_DjiUpgradeFileInfo *fileInfo);

    @brief Callback function to transfer file data
    @details After the transfer starts, this callback function will be called multiple times to sequentially transfer file data
    @param data: Pointer to the memory space for storing file data
    @param dataLen: Data length
    @return Execution result
    T_DjiReturnCode (*transfer)(const uint8_t *data, uint16_t dataLen);

    @brief Callback function to complete file transfer
    @param md5: MD5 value of the file, used to verify the correctness of the file transfer
    @return Execution result
    T_DjiReturnCode (*finish)(const uint8_t md5[DJI_MD5_BUFFER_LEN]);
} T_DjiUpgradeDcftpFileTransferOpt;
```

### T_DjiFirmwareTransferInfo

Firmware transfer information.

```c
typedef struct {
    E_DjiFirmwareTransferType transferType;  Firmware transfer type

    T_DjiUpgradeFtpFileTransferInfo ftpTransferInfo;  When transferType is DJI_FIRMWARE_TRANSFER_TYPE_FTP, FTP transfer information must be provided
    T_DjiUpgradeDcftpFileTransferOpt dcftpFileTransferOpt;  When transferType is DJI_FIRMWARE_TRANSFER_TYPE_DCFTP, DCFTP file transfer operations must be provided
} T_DjiFirmwareTransferInfo;
```

### T_DjiUpgradeState

Upgrade state information.

```c
typedef struct {
    E_DjiUpgradeStage upgradeStage;  Upgrade stage during the upgrade process

    union {
        T_DjiUpgradeOngoingInfo upgradeOngoingInfo;  When upgradeStage is DJI_UPGRADE_STAGE_ONGOING, upgrade ongoing information must be provided
        T_DjiUpgradeRebootInfo upgradeRebootInfo;  When upgradeStage is DJI_UPGRADE_STAGE_DEVICE_REBOOT, device reboot information must be provided
        T_DjiUpgradeEndInfo upgradeEndInfo;  When upgradeStage is DJI_UPGRADE_STAGE_END, upgrade end information must be provided
    };
} T_DjiUpgradeState;
```

### T_DjiUpgradeConfig

Upgrade configuration information.

```c
typedef struct {
    T_DjiFirmwareVersion currentFirmwareVersion;  Current firmware version of the payload device
    T_DjiFirmwareTransferInfo firmwareTransferInfo;  Firmware transfer information of the payload device
} T_DjiUpgradeConfig;
```

### T_DjiUpgradeHandler

- Function: Collection of upgrade handler callback functions.

Construct callback functions for upgrade handling based on the functions in this struct, including:
* Enter upgrade mode
* Verify the transferred firmware
* Start firmware upgrade
* Complete firmware upgrade

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, camera payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {
    @brief Callback function to enter upgrade mode
    @param waitTime: Wait time to enter upgrade mode. The terminal App will wait for this duration before proceeding with subsequent upgrade operations. This time can be used to prepare for the firmware upgrade in other tasks, such as clearing the firmware storage area. Unit: s
    @return Execution result
    T_DjiReturnCode (*EnterUpgradeMode)(uint16_t *waitTime);

    @brief Callback function to verify the transferred firmware
    @details Firmware signature verification and firmware decryption can be performed in this callback function
    @return Execution result
    T_DjiReturnCode (*CheckFirmware)(void);

    @brief Callback function to start firmware upgrade
    @note After starting the upgrade, the upgrade stage should be switched to DJI_UPGRADE_STAGE_ONGOING
    @return Execution result
    T_DjiReturnCode (*StartUpgrade)(void);

    @brief Callback function to complete firmware upgrade
    @note After calling finish upgrade, the upgrade stage should be switched from DJI_UPGRADE_STAGE_END to DJI_UPGRADE_STAGE_IDLE
    @return Execution result
    T_DjiReturnCode (*FinishUpgrade)(void);
} T_DjiUpgradeHandler;
```
