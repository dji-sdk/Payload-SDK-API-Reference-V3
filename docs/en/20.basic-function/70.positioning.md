
## Overview

This document describes the function prototypes and data type definitions in the precise positioning module header file `dji_positioning.h`. This module is based on the aircraft RTK positioning system and can obtain high-precision position information of the payload device target point when a positioning event is triggered. It is suitable for applications requiring centimeter-level positioning accuracy, such as aerial surveying and mapping, and precision photogrammetry.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiPositioning_Init

- Function: Initialize the precise positioning module.

::: tip Note:
* Please call this interface in blocking mode to initialize the precise positioning module before using precise positioning functions.
* The initialization time of this interface may exceed 500ms.
* Do not call this interface in the main function.
:::

```c
T_DjiReturnCode DjiPositioning_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPositioning_SetTaskIndex

- Function: Set the task index.
- Supported aircraft models: Matrice 200 RTK V2, Matrice 300 RTK

::: tip Note:
A single task may involve aerial surveying and mapping of an area. The default task index is 0.
:::

```c
void DjiPositioning_SetTaskIndex(uint8_t index);
```

- Parameters
  - index: Task index.
- Return Value
  - None


### DjiPositioning_GetPositionInformationSync

- Function: Get precise positioning information.

::: tip Note:
* Developers can simultaneously obtain positioning information triggered by multiple positioning events, such as positioning information when multiple camera payloads on the aircraft perform synchronized zoom.
* When a positioning event occurs, this interface will obtain precise positioning information in blocking mode.
* Before obtaining precise positioning, developers must register a callback function to get the latest PPS timestamp of the aircraft. For details, please refer to: DjiTimeSync_RegGetNewestPpsTriggerTimeCallback().
* When obtaining precise positioning, the default target point is the center of the main gimbal port.
* Developers can calculate the precise positioning information of the point of interest using the center of the main gimbal port, the distance between the main gimbal port and the RTK main antenna, the aircraft attitude angles, the gimbal structure, and other data.
* The execution time of this interface may exceed 600ms.
* All requested timestamps must be between 2 seconds before the latest sync timestamp and 1 second before the latest sync timestamp.
:::

```c
T_DjiReturnCode DjiPositioning_GetPositionInformationSync(uint8_t eventCount, T_DjiPositioningEventInfo *eventInfo,
                                                          T_DjiPositioningPositionInfo *positionInfo);
```

- Parameters
  - eventCount: Number of events for which to simultaneously obtain positioning information (<5).
  - eventInfo: Pointer to the positioning event information.
  - positionInfo: Positioning information of the target point.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPositioning_RegReceiveRtcmDataCallback

- Function: Register a callback function to receive RTK RTCM raw data by data type.

::: tip Note:
Once registered, the callback function will be called. The call frequency depends on the number of satellites.
:::

```c
T_DjiReturnCode DjiPositioning_RegReceiveRtcmDataCallback(E_DjiPositioningRtcmDataType dataType,
                                                          DjiReceiveRtkRtcmDataCallback callback);
```

- Parameters
  - dataType: RTCM data type.
  - callback: Pointer to the callback function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### E_DjiPositioningRtcmDataType

Positioning RTCM data type.

```c
typedef enum {
    DJI_POSITIONING_RTCM_DATA_TYPE_RTK_ON_AIRCRAFT = 0,     Aircraft onboard RTK
    DJI_POSITIONING_RTCM_DATA_TYPE_RTK_BASE_STATION = 1,    RTK base station
} E_DjiPositioningRtcmDataType;
```

### T_DjiPositioningEventInfo

Describes a positioning event.

```c
typedef struct {
    uint16_t eventSetIndex;                    Index of the positioning event triggered by the payload device. This index will be written to the .mark file. If no index is needed for the positioning event, fill in 0
    uint8_t targetPointIndex;                  Index of the positioning point obtained by the payload device. This index will be written to the .mark file. If no index is needed for the positioning event, fill in 0
    T_DjiTimeSyncAircraftTime eventTime;       Timestamp when the positioning event occurred. Users need to convert this time (local time on the payload device) to the aircraft time using the DjiTimeSync_TransferToAircraftTime() interface in the time synchronization module
} T_DjiPositioningEventInfo;
```

### T_DjiPositioningPosition

Struct for describing a positioning point.

```c
typedef struct {
    dji_f64_t longitude;    Longitude of the positioning point, unit: degree
    dji_f64_t latitude;     Latitude of the positioning point, unit: degree
    dji_f64_t height;       Height of the positioning point above sea level, unit: meter
} T_DjiPositioningPosition;
```

### T_DjiPositioningPositionStandardDeviation

Standard deviation of the positioning point.

```c
typedef struct {
    dji_f32_t longitude;    Standard deviation of the positioning point longitude, unit: degree
    dji_f32_t latitude;     Standard deviation of the positioning point latitude, unit: degree
    dji_f32_t height;       Standard deviation of the positioning point height above sea level, unit: meter
} T_DjiPositioningPositionStandardDeviation;
```

### T_DjiPositioningPositionInfo

Detailed information of the target point.

```c
typedef struct {
    E_DjiFcSubscriptionPositionSolutionProperty positionSolutionProperty;                      Position solution property
    T_DjiAttitude3d uavAttitude;                                                               Aircraft attitude angle when obtaining the target point, unit: degree
    T_DjiVector3d offsetBetweenMainAntennaAndTargetPoint;                                      Offset from the aircraft main antenna to the target point in the NED geodetic coordinate system, unit: mm
    T_DjiPositioningPosition targetPointPosition;                                              Position of the target point in the geodetic coordinate system
    T_DjiPositioningPositionStandardDeviation targetPointPositionStandardDeviation;             Standard deviation of the target point
} T_DjiPositioningPositionInfo;
```

### DjiReceiveRtkRtcmDataCallback

- Function: Callback function prototype for receiving RTK RTCM raw data.

```c
typedef T_DjiReturnCode (*DjiReceiveRtkRtcmDataCallback)(uint8_t index, const uint8_t *data, uint16_t dataLen);
```

- Parameters
  - index: Index of the RTCM data packet.
  - data: Pointer to the RTK RTCM data received from the aircraft.
  - dataLen: Length of the RTCM data received from the aircraft.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
