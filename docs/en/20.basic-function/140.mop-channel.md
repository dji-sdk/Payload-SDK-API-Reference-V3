
## Overview

This document describes the function prototypes and data type definitions in the SDK interconnection module header file `dji_mop_channel.h`. This module is used to establish MOP channels between payload devices and mobile apps developed based on MSDK or onboard applications developed based on OSDK, enabling reliable or unreliable data transmission.

::: tip Note:
- Only payload devices developed on Linux support developers using the SDK interconnection feature.
- For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiMopChannel_Init

- Function: MOP channel initialization.

::: tip Note:
* Before using the MOP channel to transmit information, please use this interface to initialize the MOP channel first.
* Before calling this interface, please ensure that the payload device is connected to the network port.
:::

```c
T_DjiReturnCode DjiMopChannel_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Create

- Function: Create an MOP channel.

::: tip Note:
* After the MOP channel is successfully created, specify the channel ID to be connected with the created channel and wait for the mobile app developed based on MSDK or the application developed based on OSDK to connect to the channel.
* After successfully accepting a connection from another device, the user can send or receive data on this channel.
* When the MOP channel is no longer needed, please close or destroy the created channel to release the system resources occupied by the channel.
:::

```c
T_DjiReturnCode DjiMopChannel_Create(T_DjiMopChannelHandle *channelHandle, E_DjiMopChannelTransType transType);
```

- Parameters
  - channelHandle: Pointer to the MOP channel handle to be created.
  - transType: Type of the MOP channel.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Destroy

- Function: Destroy a created MOP channel.

::: tip Note:
After calling this interface, developers cannot perform any other operations on this channel.
:::

```c
T_DjiReturnCode DjiMopChannel_Destroy(T_DjiMopChannelHandle channelHandle);
```

- Parameters
  - channelHandle: Pointer to the created MOP channel.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Bind

- Function: Bind a channel ID to a created MOP channel.

::: tip Note:
After the MOP channel is successfully created, developers can bind a specified channel ID to the created MOP channel. After calling the DjiMopChannel_Accept interface, a connection can be established with the client device.
:::

```c
T_DjiReturnCode DjiMopChannel_Bind(T_DjiMopChannelHandle channelHandle, uint16_t channelId);
```

- Parameters
  - channelHandle: Pointer to the created MOP channel.
  - channelId: Specified channel ID for the connection.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Accept

- Function: Accept a connection request from another device and establish a connection through the bound channel ID.

::: tip Note:
MOP listens on the channel through channelHandle, accepts MOP channel connection requests waiting in the queue, creates a new connected channel, and returns the channel information through outChannelHandle. The payload device can act as a server to allow multiple clients to establish connections with the created channel through the bound channel ID.
:::

```c
T_DjiReturnCode DjiMopChannel_Accept(T_DjiMopChannelHandle channelHandle,
                                     T_DjiMopChannelHandle *outChannelHandle);
```

- Parameters
  - channelHandle: Pointer to the created MOP channel.
  - outChannelHandle: Pointer to the MOP output channel after a successful connection.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Connect

- Function: MOP channel connection.

```c
T_DjiReturnCode DjiMopChannel_Connect(T_DjiMopChannelHandle channelHandle, E_DjiChannelAddress channelAddress,
                                      uint16_t channelId);
```

- Parameters
  - channelHandle: Pointer to the created MOP channel.
  - channelAddress: Channel address.
  - channelId: Channel ID.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_Close

- Function: Close a created MOP channel.

::: tip Note:
After calling this interface, no other operations can be performed on this channel except destroying the channel.
:::

```c
T_DjiReturnCode DjiMopChannel_Close(T_DjiMopChannelHandle channelHandle);
```

- Parameters
  - channelHandle: Pointer to the created MOP channel.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_SendData

- Function: Send data using the MOP channel.

::: tip Note:
* This interface can be called after successfully calling the DjiMopChannel_Accept interface.
* To improve read/write efficiency, it is recommended to send larger data chunks each time. Please determine the data sending status based on the return value and data length.
:::

```c
T_DjiReturnCode DjiMopChannel_SendData(T_DjiMopChannelHandle channelHandle,
                                       uint8_t *data,
                                       uint32_t len,
                                       uint32_t *realLen);
```

- Parameters
  - channelHandle: Pointer to the MOP handle outChannelHandle obtained after calling DjiMopChannel_Accept.
  - data: Pointer to the data to be sent.
  - len: Length of the data to be sent, unit: byte.
  - realLen: Pointer to the actual length of data sent.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiMopChannel_RecvData

- Function: Receive data using the MOP channel.

::: tip Note:
* This interface can be called after successfully calling the DjiMopChannel_Accept interface.
* To improve read/write efficiency, it is recommended to receive larger data chunks each time. Please determine the data receiving status based on the return value and the length of successfully received data.
:::

```c
T_DjiReturnCode DjiMopChannel_RecvData(T_DjiMopChannelHandle channelHandle,
                                       uint8_t *data,
                                       uint32_t len,
                                       uint32_t *realLen);
```

- Parameters
  - channelHandle: Pointer to the MOP handle outChannelHandle obtained after calling DjiMopChannel_Accept.
  - data: Pointer to the buffer for storing received data.
  - len: Length of data to receive, unit: byte.
  - realLen: Pointer to the actual length of data received.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### T_DjiMopChannelHandle

MOP communication channel handle.

```c
typedef void *T_DjiMopChannelHandle;
```

### E_DjiMopChannelTransType

Data transmission type of the MOP channel.

```c
typedef enum {
    DJI_MOP_CHANNEL_TRANS_RELIABLE = 0,    Reliable transmission
    DJI_MOP_CHANNEL_TRANS_UNRELIABLE,      Unreliable transmission
} E_DjiMopChannelTransType;
```
