
## Overview

This document describes the function prototypes and data type definitions in the HMS customization module header file `dji_hms_customization.h`. This module is used to report and clear custom HMS error codes to DJI Pilot or mobile apps developed based on MSDK, and supports registering HMS text configurations via directory path or binary array to display multilingual custom health management information.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiHmsCustomization_Init

- Function: Initialize the HMS customization module.

::: tip Note:
Users should call this function before using the HMS customization module.
:::

```c
T_DjiReturnCode DjiHmsCustomization_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_DeInit

- Function: Deinitialize the HMS customization module.

```c
T_DjiReturnCode DjiHmsCustomization_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_InjectHmsErrorCode

- Function: Report a custom HMS error code to the application.

::: tip Note:
* To report the same HMS error code, the interface only needs to be called once; repeated calls are unnecessary.
* The FlightHub platform does not yet support custom HMS text from third-party users, so it will be displayed as an unknown error on the FlightHub platform.
:::

```c
T_DjiReturnCode DjiHmsCustomization_InjectHmsErrorCode(uint32_t errorCode, E_DjiHmsErrorLevel errorLevel);
```

- Parameters
  - errorCode: HMS error code, value range: [0x1E020005 ~ 0x1E02FFFF].
  - errorLevel: HMS error level.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_EliminateHmsErrorCode

### DjiHmsCustomization_RegHmsTextConfigByDirPath

- Function: Register the directory path of the HMS text configuration file for a specified language.

::: tip Note:
The HMS text configurations for different languages must be identical.
:::

```c
T_DjiReturnCode DjiHmsCustomization_RegHmsTextConfigByDirPath(E_DjiMobileAppLanguage appLanguage, const char *configDirPath);
```

- Parameters
  - appLanguage: Language type of the mobile app.
  - configDirPath: Directory path of the HMS text configuration file.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_RegDefaultHmsTextConfigByBinaryArray

- Function: Register the default HMS text configuration using a binary array.

::: tip Note:
* In RTOS, there is usually no file system, so the HMS text configuration file content can be represented using C language arrays.
* When the settings in DjiHmsCustomization_RegHmsTextConfigByBinaryArray do not include a certain language, the HMS text configuration will fall back to the settings of this function.
:::

```c
T_DjiReturnCode DjiHmsCustomization_RegDefaultHmsTextConfigByBinaryArray(const T_DjiHmsBinaryArrayConfig *binaryArrayConfig);
```

- Parameters
  - binaryArrayConfig: Pointer to the HMS text binary array configuration.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiHmsErrorLevel

HMS error level.

```c
typedef enum {
    DJI_HMS_ERROR_LEVEL_NONE = 0,         No error
    DJI_HMS_ERROR_LEVEL_HINT,             Hint
    DJI_HMS_ERROR_LEVEL_WARN,             Warning
    DJI_HMS_ERROR_LEVEL_CRITICAL,         Critical
    DJI_HMS_ERROR_LEVEL_FATAL,            Fatal
} E_DjiHmsErrorLevel;
```

### T_DjiHmsFileBinaryArray

Binary array of the HMS text configuration file.

```c
typedef struct {
    char *fileName;                   HMS text configuration file name
    uint32_t fileSize;                Size of the HMS text configuration file, unit: byte
    const uint8_t *fileBinaryArray;   C language array of the HMS text configuration file
} T_DjiHmsFileBinaryArray;
```

### T_DjiHmsBinaryArrayConfig

HMS text binary array configuration.

```c
typedef struct {
    uint16_t binaryArrayCount;                    Element count of the binary array
    T_DjiHmsFileBinaryArray *fileBinaryArrayList;  Pointer to the binary array list
} T_DjiHmsBinaryArrayConfig;
```

### E_DjiHmsAlarmEnhancedType

Enhanced alarm type.

```c
typedef enum {
    DJI_HMS_ALARM_ENHANCED_TYPE_SHAKE_MOTOR = 1,             Trigger alarm by vibrating the motor on the remote controller, alerting the user to warnings or faults through vibration
    DJI_HMS_ALARM_ENHANCED_PLAY_SOUND = 2,                   Trigger alarm by playing sound
    DJI_HMS_ALARM_ENHANCED_PLAY_SOUND_AND_SHAKE_MOTOR = 3,   Alert the user on the Pilot App through both sound and vibration
} E_DjiHmsAlarmEnhancedType;
```

### E_DjiHmsAlarmEnhancedAction

Enhanced alarm action.

```c
typedef enum {
    DJI_HMS_ALARM_ENHANCED_ACTION_STOP = 0,       Stop the specified enhanced alarm (vibrate motor or play sound)
    DJI_HMS_ALARM_ENHANCED_ACTION_START = 1,      Start the specified enhanced alarm
    DJI_HMS_ALARM_ENHANCED_ACTION_EXIT_ALL = 2,   Exit all enhanced alarms, including vibrate motor and play sound
} E_DjiHmsAlarmEnhancedAction;
```

### T_DjiHmsAlarmEnhancedSetting

Enhanced alarm configuration.

```c
typedef struct {
    E_DjiHmsAlarmEnhancedType type;    Alarm type, specifying which enhanced alarm to perform ACTION_STOP or ACTION_START on. This field is ignored when executing EXIT_ALL
    int8_t times;                      Number of times the alarm is continuously activated
    int16_t interval;                  Interval between consecutive alarm activations, unit: milliseconds
} T_DjiHmsAlarmEnhancedSetting;
```
