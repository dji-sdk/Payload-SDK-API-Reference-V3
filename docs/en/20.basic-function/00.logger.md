
## Overview

This document describes the function prototypes and data type definitions in the logger management module header file `dji_logger.h`. This module is used to manage the output method and log level of PSDK runtime logs. Developers can register multiple console output methods (up to 8), and specify a log level for each console to flexibly control the scope of log output.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiLogger_AddConsole

- Function: Add console functionality and level for PSDK.

::: tip Note:
Before registering a console, the user needs to provide the console method and the level associated with that method. Log levels from high to low are Debug, Info, Warn, and Error. The logger module can print all logs at or below the specified level. A maximum of 8 different console methods can be registered simultaneously. Before registering console methods, you need to test the registered modules to ensure all methods work properly. If the user registers multiple modules simultaneously, all methods will be printed.
:::

```c
T_DjiReturnCode DjiLogger_AddConsole(T_DjiLoggerConsole *console);
```

- Parameters
  - console: Pointer to the console function method.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLogger_RemoveConsole

- Function: Remove PSDK console functionality and level.

```c
T_DjiReturnCode DjiLogger_RemoveConsole(T_DjiLoggerConsole *console);
```

- Parameters
  - console: Pointer to the console function method.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiLogger_UserLogOutput

- Function: Print and output logs of a selected level in a specific format through the registered method.

::: tip Note:
The registered methods print according to the corresponding level. If the console level is lower than the level of the log to be printed, the log will not be printed successfully.
:::

```c
void PsdkLogger_UserLogInfo(const char *fmt, ...);
```

- Parameters
  - fmt: Pointer to the log content that the user needs to print.
  - ...: Variable arguments, used in the same way as variable arguments in printf.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### ConsoleFunc

- Function: Console method to be registered.

::: tip Note:
Before registering log output methods, please test the methods to be registered to ensure they can be used properly.
:::

```c
typedef T_DjiReturnCode (*ConsoleFunc)(const uint8_t *data, uint16_t dataLen);
```

- Parameters
  - data: Pointer to the log data to be printed.
  - dataLen: Length of the log data.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### E_DjiLoggerConsoleLogLevel

Log level.

```c
typedef enum {
    DJI_LOGGER_CONSOLE_LOG_LEVEL_ERROR = 0,      Print system error type (Error) logs. The console method and level are associated with each other. If the registered console method level is lower than the current level, the level interface will not be printed successfully.      
    DJI_LOGGER_CONSOLE_LOG_LEVEL_WARN = 1,       Print warning information type (Warning) logs. The console method and level are associated with each other. If the registered console method level is lower than the current level, the level interface will not be printed successfully.      
    DJI_LOGGER_CONSOLE_LOG_LEVEL_INFO = 2,       Print key information type (Info) logs. The console method and level are associated with each other. If the registered console method level is lower than the current level, the level interface will not be printed successfully.      
    DJI_LOGGER_CONSOLE_LOG_LEVEL_DEBUG = 3,      Print debug information type (Debug) logs. The console method and level are associated with each other. If the registered console method level is lower than the current level, the level interface will not be printed successfully.      
} E_DjiLoggerConsoleLogLevel;
```

### T_DjiLoggerConsole

Logger console configuration.

```c
typedef struct {
    uint8_t consoleLevel;      Specify the log level to print. Log levels from high to low are Debug, Info, Warn, and Error. The logger module can print all logs at or below the specified level      
    ConsoleFunc func;          Specify the log output method. Before registering the log output method, please test that the log output method can properly print the logs required by the user
    bool isSupportColor;     
} T_DjiLoggerConsole;
```
