
## Overview

This document describes the function prototypes and data type definitions in the data subscription module header file `dji_fc_subscription.h`. This module allows payload devices to subscribe to various flight data from the aircraft at specified frequencies, including attitude, position, velocity, battery status, remote controller input, and other information. It is suitable for application scenarios that require real-time access to aircraft state data.

For subscription topics and their maximum subscription frequencies, please refer to the "Subscription Topics" section in the [Data Subscription](https://developer.dji.com/doc/payload-sdk-tutorial/en/function-overview/basic-function/fc-subscription.html#subscription-topics) chapter of the PSDK tutorial documentation.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiFcSubscription_Init

- Function: Initialize the data subscription module.

::: tip Note:
* Please use this interface to initialize the data subscription function before subscribing to any information on the aircraft.
* Do not call this interface in the main() function. Call this interface in a user thread; after the scheduler is started, this interface will operate normally.
* The execution time of this interface may exceed 500ms.
:::

```c
T_DjiReturnCode DjiFcSubscription_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFcSubscription_DeInit

- Function: Deinitialize the data subscription function.

::: tip Note:
After deinitializing the data subscription function, the occupied resources in the aircraft will also be released.
:::

```c
T_DjiReturnCode DjiFcSubscription_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFcSubscription_SubscribeTopic

- Function: Subscribe in blocking mode. Before subscribing to any data from the aircraft, the DjiFcSubscription_Init() function must be called.

::: tip Note:
* The execution time of this interface may exceed 1200ms.
* A topic cannot be subscribed to repeatedly, i.e., the same topic cannot be subscribed more than once.
* The number of subscription frequency types across all subscribed topics must not exceed 4; otherwise, the subscription will fail.
* The total data length of all topics with the same subscription frequency must not exceed 242 bytes.
:::

```c
T_DjiReturnCode DjiFcSubscription_SubscribeTopic(E_DjiFcSubscriptionTopic topic,
                                                 E_DjiDataSubscriptionTopicFreq frequency,
                                                 DjiReceiveDataOfTopicCallback callback);
```

- Parameters
  - topic: Subscription topic name.
  - frequency: Subscription frequency. The subscription frequency cannot exceed the maximum frequency limit and must be a value from the enum E_DjiFcSubscriptionTopicFreq. Also, the subscription frequency must be greater than 0. Users can find the maximum frequency in the data subscription section of the developer website (developer.dji.com) documentation.
  - callback: Callback function for receiving subscription data. If no callback function is needed, this can be set to NULL.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFcSubscription_UnSubscribeTopic

- Function: Unsubscribe in blocking mode. Before unsubscribing from any data, the DjiFcSubscription_Init() and DjiFcSubscription_SubscribeTopic() functions must have been called.

::: tip Note:
* The topic to be unsubscribed must have been previously subscribed.
* Topics to be unsubscribed must be unsubscribed in the order they were subscribed, similar to a queue where subscribing is like enqueue and unsubscribing is like dequeue.
:::

```c
T_DjiReturnCode DjiFcSubscription_UnSubscribeTopic(E_DjiFcSubscriptionTopic topic);
```

- Parameters
  - topic: Name of the topic to unsubscribe.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFcSubscription_GetLatestValueOfTopic

- Function: Get the latest data and timestamp.

::: tip Note:
When calling this interface, please specify the subscription topic and the corresponding data.
:::

```c
T_DjiReturnCode DjiFcSubscription_GetLatestValueOfTopic(E_DjiFcSubscriptionTopic topic,
                                                        uint8_t *data, uint16_t dataSizeOfTopic,
                                                        T_DjiDataTimestamp *timestamp);
```

- Parameters
  - topicName: Name of the subscription topic.
  - data: Must correctly point to the memory space for storing the subscription topic data; otherwise, this interface will return an error code.
  - dataSizeOfTopic: Must correctly specify the size of the memory space for storing the subscription topic data. Normally, this value should be the same as the length of the subscription topic; otherwise, issues such as memory overflow may occur.
  - timestamp: Must correctly point to the memory space for storing the timestamp; otherwise, this interface will return an error code or cause issues such as memory overflow. If the timestamp is not needed, this parameter can be NULL.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
