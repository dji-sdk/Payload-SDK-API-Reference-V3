
## Overview

This document describes the function prototypes and data type definitions in the gimbal module header file `dji_gimbal.h`. This module is used to implement third-party gimbals. By registering gimbal control callback functions, developers can implement gimbal angle control, calibration, mode switching, reset, and other functions, enabling full integration of a third-party gimbal with the DJI flight platform.

::: tip Note:
- Only payload devices developed using SkyPort can use `dji_gimbal.h`. If you are developing a payload device using X-Port, please use <a href="./xport.html">dji_xport.h</a>.
- For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiGimbal_Init

- Function: Initialize the gimbal module.

::: tip Note:
Please call this interface to initialize the gimbal module before using gimbal functions.
:::

```c
T_DjiReturnCode DjiGimbal_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiGimbal_DeInit

- Function: Deinitialize the gimbal module.

```c
T_DjiReturnCode DjiGimbal_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiGimbal_RegCommonHandler

- Function: Register gimbal control functions.

::: tip Note:
Register callback functions for controlling the gimbal. Once registered, the callback functions will be called automatically.
:::

```c
T_DjiReturnCode DjiGimbal_RegCommonHandler(const T_DjiGimbalCommonHandler *commonHandler);
```

- Parameters
  - commonHandler: Pointer to the callback functions.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### E_DjiGimbalCalibrationStage

Gimbal calibration.

```c
typedef enum {
    DJI_GIMBAL_CALIBRATION_STAGE_COMPLETE = 0,       Gimbal calibration succeeded
    DJI_GIMBAL_CALIBRATION_STAGE_PROCRESSING = 1,    Gimbal calibration in progress
    DJI_GIMBAL_CALIBRATION_STAGE_FAILED = 3,         Gimbal calibration failed
} E_DjiGimbalCalibrationStage;
```

### E_DjiGimbalAxis

Gimbal axis.

```c
typedef enum {
    DJI_GIMBAL_AXIS_PITCH = 0,    Pitch axis
    DJI_GIMBAL_AXIS_ROLL = 1,     Roll axis
    DJI_GIMBAL_AXIS_YAW = 2,      Yaw axis
} E_DjiGimbalAxis;
```

### E_DjiGimbalResetMode

Gimbal reset mode.

```c
typedef enum {
    DJI_GIMBAL_RESET_MODE_YAW = 1,                             Yaw axis reset: resets the gimbal yaw axis angle to the sum of the aircraft yaw axis angle and the gimbal yaw axis fine-tune angle
    DJI_GIMBAL_RESET_MODE_PITCH_AND_YAW = 3,                   Pitch and yaw axis reset: resets the gimbal pitch axis angle to the fine-tune angle, and resets the gimbal yaw axis angle to the sum of the aircraft yaw axis angle and the gimbal yaw axis fine-tune angle
    DJI_GIMBAL_RESET_MODE_PITCH_ONLY = 4,                      Reset pitch axis only
    DJI_GIMBAL_RESET_MODE_ROLL_ONLY = 5,                       Reset roll axis only
    DJI_GIMBAL_RESET_MODE_YAW_ONLY = 6,                        Reset yaw axis only
    DJI_GIMBAL_RESET_MODE_PITCH_DOWNWARD_UPWARD_AND_YAW = 11,  Reset the gimbal yaw and pitch axes. Resets the yaw axis angle to the sum of the aircraft yaw axis and fine-tune angle. Resets the pitch axis to the sum of -90° and the fine-tune angle (gimbal mounted downward), or the sum of 90° and the fine-tune angle (gimbal mounted upward)
    DJI_GIMBAL_RESET_MODE_PITCH_DOWNWARD_UPWARD = 12,          Reset the gimbal pitch axis to the sum of -90° and the fine-tune angle (gimbal mounted downward), or the sum of 90° and the fine-tune angle (gimbal mounted upward)
} E_DjiGimbalResetMode;
```

### T_DjiGimbalSystemState

Gimbal state.

```c
typedef struct {
    bool resettingFlag;                                              Gimbal is resetting
    bool mountedUpward;                                              Gimbal mounted upward
    bool blockingFlag;                                               Gimbal is stuck
    bool pitchRangeExtensionEnabledFlag;                             Pitch axis angle range extension enabled
    E_DjiGimbalMode gimbalMode;                                      Gimbal control mode
    T_DjiAttitude3d fineTuneAngle;                                   Gimbal fine-tune angle, unit: 0.1 degree
    T_DjiGimbalControllerSmoothFactor smoothFactor;                  Gimbal smoothing factor
    T_DjiGimbalControllerMaxSpeedPercentage maxSpeedPercentage;      Gimbal maximum speed percentage
} T_DjiGimbalSystemState;
```

### T_DjiGimbalCalibrationState

Gimbal calibration state.

```c
typedef struct {
    bool calibratingFlag;                                    Gimbal is calibrating
    bool lastCalibrationResult;                              Result of the last successful gimbal calibration
    uint8_t currentCalibrationProgress;                      Current gimbal calibration progress, range: 0–100
    E_DjiGimbalCalibrationStage currentCalibrationStage;     Current gimbal calibration stage and result. For detailed information during calibration, see DJI_GIMBAL_CALIBRATION_STAGE_PROCRESSING. When the gimbal is not calibrating, the detailed information is the result of the last calibration
} T_DjiGimbalCalibrationState;
```

### T_DjiGimbalRotationProperty

Properties of gimbal rotation commands.

```c
typedef struct {
    struct {
        bool pitch;    Ignore pitch axis rotation command
        bool roll;     Ignore roll axis rotation command
        bool yaw;      Ignore yaw axis rotation command
    } rotationValueInvalidFlag;    Specifies which axes of the gimbal should ignore rotation commands

    union {
        struct {
            uint16_t actionTime;    Time for the gimbal to rotate to the target angle, unit: 0.01s
        } relativeAngleRotation;    Relative angle control

        struct {
            uint16_t actionTime;         Time for the gimbal to rotate to the target angle, unit: 0.01s
            bool jointAngleValid;        Joint angle valid flag, specifying whether jointAngle is valid in absolute angle control
            T_DjiAttitude3d jointAngle;  Gimbal joint angle, unit: 0.1 degree. If jointAngleValid is false, the specified joint angle is invalid and should be ignored. If the joint angle is valid, users should ensure the gimbal's target joint angle is approximately the same as the specified value
        } absoluteAngleRotation;    Absolute angle control
    };
} T_DjiGimbalRotationProperty;
```

### T_DjiGimbalCommonHandler

- Function: Collection of gimbal control callback functions.

Construct callback functions for gimbal control based on the functions in this struct, including:
* Get the current state of the gimbal
* Get the current attitude of the gimbal
* Get the gimbal calibration state
* Get the gimbal rotation speed
* Get the gimbal joint angle
* Rotate the gimbal
* Start gimbal calibration
* Set gimbal smoothing factor
* Enable or disable pitch axis Euler angle extension
* Set gimbal maximum speed percentage
* Restore gimbal settings
* Set gimbal mode
* Reset gimbal parameters
* Fine-tune gimbal angle

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, camera payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {

    @brief Callback function to get the current gimbal state
    @param systemState: Pointer to the memory space for storing the gimbal state
    @return Execution result
    T_DjiReturnCode (*GetSystemState)(T_DjiGimbalSystemState *systemState);

    @brief Callback function to get the current gimbal attitude
    @param attitudeInformation: Pointer to the memory space for storing gimbal attitude information
    @return Execution result
    T_DjiReturnCode (*GetAttitudeInformation)(T_DjiGimbalAttitudeInformation *attitudeInformation);

    @brief Callback function to get the gimbal calibration state
    @param calibrationState: Pointer to the memory space for storing the gimbal calibration state
    @return Execution result
    T_DjiReturnCode (*GetCalibrationState)(T_DjiGimbalCalibrationState *calibrationState);

    @brief Callback function to rotate the gimbal, triggered when a module controls the gimbal
    @note In some scenarios, since this callback function may be called at a high frequency (e.g., 200Hz), please keep the execution time short
    @param rotationMode: Gimbal control mode
    @param rotationProperty: Properties of the gimbal rotation
    @param rotationValue: Gimbal rotation angle, unit: 0.1 degree (if the gimbal control mode is DJI_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE or DJI_GIMBAL_ROTATION_MODE_ABSOLUTE_ANGLE), 0.1 degree/s (if the gimbal control mode is DJI_GIMBAL_ROTATION_MODE_SPEED)
    @return Execution result
    T_DjiReturnCode (*Rotate)(E_DjiGimbalRotationMode rotationMode,
        T_DjiGimbalRotationProperty rotationProperty,
        T_DjiAttitude3d rotationValue);

    @brief Start gimbal calibration
    @note The maximum gimbal calibration time is 120s. After this time, DJI Pilot or mobile apps developed with MSDK will consider the gimbal calibration as failed
    @return Execution result
    T_DjiReturnCode (*StartCalibrate)(void);

    @brief Set gimbal smoothing factor
    @param smoothingFactor: Smoothing factor. The larger this value, the smaller the gimbal acceleration. Maximum gimbal rotation acceleration = 10000 × (0.8 ^ (1 + X)) deg/s^2 (where X is the smoothing factor), range: 0–30
    @param axis: Specifies the axis of the gimbal to set the smoothing factor for
    @return Execution result
    T_DjiReturnCode (*SetControllerSmoothFactor)(uint8_t smoothingFactor, E_DjiGimbalAxis axis);

    @brief Callback function to enable or disable pitch axis Euler angle extension
    @details After enabling the pitch axis angle range extension, the gimbal pitch axis Euler angle limit can be set to the default limit or the extended limit
    @param enabledFlag: Enable or disable the pitch axis Euler angle extension function
    @return Execution result
    T_DjiReturnCode (*SetPitchRangeExtensionEnabled)(bool enabledFlag);

    @brief Set gimbal maximum speed percentage
    @param maxSpeedPercentage: Set the gimbal maximum speed (range: 1–100). Actual maximum gimbal rotation speed = default maximum speed × maximum speed percentage
    @param axis: Specifies the axis of the gimbal to set the maximum speed percentage for
    @return Execution result
    T_DjiReturnCode (*SetControllerMaxSpeedPercentage)(uint8_t maxSpeedPercentage, E_DjiGimbalAxis axis);

    @brief Restore gimbal settings
    @return Execution result
    T_DjiReturnCode (*RestoreFactorySettings)(void);

    @brief Callback function to set gimbal mode
    @param mode: Gimbal mode
    @return Execution result
    T_DjiReturnCode (*SetMode)(E_DjiGimbalMode mode);

    @brief Callback function to reset gimbal parameters
    @note Resetting gimbal parameters will interrupt gimbal operation
    @param mode: Gimbal reset mode
    @return Execution result
    T_DjiReturnCode (*Reset)(E_DjiGimbalResetMode mode);

    @brief Fine-tune gimbal angle
    @param fineTuneAngle: Fine-tune value, unit: 0.1 degree. Values greater than 0 indicate rotation toward the positive direction of the body coordinate system
    @return Execution result
    T_DjiReturnCode (*FineTuneAngle)(T_DjiAttitude3d fineTuneAngle);

    @brief Callback function to get gimbal rotation speed
    @note After calling this function, the user can obtain the gimbal rotation speed within 20 ms (50 Hz)
    @param rotationSpeed: Pointer to the memory space for storing gimbal rotation speed, using body coordinate system, unit: 0.1 degree/s
    @return Execution result
    T_DjiReturnCode (*GetRotationSpeed)(T_DjiAttitude3d *rotationSpeed);

    @brief Callback function to get gimbal joint angle
    @param jointAngle: Pointer to the memory space for storing the gimbal joint angle, unit: 0.1 degree
    @return Execution result
    T_DjiReturnCode (*GetJointAngle)(T_DjiAttitude3d *jointAngle);
} T_DjiGimbalCommonHandler;
```
