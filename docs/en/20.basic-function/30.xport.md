
## Overview

This document describes the function prototypes and data type definitions in the X-Port function module header file `dji_xport.h`. This module is used to control the DJI X-Port standard gimbal. Developers can use this module to implement X-Port mode switching, rotation control, limit angle settings, reset, state subscription, and other functions, to fully integrate payload devices developed based on X-Port with the DJI flight platform.

::: tip Note:
- Only payload devices developed using X-Port can use `dji_xport.h`. If developing payload devices using SkyPort, please use <a href="./gimbal.html">dji_gimbal.h</a>.
- For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### DjiXPort_RotateSync

- Function: Rotate X-Port.

::: tip Note:
* The maximum execution time of this interface may exceed 600ms.
* In PSDK_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE or PSDK_GIMBAL_ROTATION_MODE_ABSOLUTE_ANGLE mode, the rotation range of the yaw axis is [-1800, 1800]. The sign of the X-Port rotation angle does not determine the rotation direction of X-Port.
* The reachable angle of X-Port is mainly affected by the X-Port rotation angle limits and the limit buffer zone.
* When X-Port is mounted on top of the aircraft, the range of achievable rotation angles may differ significantly from when it is mounted on the underside gimbal bracket of the aircraft.
* When X-Port exceeds the limit angle, X-Port will return an error value or stay within the limit buffer zone.
* The rotation speed and rotation range of X-Port are limited by the maximum rotation speed and maximum acceleration. The maximum acceleration of X-Port rotation is limited by the gimbal rotation smoothness. The maximum rotation speed of X-Port is limited by the X-Port default maximum speed (90 deg/s) and the maximum speed percentage. For details, please refer to SetControllerSmoothFactor() and SetControllerMaxSpeedPercentage().
* PSDK only supports developers to control the pitch and yaw axes of X-Port.
* To prevent interrupting the rotation of X-Port, X-Port will not respond to rotation commands sent by the user during the processes of control parameter auto-tuning, coaxiality detection, balance detection, and reset.
* The effective control time of X-Port is 500ms. If X-Port does not receive a rotation command within 500ms, X-Port will not be able to rotate.
:::

```c
T_DjiReturnCode DjiXPort_RotateSync(E_DjiGimbalRotationMode rotationMode,
                                    T_DjiGimbalRotationProperty rotationProperty, T_DjiAttitude3d rotationValue);
```

- Parameters
  - rotationMode: Control mode of X-Port.
  - rotationProperty: Properties of the X-Port rotation command.
  - rotationValue: Value of the gimbal rotation command. When the rotation mode of X-Port is PSDK_GIMBAL_ROTATION_MODE_RELATIVE_ANGLE or PSDK_GIMBAL_ROTATION_MODE_ABSOLUTE_ANGLE, the unit is 0.1 deg; when the rotation mode of X-Port is PSDK_GIMBAL_ROTATION_MODE_SPEED, the unit is 0.1 deg/s.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiXPort_ReleaseControlPermissionSync

- Function: Release the control permission of X-Port.

::: tip Note:
* The execution time of this interface may exceed 600ms.
* When an application developed based on PSDK controls X-Port, it will acquire the control permission of X-Port. After sending the control command, please call this interface to release the control permission of X-Port so that other modules (such as DJI Pilot or the remote controller) can control X-Port.
* During the processes of parameter auto-tuning, coaxiality detection, and balance detection, the release control permission command will not be responded to.
:::

```c
T_DjiReturnCode DjiXPort_ReleaseControlPermissionSync(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiXPort_SetSpeedConversionFactor

- Function: Set the X-Port gimbal speed conversion factor.

::: tip Note:
* Set the X-Port gimbal speed conversion factor in speed control mode from the Joystick and mobile App.
* Actual motion speed = Max_speed x Factor, Factor <= 1. Users can set the X-Port speed conversion factor according to actual needs. It is recommended to set the speed conversion factor to the reciprocal of the zoom multiplier.
* Max_speed (maximum speed of X-Port) = default maximum speed (90 deg/s) x maximum speed percentage.
* This parameter will take effect within 100ms.
:::

```c
T_DjiReturnCode DjiXPort_SetSpeedConversionFactor(float factor);
```

- Parameters
  - factor: Speed conversion factor (<= 1.0).
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>


## Data Type Definitions

### E_DjiXPortLimitAngleCategory

X-Port angle limit category.

```c
typedef enum {
    DJI_XPORT_LIMIT_ANGLE_CATEGORY_ROLL_JOINT_ANGLE = 0,              Roll axis joint angle limit
    DJI_XPORT_LIMIT_ANGLE_CATEGORY_PITCH_JOINT_ANGLE = 1,             Pitch axis joint angle limit
    DJI_XPORT_LIMIT_ANGLE_CATEGORY_PITCH_EULER_ANGLE = 2,             Pitch axis Euler angle limit (in the ground coordinate system)
    DJI_XPORT_LIMIT_ANGLE_CATEGORY_PITCH_EULER_ANGLE_EXTENSION = 3,   Extended pitch axis Euler angle limit (in the ground coordinate system). When using this function, please enable the extended pitch axis angle limit function
    DJI_XPORT_LIMIT_ANGLE_CATEGORY_YAW_JOINT_ANGLE = 4,               Yaw axis joint angle limit
} E_DjiXPortLimitAngleCategory;
```

### T_DjiXPortLimitAngle

Data structure for angle limits.

```c
typedef struct {
    int16_t upperLimit;    Upper limit of the angle, unit: 0.1 degree
    int16_t lowerLimit;    Lower limit of the angle, unit: 0.1 degree
} T_DjiXPortLimitAngle;
```

### DjiReceiveXPortSystemStateCallback

- Function: Callback function for receiving X-Port system state.

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, camera payload device disconnection, and infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef T_DjiReturnCode (*DjiReceiveXPortSystemStateCallback)(T_DjiGimbalSystemState systemState);
```

- Parameters
  - systemState: State of the X-Port system.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
