


:::warning Note:
* DJI has stopped the development of **PSDK V2.x.x** and SkyPort on **October 21, 2021**. It is recommended to use **PSDK V3.x.x** for payload development. For PSDK V2.x.x content, please refer to the [legacy documentation](https://developer.dji.com/cn/document/26cd55ae-ef09-4463-b941-d6bb2bb98461).
* SkyPort only supports **PSDK V1.x.x**. If you are still using **PSDK V1.x.x** and **SkyPort** for payload development, please use the [PSDK V1.x.x](https://terra-1-g.djicdn.com/71a7d383e71a4fb8887a310eb746b47f/psdk/payload-sdk-doc-1.0.zip) documentation.
:::

To support developers in creating payload devices that can be mounted on DJI drones, DJI provides a software interface system centered around PSDK, along with hardware components such as [X-Port Standard Gimbal](https://store.dji.com/cn/product/dji-x-port), [SkyPort V3 Adapter](https://store.dji.com/cn/product/dji-skyport-v3-adapter-set?vid=192891), and [E-Port V2 Coaxial Cable](https://store.dji.com/cn/product/dji-e-port-v2-coaxial-cable-kit?vid=192711), helping developers more efficiently utilize **resources** such as power, communication links, and status information on DJI drones. Based on industry application requirements, developers can leverage the functional interfaces provided by PSDK, combined with specific structural design, hardware design, software logic implementation, and algorithm optimization, to develop payload devices such as **automated inspection systems**, **infrared cameras**, **surveying cameras**, **multispectral cameras**, **loudspeakers**, **searchlights**, and more for various specialized fields.

## Key Features
* Developed in C language
* Supports mainstream embedded systems such as Linux and RTOS
* Modular design approach for easy cross-platform porting
