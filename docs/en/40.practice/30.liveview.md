<table style="text-align:left;border:none">
    <tr>
      <td>Function:Start the FPV or Camera H264 Stream by selected position.</td>  
      <td>product：all</td>
    </tr>
</table>


```c
T_DjiReturnCode DjiLiveview_StartH264Stream(E_DjiLiveViewCameraPosition position, E_DjiLiveViewCameraSource source,
                                            DjiLiveview_H264Callback callback);
```

<font color="#AAA">Parameter</font>   
<br/><font color="#70BF41">position</font>：point out which camera to output the H264 stream
<br/><font color="#70BF41">source</font>：point out which sub camera to output the H264 stream   
<br/><font color="#70BF41">callback</font>：callback function that is called in a callback thread when a new h264 frame is received

<br/>The details for the return code please refer to: <a href="../core/dji-error.html">DjiErrorCode</a>
