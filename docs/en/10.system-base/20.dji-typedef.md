

## Overview

This document describes the macro definitions and data type definitions in the PSDK public data type header file `dji_typedef.h`. This header file defines the basic data types shared across all PSDK modules, including coordinate system definitions, aircraft type enumerations, camera type enumerations, gimbal mode enumerations, channel address enumerations, etc. It serves as the foundational dependency for all PSDK functional modules.

### DJI_DATA_SUBSCRIPTION_TOPIC
Data subscription topic combination macro that combines the subscription module index and topic code into a single uint32 topic value.
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC(subscriptionModule, topicCode) \
    (uint32_t)\
    (((((uint32_t)(subscriptionModule)) << (DJI_SUBSCRIPTION_MODULE_INDEX_OFFSET)) & (DJI_SUBSCRIPTION_MODULE_INDEX_MASK)) | \
    ((((uint32_t)(topicCode)) << (DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET)) & (DJI_SUBSCRIPTION_TOPIC_CODE_MASK)))
```

### DJI_DATA_SUBSCRIPTION_TOPIC_GET_MODULE
Extracts the subscription module index from a combined topic value.
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC_GET_MODULE(topic) \
    ((uint32_t)((topic & DJI_SUBSCRIPTION_MODULE_INDEX_MASK) >> DJI_SUBSCRIPTION_MODULE_INDEX_OFFSET))
```

### DJI_DATA_SUBSCRIPTION_TOPIC_GET_CODE
Extracts the topic code from a combined topic value.
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC_GET_CODE(topic) \
    ((uint32_t)((topic & DJI_SUBSCRIPTION_TOPIC_CODE_MASK) >> DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET))
```

## Callback Functions

### DjiReceiveDataOfTopicCallback

- Function: Callback function for receiving subscription topic data.

::: tip Note:
Users must not perform blocking operations or functions within the callback function, as this will block the PSDK root thread, causing slow system response, payload device disconnection, or infinite loops.
:::

```c
typedef T_DjiReturnCode (*DjiReceiveDataOfTopicCallback)(const uint8_t *data, uint16_t dataSize,
                                                         const T_DjiDataTimestamp *timestamp);
```

- Parameters
  - data: Pointer to the topic data. Users need to cast this pointer to the corresponding topic data structure pointer to access individual fields.
  - dataSize: Size of the memory space pointed to by the data pointer, equal to the size of the data structure corresponding to the topic.
  - timestamp: Pointer to the timestamp corresponding to this data. M300 RTK uses the flight controller power-on timestamp, while M30/M30T uses the payload local timestamp.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
