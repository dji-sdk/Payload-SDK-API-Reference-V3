


## Overview

This document describes the function prototypes and data type definitions in the PSDK core module header file `dji_core.h`. This module serves as the core initialization entry point of PSDK. Developers need to use this module to complete basic operations such as SDK initialization, application information configuration, firmware version setting, and serial number setting. All other function modules can only be used after the core module initialization is complete.

## Function Prototypes

### DjiCore_Init

- Function: Initialize the Payload SDK kernel in blocking mode.

::: tip Note:
* The calling order of this interface is critical. It must be called after the console/OSAL handler/HAL handler functions have been registered, and the initialization must be completed before calling any other function module interfaces. Please fill in the developer information correctly to ensure successful initialization. For details, please refer to the tutorial "PSDK Initialization".
* This function will not return until the correct aircraft type and PSDK adapter type are obtained. This logic ensures that the aircraft and PSDK adapter have started normally before function modules and user programs run. The typical execution time of this function is 2~4 seconds.
:::

```c
T_DjiReturnCode DjiCore_Init(const T_DjiUserInfo *userInfo);
```

- Parameters
  - userInfo: Pointer to the PSDK application information.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetAlias

- Function: Set an alias for the DJI application or product.

::: tip Note:
* The correct DJI APP name obtained from the DJI SDK developer website still needs to be passed to the DjiCore_Init() interface. The DJI APP name will be used for binding and verification.
* The alias will take effect after a brief delay, no longer than 1 second. Once set successfully, the alias will be displayed in DJI Pilot.
:::

```c
T_DjiReturnCode DjiCore_SetAlias(const char *productAlias);
```

- Parameters
  - productAlias: Pointer to the product alias string, null-terminated, with a maximum length of 31 characters. If the alias string length exceeds 31 characters, it will be truncated before being passed in.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetFirmwareVersion

- Function: Set a custom firmware version number for the DJI application or product.

::: tip Note:
The payload firmware version number will always be displayed on the DJI Pilot payload settings screen.
:::

```c
T_DjiReturnCode DjiCore_SetFirmwareVersion(T_DjiFirmwareVersion version);
```

- Parameters
  - version: Custom firmware version number.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetSerialNumber

- Function: Set a custom serial number for the DJI application or product.

::: tip Note:
The payload custom serial number will always be displayed on the DJI Pilot payload settings screen.
:::

```c
T_DjiReturnCode DjiCore_SetSerialNumber(const char *productSerialNumber);
```

- Parameters
  - productSerialNumber: Custom serial number string, with a length not exceeding 32 bytes.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_ApplicationStart

- Function: Notify the Payload SDK kernel that the application has started.

::: tip Note:
The calling order of this interface requires special attention. It must be called after all function module initialization and callback registration interfaces have been called.
:::

```c
T_DjiReturnCode DjiCore_ApplicationStart(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_DeInit

- Function: Deinitialize the Payload SDK kernel in blocking mode.

```c
T_DjiReturnCode DjiCore_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetSdkDeviceType

- Function: Set the SDK sub-device type.

::: tip Note:
* This interface is only applicable to payloads that need to report a specific SDK device type and must be called before `DjiCore_Init`.
* Currently, it is only applicable to scenarios where the payload type is transport box (DJI_SDK_DEVICE_TYPE_TRANSPORT_BOX).
:::

```c
T_DjiReturnCode DjiCore_SetSdkDeviceType(E_DjiSdkDeviceType type);
```

- Parameters
  - type: The device type to set. See the <a href="../system-base/dji-typedef.html#e-djisdkdevicetype">E_DjiSdkDeviceType</a> enum for available values.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### T_DjiUserInfo

Describes the payload application information developed based on PSDK.

::: tip Note:
Please confirm that the appName, appId, appKey, and other information are consistent with the developer website. For more information, please visit the [User Center](https://developer.dji.com/user/apps/#all).
:::

```c
typedef struct {
    char appName[32];           PSDK application name, null-terminated. Obtained from the developer website
    char appId[16];             PSDK application ID. Obtained from the developer website
    char appKey[32];            PSDK application key. Obtained from the developer website
    char appLicense[512];       PSDK application license. Obtained from the developer website
    char developerAccount[64];  Developer account email, null-terminated. Obtained from the developer website, must correspond to the application information
    char baudRate[7];           Communication serial port baud rate
} T_DjiUserInfo;
```
