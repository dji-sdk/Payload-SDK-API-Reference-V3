
## Overview

This document describes the function prototypes and data type definitions in the platform porting module header file `dji_platform.h`. This module defines the abstraction layer interfaces between PSDK and different hardware platforms and operating systems. Developers need to implement the adaptation of UART, USB Bulk, Network, I2C, OSAL, FileSystem, and Socket interfaces according to their own platform, and register the implementations into the SDK through registration functions.

## Function Prototypes

### DjiPlatform_RegHalUartHandler

- Function: Register the HAL layer UART handler.

::: tip Note:
* Before registering the callback functions for the HAL layer interface, please ensure the interface has been tested and works properly.
* Please call this interface during the application initialization phase to complete registration, otherwise subsequent functions will not work properly.
:::

```c
T_DjiReturnCode DjiPlatform_RegHalUartHandler(const T_DjiHalUartHandler *halUartHandler);
```

- Parameters
  - halUartHandler: Pointer to the platform HAL layer UART handler.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### T_DjiHalUartHandler

- Function: HAL layer UART interface callback function collection.

Construct callback functions for UART interface related functionalities based on the functions in this structure, including:
* Initialize UART interface
* Deinitialize UART interface
* Write data via UART
* Read data via UART
* Get UART connection status
* Get UART device information (for Eport V2 cable adapter, not required for other interface types)

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, disconnection, or infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {
    @brief Initialize UART interface
    @param uartNum: UART port number
    @param baudRate: Baud rate
    @param uartHandle: Pointer to memory space for storing the UART handle
    @return Execution result
    T_DjiReturnCode (*UartInit)(E_DjiHalUartNum uartNum, uint32_t baudRate, T_DjiUartHandle *uartHandle);

    @brief Deinitialize UART interface
    @param uartHandle: UART handle
    @return Execution result
    T_DjiReturnCode (*UartDeInit)(T_DjiUartHandle uartHandle);

    @brief Write data via UART
    @param uartHandle: UART handle
    @param buf: Pointer to the buffer containing data to be written
    @param len: Length of data to be written, unit: bytes
    @param realLen: Pointer to memory space for storing the actual written length
    @return Execution result
    T_DjiReturnCode (*UartWriteData)(T_DjiUartHandle uartHandle, const uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief Read data via UART
    @param uartHandle: UART handle
    @param buf: Pointer to the buffer for storing read data
    @param len: Expected data length to read, unit: bytes
    @param realLen: Pointer to memory space for storing the actual read length
    @return Execution result
    T_DjiReturnCode (*UartReadData)(T_DjiUartHandle uartHandle, uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief Get UART connection status
    @param uartNum: UART port number
    @param status: Pointer to memory space for storing the UART connection status
    @return Execution result
    T_DjiReturnCode (*UartGetStatus)(E_DjiHalUartNum uartNum, T_DjiUartStatus *status);

    @brief Get USB serial device information for direct aircraft connection, for Eport V2 cable adapter, not required for other interface types
    @param deviceInfo: Pointer to memory space for storing the UART device information
    @return Execution result
    T_DjiReturnCode (*UartGetDeviceInfo)(T_DjiHalUartDeviceInfo *deviceInfo);
} T_DjiHalUartHandler;
```

```c
} T_DjiFileSystemHandler;
```

### T_DjiSocketHandler

- Function: Socket interface callback function collection.

Construct callback functions for Socket interface related functionalities based on the functions in this structure, including:
* Create Socket
* Close Socket
* Bind address and port
* UDP send data
* UDP receive data
* TCP listen for connections
* TCP accept connection
* TCP connect to server
* TCP send data
* TCP receive data

::: tip Note:
To prevent blocking the PSDK main thread, which may cause slow program response, disconnection, or infinite loops, do not execute this function in a blocking manner within the callback function.
:::

```c
typedef struct {
    @brief Create Socket
    @param mode: Socket mode (UDP or TCP)
    @param socketHandle: Pointer to memory space for storing the Socket handle
    @return Execution result
    T_DjiReturnCode (*Socket)(E_DjiSocketMode mode, T_DjiSocketHandle *socketHandle);

    @brief Close Socket
    @param socketHandle: Socket handle
    @return Execution result
    T_DjiReturnCode (*Close)(T_DjiSocketHandle socketHandle);

    @brief Bind Socket to specified address and port
    @param socketHandle: Socket handle
    @param ipAddr: IP address string
    @param port: Port number
    @return Execution result
    T_DjiReturnCode (*Bind)(T_DjiSocketHandle socketHandle, const char *ipAddr, uint32_t port);

    @brief Send data via UDP
    @param socketHandle: Socket handle
    @param ipAddr: Destination IP address string
    @param port: Destination port number
    @param buf: Pointer to the buffer containing data to be sent
    @param len: Length of data to be sent, unit: bytes
    @param realLen: Pointer to memory space for storing the actual sent length
    @return Execution result
    T_DjiReturnCode (*UdpSendData)(T_DjiSocketHandle socketHandle, const char *ipAddr, uint32_t port,
                                   const uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief Receive data via UDP
    @param socketHandle: Socket handle
    @param ipAddr: Pointer to the buffer for storing the sender's IP address
    @param port: Pointer to memory space for storing the sender's port number
    @param buf: Pointer to the buffer for storing received data
    @param len: Expected data length to receive, unit: bytes
    @param realLen: Pointer to memory space for storing the actual received length
    @return Execution result
    T_DjiReturnCode (*UdpRecvData)(T_DjiSocketHandle socketHandle, char *ipAddr, uint32_t *port,
                                   uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief TCP listen for connections
    @param socketHandle: Socket handle
    @return Execution result
    T_DjiReturnCode (*TcpListen)(T_DjiSocketHandle socketHandle);

    @brief TCP accept connection
    @param socketHandle: Socket handle
    @param ipAddr: Pointer to the buffer for storing the client's IP address
    @param port: Pointer to memory space for storing the client's port number
    @param outSocketHandle: Pointer to memory space for storing the new connection Socket handle
    @return Execution result
    T_DjiReturnCode (*TcpAccept)(T_DjiSocketHandle socketHandle, char *ipAddr, uint32_t *port,
                                 T_DjiSocketHandle *outSocketHandle);

    @brief TCP connect to server
    @param socketHandle: Socket handle
    @param ipAddr: Server IP address string
    @param port: Server port number
    @return Execution result
    T_DjiReturnCode (*TcpConnect)(T_DjiSocketHandle socketHandle, const char *ipAddr, uint32_t port);

    @brief Send data via TCP
    @param socketHandle: Socket handle
    @param buf: Pointer to the buffer containing data to be sent
    @param len: Length of data to be sent, unit: bytes
    @param realLen: Pointer to memory space for storing the actual sent length
    @return Execution result
    T_DjiReturnCode (*TcpSendData)(T_DjiSocketHandle socketHandle,
                                   const uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief Receive data via TCP
    @param socketHandle: Socket handle
    @param buf: Pointer to the buffer for storing received data
    @param len: Expected data length to receive, unit: bytes
    @param realLen: Pointer to memory space for storing the actual received length
    @return Execution result
    T_DjiReturnCode (*TcpRecvData)(T_DjiSocketHandle socketHandle,
                                   uint8_t *buf, uint32_t len, uint32_t *realLen);
} T_DjiSocketHandler;
```
