

## Overview

This document describes the macro definitions in the PSDK version information header file `dji_version.h`. This header file defines the current PSDK version number information. Developers can use these macros to obtain the SDK's major version number, minor version number, patch version number, and other information.

## Version Macros

### DJI_VERSION_MAJOR

PSDK major version number, indicating incompatible API changes. Value range: 0–99.

```c
#define DJI_VERSION_MAJOR     3
```

### DJI_VERSION_MINOR

PSDK minor version number, indicating changes when new features are added in a backward-compatible manner. Value range: 0–99.

```c
#define DJI_VERSION_MINOR     16
```

### DJI_VERSION_MODIFY

PSDK patch version number, indicating backward-compatible bug fix changes. Value range: 0–99.

```c
#define DJI_VERSION_MODIFY    0
```

### DJI_VERSION_BETA

PSDK Beta version information. The value is 0 for official releases. Value range: 0–255.

```c
#define DJI_VERSION_BETA      0
```

### DJI_VERSION_BUILD

PSDK build version number, indicating changes when a build is triggered. Value range: 0–65535.

```c
#define DJI_VERSION_BUILD     2338
```
