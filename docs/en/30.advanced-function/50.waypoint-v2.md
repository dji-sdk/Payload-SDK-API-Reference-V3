
## Overview

This document describes the function prototypes and data type definitions in the Waypoint V2 waypoint mission module header files `dji_waypoint_v2.h` and `dji_waypoint_v2_type.h`. This module is used for planning and executing waypoint flight missions. Developers can use this module to upload, start, stop, pause, and resume waypoint missions, as well as configure camera, gimbal, and flight control actions between waypoints.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### E_DJIWaypointV2MissionFinishedAction

Actions to be taken when the waypoint mission is finished.

```c
typedef enum {
    DJI_WAYPOINT_V2_FINISHED_NO_ACTION,                 No further action, the aircraft can be controlled by the remote controller
    DJI_WAYPOINT_V2_FINISHED_GO_HOME,                   Goes home when finished, lands directly if within 20 meters of the home point
    DJI_WAYPOINT_V2_FINISHED_AUTO_LANDING,              The aircraft will land automatically at the last waypoint
    DJI_WAYPOINT_V2_FINISHED_GO_TO_FIRST_WAYPOINT,      The aircraft will go back to the first waypoint and hover
    DJI_WAYPOINT_V2_FINISHED_CONTINUE_UNTIL_STOP,       The aircraft will hover at the final waypoint without ending the mission until stopMission is called
} E_DJIWaypointV2MissionFinishedAction;
```

### E_DJIWaypointV2FlightPathMode

Waypoint flight path mode, determines how the aircraft flies to and through the waypoint.

```c
typedef enum {
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_ALONG_CURVE,                     Go to the waypoint along a curve and fly past the waypoint
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_ALONG_CURVE_AND_STOP,            Go to the waypoint along a curve and stop at the waypoint
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_IN_STRAIGHT_AND_STOP,            Go to the waypoint along a straight line and stop at the waypoint
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_COORDINATE_TURN,                             Fly from the previous waypoint to the next along a smooth curve without stopping, adhering to dampingDistance
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_FIRST_POINT_ALONG_STRAIGHT_LINE,       Go to the first waypoint along a straight line, only valid for the first waypoint
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_STRAIGHT_OUT,                                Straight exit from the last waypoint, only valid for the last waypoint
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_UNKNOWN = 0xFF,                              Unknown flight path mode
} E_DJIWaypointV2FlightPathMode;
```

### U_DjiWaypointV2EventData

Union of mission event data, interpreted based on the event type in T_DjiWaypointV2MissionEventPush.

```c
typedef union {
    uint8_t interruptReason;       Event 0x01: Mission interrupt reason (0x00: RC triggered interrupt)
    uint8_t recoverProcess;        Event 0x02: Recovery process status (0x00: Finished recover from pause, 0x10: Start recover from break, 0x11: Finished recover from break, 0x12: Failed to recover from break)
    uint8_t exitReason;            Event 0x03: Mission exit reason (0x00: Finished successfully, 0x10: User triggered stop, 0x20-0x26: Various abnormal exit reasons)
    uint16_t waypointIndex;        Event 0x10: Index of the reached waypoint
    struct T_DjiWaypointV2MissionExecEvent {
        uint8_t currentMissionExecTimes;              Current number of mission executions completed
        uint8_t finishedAllMissExecTimes: 1;          0: Not all executions completed, 1: All completed
        uint8_t reserved: 7;                          Reserved field
    } T_DjiWaypointV2MissionExecEvent;                Event 0x11: Mission execution event
    uint8_t avoidState;                               Event 0x12: Obstacle avoidance state
    struct T_DjiWaypointV2ActionExecEvent {
        uint16_t actionId;                            Action ID
        uint8_t preActuatorState;                     Previous actuator state (0x00: Not mounted, 0x01: Idle, 0x02: Running, 0x03: Paused)
        uint8_t curActuatorState;                     Current actuator state (0x00: Not mounted, 0x01: Idle, 0x02: Running, 0x03: Paused)
        uint32_t result;                              Error code
    } T_DjiWaypointV2ActionExecEvent;                 Event 0x30: Action execution event
} U_DjiWaypointV2EventData;
```
