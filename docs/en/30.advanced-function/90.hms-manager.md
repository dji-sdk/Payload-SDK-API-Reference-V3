
## Overview

This document describes the function prototypes and data type definitions in the HMS management module header file `dji_hms_manager.h`. This module is used to obtain the aircraft's Health Management System (HMS) information. Developers can use this module to register callback functions to receive HMS push data and monitor the health status of various aircraft components in real time.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiHmsManager_Init

- Function: Initialize the HMS management module.

::: tip Note:
Users should call this function before using HMS features.
:::

```c
T_DjiReturnCode DjiHmsManager_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiHmsManager_DeInit

- Function: Deinitialize the HMS management module.

```c
T_DjiReturnCode DjiHmsManager_DeInit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiHmsManager_RegHmsInfoCallback

- Function: Register a callback function to obtain HMS information.

::: tip Note:
Data is pushed at a frequency of 1 Hz.
:::

```c
T_DjiReturnCode DjiHmsManager_RegHmsInfoCallback(DjiHmsInfoCallback callback);
```

- Parameters
  - callback: HMS information callback function, see DjiHmsInfoCallback.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### T_DjiHmsInfo

HMS information structure, describing a single health management information entry.

```c
typedef struct {
    uint32_t errorCode;        Error code
    uint8_t componentIndex;    Component index
    uint8_t errorLevel;        Error level
} T_DjiHmsInfo;
```

### T_DjiHmsInfoTable

HMS information table structure, containing a collection of all HMS information entries.

```c
typedef struct {
    T_DjiHmsInfo *hmsInfo;     HMS information array pointer
    uint32_t hmsInfoNum;       Number of HMS information entries
} T_DjiHmsInfoTable;
```

### DjiHmsInfoCallback

- Function: HMS information callback function, used to receive push data from the aircraft's Health Management System.

```c
typedef T_DjiReturnCode (*DjiHmsInfoCallback)(T_DjiHmsInfoTable hmsInfoTable);
```

- Parameters
  - hmsInfoTable: HMS information table, see <a href="hms-manager.html#t-djihmsinfotable">T_DjiHmsInfoTable</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
