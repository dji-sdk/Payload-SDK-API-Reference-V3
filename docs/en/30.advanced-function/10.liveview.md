
## Overview

This document describes the function prototypes and data type definitions in the liveview module header file `dji_liveview.h`. This module is used to obtain real-time stream data from cameras on the aircraft. Developers can use this module to subscribe to H.264 video streams from specified camera positions and stream types, obtain decoded image data, and perform H.264 encoding, target recognition annotation, and other operations.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiLiveview_Init

- Function: Initialize the Liveview module.

::: tip Note:
The interface initialization must be performed after DjiCore_Init.
:::

```c
T_DjiReturnCode DjiLiveview_Init(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

```c
T_DjiReturnCode DjiLiveview_Deinit(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_StartH264Stream

- Function: Start FPV or camera H.264 stream at the selected position.

::: warning Note
This interface will no longer be maintained in future releases. It is recommended to use <a href="liveview.html#djiliveview-startstream">DjiLiveview_StartStream</a> instead.
:::

```c
T_DjiReturnCode DjiLiveview_StartH264Stream(E_DjiLiveViewCameraPosition position, E_DjiLiveViewCameraSource source,
                                            DjiLiveview_H264Callback callback);
```

- Parameters
  - position: Specifies the camera position for H.264 stream output.
  - source: Specifies the sub-camera source for H.264 stream output.
  - callback: Callback function invoked in the callback thread when a new H.264 frame is received.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_StartStream

- Function: Start FPV or camera stream at the selected position.

::: tip Note:
* This interface is compatible with the original <a href="liveview.html#djiliveview-starth264stream">DjiLiveview_StartH264Stream</a> interface. It can be used to obtain both H.264 and H.265 streams, and the stream encoding type is determined by the aircraft model.
* It is also recommended to use this interface when only the H.264 stream is needed.
:::

```c
T_DjiReturnCode DjiLiveview_StartStream(E_DjiLiveViewCameraPosition position, E_DjiLiveViewCameraSource source,
                                        DjiLiveview_H264Callback callback);
```

- Parameters
  - position: Specifies the camera position for stream output.
  - source: Specifies the sub-camera source for stream output.
  - callback: Callback function invoked in the callback thread when a new stream frame is received. See <a href="liveview.html#djiliveview-h264callback">DjiLiveview_H264Callback</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_EncodeAFrameToH264

- Function: Encode an image into H.264 stream.

::: tip Note:
* If target recognition related information is not needed, the metaData parameter can be set to NULL.
* This interface must be used after DjiLiveview_RegEncoderCallback.
* This interface is only supported on DJI Manifold 3.
:::

```c
T_DjiReturnCode DjiLiveview_EncodeAFrameToH264(const uint8_t *buf, uint32_t len, T_DjiLiveviewImageInfo imageInfo,
                                               T_DjiLiveViewStandardMetaData *metaData);
```

- Parameters
  - buf: Raw image data.
  - len: Image data length.
  - imageInfo: Image information, see <a href="liveview.html#t-djiliveviewimageinfo">T_DjiLiveviewImageInfo</a>.
  - metaData: Result information of image target recognition, see <a href="liveview.html#t-djiliveviewstandardmetadata">T_DjiLiveViewStandardMetaData</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_RegUserAiTargetLableList

- Function: Register user-defined target recognition label list.

::: tip Note:
* After registration, the key-value pairs of labels and indices are recorded in Pilot for parsing metaData and displaying labels when rendering target boxes.
* This interface is only supported on DJI Manifold 3.
:::

```c
T_DjiReturnCode DjiLiveview_RegUserAiTargetLableList(uint8_t lableCount, const char *labels[]);
```

- Parameters
  - lableCount: Number of labels.
  - labels: Array of label strings.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

```c
    DJI_LIVEVIEW_CAMERA_POSITION_NO_3 = DJI_MOUNT_POSITION_PAYLOAD_PORT_NO3,    Payload mount position 3
    DJI_LIVEVIEW_CAMERA_POSITION_FPV = 7                                        FPV camera
```

```c
typedef enum {
    DJI_LIVEVIEW_OBJ_STATE_INVALID = 0,                  Invalid state
    DJI_LIVEVIEW_OBJ_STATE_TRACKED = 1,                  Stable tracking state
    DJI_LIVEVIEW_OBJ_STATE_VISION_BEACON_FUSIONED = 2,   Vision-beacon fusion state
```

### T_DjiLiveViewTarget2dBox

Bounding box information struct for target recognition results.

```c
typedef struct {
    uint16_t cx;            Center X coordinate, unit: 1/10000 screen width
    uint16_t cy;            Center Y coordinate, unit: 1/10000 screen height
    uint16_t w;             Box width, unit: 1/10000 screen width
    uint16_t h;             Box height, unit: 1/10000 screen height
    uint32_t distance;      Distance, unit: millimeters
} T_DjiLiveViewTarget2dBox;
```

### T_DjiLiveViewBoundingBox

Target recognition bounding box information struct.

```c
typedef struct {
    uint16_t id;        Target ID
    uint8_t type;       Target type, can be E_DjiLiveViewTargetObjectType enum value or user-defined value
    uint8_t state;      Target state, see E_DjiLiveViewTargetObjectState enum
    T_DjiLiveViewTarget2dBox box;   Target box information
} T_DjiLiveViewBoundingBox;
```

### DjiLiveview_H264Callback

- Function: H.264 stream data callback function, used to receive H.264 video frame data from the specified camera.

```c
typedef void (*DjiLiveview_H264Callback)(E_DjiLiveViewCameraPosition position, const uint8_t *buf, uint32_t len);
```

- Parameters
  - position: Camera position corresponding to the stream.
  - buf: Pointer to the H.264 frame data buffer.
  - len: H.264 frame data length, unit: bytes.
- Return Value
  - None

### DjiLiveview_ImageCallback

- Function: Image data callback function, used to receive decoded image data from the specified camera.

```c
typedef void (*DjiLiveview_ImageCallback)(E_DjiLiveViewCameraPosition position, const uint8_t *buf,
                                        uint32_t len, T_DjiLiveviewImageInfo ImageInfo);
```

- Parameters
  - position: Camera position corresponding to the stream.
  - buf: Pointer to the image data buffer.
  - len: Image data length, unit: bytes.
  - ImageInfo: Image information, see <a href="liveview.html#t-djiliveviewimageinfo">T_DjiLiveviewImageInfo</a>.
- Return Value
  - None
