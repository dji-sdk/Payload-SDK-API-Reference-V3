

## Overview

This document describes the function prototypes and data type definitions in the network RTK module header file `dji_network_rtk.h`. This module is used to connect to network RTK services (NTRIP protocol) to provide high-precision differential positioning data for the aircraft. Developers can use this module to configure RTK service parameters, start/stop the service, and listen for service status.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiNetworkRtk_RegReceiveNetworkRtkStateCallback

- Function: Register a network RTK state callback function.

::: tip Note:
It is recommended to register before starting the service.
:::

```c
T_DjiReturnCode DjiNetworkRtk_RegReceiveNetworkRtkStateCallback(DjiReceiveNetworkRtkStateCallback callback);
```

- Parameters
  - callback: Pointer to the state callback function.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiNetworkRtk_StartService

- Function: Start the network RTK service.

::: tip Note:
* If the current RTK source is not a custom network source, you need to manually restart the device to switch the RTK source after the first call, then call this interface again after restart.
* DJI_REBOOTING state indicates that the device needs to be restarted.
* DJI_TRANSFER state indicates that data transfer has been established, but it does not guarantee that the RTK solution has converged.
:::

```c
T_DjiReturnCode DjiNetworkRtk_StartService(const T_DjiNetworkRtkServiceConfig *config);
```

- Parameters
  - config: Pointer to the network RTK service configuration, see <a href="network-rtk.html#t-djinetworkrtkserviceconfig">T_DjiNetworkRtkServiceConfig</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiNetworkRtk_StopService

- Function: Stop the network RTK service.

```c
T_DjiReturnCode DjiNetworkRtk_StopService(void);
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiNetworkRtkOnboardState

Network RTK state.

```c
typedef enum {
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_LOG_IN = 0,        Logging in
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_CONNECTING = 1,    Connecting
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_TRANSFER = 2,      Transferring data
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_RECONNECT = 3,     Reconnecting
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_BROKEN = 4,        Connection broken
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_STOPPING = 5,      Stopping
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_REBOOTING = 6      Rebooting
} E_DjiNetworkRtkOnboardState;
```

### T_DjiNetworkRtkServiceConfig

Network RTK service configuration.

```c
typedef struct {
    char account[16];        Account
    char password[64];       Password
    char host[64];           Server address, only IP is supported, domain names are not supported
    char port[6];            Port number
    char mountPoint[32];     Mount point
} T_DjiNetworkRtkServiceConfig;
```

### DjiReceiveNetworkRtkStateCallback

- Function: Network RTK state callback function prototype.

```c
typedef void (*DjiReceiveNetworkRtkStateCallback)(E_DjiNetworkRtkOnboardState state);
```

- Parameters
  - state: Current network RTK state, see <a href="network-rtk.html#e-djinetworkrtkonboardstate">E_DjiNetworkRtkOnboardState</a>.
- Return Value
  - None
