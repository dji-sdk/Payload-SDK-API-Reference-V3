

## Overview

This document describes the function prototypes and data type definitions in the point of interest (POI) orbit module header file `dji_interest_point.h`. This module is used to control the aircraft to orbit around a specified point of interest. Developers can use this module to set the point of interest location and orbit speed, and obtain the orbit mission state in real time.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Data Type Definitions

### E_DjiInterestPointActionState

Orbit mission action state.

```c
typedef enum {
    DJI_INTEREST_POINT_ACTION_STATE_NOT_STARTED = 0,    Not started
    DJI_INTEREST_POINT_ACTION_STATE_PAUSE = 1,          Paused
    DJI_INTEREST_POINT_ACTION_STATE_RUNNING = 2         Running
} E_DjiInterestPointActionState;
```

### T_DjiInterestPointMissionState

Orbit mission state.

```c
typedef struct {
    dji_f32_t curSpeed;                        Current orbit speed
    dji_f32_t radius;                          Orbit radius
    E_DjiInterestPointActionState state;       Current mission action state
} T_DjiInterestPointMissionState;
```

### T_DjiInterestPointSettings

Point of interest orbit configuration.

```c
typedef struct {
    dji_f64_t latitude;              Point of interest latitude, unit: degrees
    dji_f64_t longitude;             Point of interest longitude, unit: degrees
    dji_f32_t speed;                 Orbit speed
    uint8_t payloadCameraIndex;      Payload camera index, starting from 1
} T_DjiInterestPointSettings;
```

### InterestPointMissionStateCallback

- Function: Orbit mission state callback function prototype.

```c
typedef void (*InterestPointMissionStateCallback)(T_DjiInterestPointMissionState missionState);
```

- Parameters
  - missionState: Current orbit mission state.
- Return Value
  - None
