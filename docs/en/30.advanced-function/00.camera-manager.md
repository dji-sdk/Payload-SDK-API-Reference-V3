## Overview

This document describes the function prototypes and data type definitions in the camera management module header file `dji_camera_manager.h`. This module is used to control and manage DJI cameras installed on the aircraft. Developers can use this module to implement camera work mode switching, photo and video capture control, zoom and focus settings, exposure parameter adjustment, storage formatting, media file download, SD card encryption management, and other functions.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### DjiCameraManager_SetTapZoomMultiplier

- Function: Set the tap zoom multiplier of the camera at the specified mount position.

::: tip Note:
Tap-zoom uses a multiplier to change the zoom scale. The final zoom scale of TapZoom is: current zoom scale x multiplier.
:::

```c

```

- Parameters
  - position: Camera mount position.
  - tapZoomMultiplier: Multiplier range is [1,5]. When the multiplier is 1, the zoom will not change.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCameraManagerDownloadFileDataCallback

- Function: File download data callback function, used to receive downloaded file data.

```c
typedef T_DjiReturnCode (*DjiCameraManagerDownloadFileDataCallback)(T_DjiDownloadFilePacketInfo packetInfo,
                                                                    const uint8_t *data,
                                                                    uint16_t dataLen);
```

- Parameters
  - packetInfo: Packet information of the downloaded file, see <a href="camera-manager.html#t-djidownloadfilepacketinfo">T_DjiDownloadFilePacketInfo</a>.
  - data: Pointer to the downloaded file data buffer.
  - dataLen: Data length, unit: bytes.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
