## Overview

This document describes the function prototypes and data type definitions in the flight control module header file `dji_flight_controller.h`. This module is used to control the flight behavior of the aircraft. Developers can use this module to implement takeoff and landing, return-to-home control, Joystick virtual stick control, flight parameter settings, control authority management, and other functions.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### DjiFlightController_ArrestFlying

- Function: Emergency arrest flying.

::: tip Note:
* When the drone is on the ground, it will stop the motors and display "hms description" on the APP.
* When the drone is in the air, it will only display "hms description" on the APP.
* After using this interface, you need to call DjiFlightController_CancelArrestFlying to exit this state before the drone can fly again.
:::

```c

```

* If the ground is not suitable for landing, the user must manually control landing or force landing using the remote controller.
:::

```c

```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFlightController_StartForceLanding

::: tip Note:

* Warning: This may cause the aircraft to crash!

### DjiFlightController_SetGoHomeAltitude

- Function: Set the return-to-home altitude.

::: tip Note:
* If the drone's current altitude is higher than the return-to-home altitude setting, the drone will return at the current altitude. Otherwise, it will climb to the return-to-home altitude before executing the return operation.
* The return-to-home altitude setting range is 20m ~ 1500m.
:::

