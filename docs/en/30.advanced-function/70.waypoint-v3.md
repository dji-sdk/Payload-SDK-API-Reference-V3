
## Overview

This document describes the function prototypes and data type definitions in the Waypoint V3 waypoint mission module header file `dji_waypoint_v3.h`. This module is used for planning and executing waypoint flight missions via KMZ files. Developers can use this module to upload, execute, pause, resume, and stop route missions.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::


## Data Type Definitions

### E_DjiWaypointV3Action

Waypoint V3 mission action enumeration.

```c
typedef enum {
    DJI_WAYPOINT_V3_ACTION_START = 0,     Start mission
    DJI_WAYPOINT_V3_ACTION_STOP = 1,      Stop mission
    DJI_WAYPOINT_V3_ACTION_PAUSE = 2,     Pause mission
    DJI_WAYPOINT_V3_ACTION_RESUME = 3,    Resume mission
} E_DjiWaypointV3Action;
```

### E_DjiWaypointV3MissionState

Waypoint V3 aircraft current mission state enumeration.

```c
typedef enum {
    DJI_WAYPOINT_V3_MISSION_STATE_IDLE = 0,                Idle state
    DJI_WAYPOINT_V3_MISSION_STATE_PREPARE = 16,            Preparing state
    DJI_WAYPOINT_V3_MISSION_STATE_TRANS_MISSION = 32,      Mission transmitting
    DJI_WAYPOINT_V3_MISSION_STATE_MISSION = 48,            Mission executing
    DJI_WAYPOINT_V3_MISSION_STATE_BREAK = 64,              Mission interrupted
    DJI_WAYPOINT_V3_MISSION_STATE_RESUME = 80,             Mission resuming
    DJI_WAYPOINT_V3_MISSION_STATE_RETURN_FIRSTPOINT = 98,  Returning to first waypoint
} E_DjiWaypointV3MissionState;
```

### E_DjiWaypointV3ActionState

Waypoint V3 aircraft current action state enumeration.

```c
typedef enum {
    DJI_WAYPOINT_V3_ACTION_STATE_IDLE = 0,        Action idle state
    DJI_WAYPOINT_V3_ACTION_STATE_RUNNING = 1,     Action executing
    DJI_WAYPOINT_V3_ACTION_STATE_FINISHED = 5,    Action execution completed
} E_DjiWaypointV3ActionState;
```

### T_DjiWaypointV3MissionState

Waypoint V3 mission state information structure.

```c
typedef struct {
    E_DjiWaypointV3MissionState state;          Current mission state
    uint32_t wayLineId;                         Current route ID
    uint16_t currentWaypointIndex;              Current waypoint index
} T_DjiWaypointV3MissionState;
```

### T_DjiWaypointV3ActionState

Waypoint V3 action state information structure.

```c
typedef struct {
    E_DjiWaypointV3ActionState state;           Current action state
    uint32_t wayLineId;                         Current route ID
    uint16_t currentWaypointIndex;              Current waypoint index
    uint16_t actionGroupId;                     Current action group index
    uint16_t actionId;                          Current action index
} T_DjiWaypointV3ActionState;
```

### WaypointV3MissionStateCallback

- Function: Waypoint V3 mission state callback function, used to receive real-time state information of the waypoint mission.

```c
typedef T_DjiReturnCode (*WaypointV3MissionStateCallback)(T_DjiWaypointV3MissionState missionState);
```

- Parameters
  - missionState: Current Waypoint V3 mission state information, see <a href="waypoint-v3.html#t-djiwaypointv3missionstate">T_DjiWaypointV3MissionState</a>.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
