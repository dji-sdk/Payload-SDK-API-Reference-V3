
## Overview

This document describes the function prototypes and data type definitions in the liveview AR rendering module header file `dji_open_ar.h`. This module is used to render AR (Augmented Reality) elements on the real-time camera stream of the aircraft. Developers can use this module to create, update, and delete AR graphics such as points, lines, polygons, circles, and pivot axes.

::: tip Note:
- This feature is only supported on DJI Manifold 3.
- For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Data Type Definitions

### T_DjiOpenArCoordinate

AR coordinate information, used to describe the position of AR elements in geographic space.

```c
typedef struct {
    float longitude;    Longitude, unit: degrees
    float latitude;     Latitude, unit: degrees
    float altitude;     Altitude, unit: meters
} T_DjiOpenArCoordinate;
```

### T_DjiOpenArTextAttribute

AR text attribute, used to configure the text display of AR elements.

```c
typedef struct {
    uint8_t is_show:1;      Whether to display text, 1: show, 0: hide
    uint8_t text[30];       Text content, terminated with '\0'
} T_DjiOpenArTextAttribute;
```

### T_DjiOpenArIconAttribute

AR icon attribute, used to configure the icon display of AR elements.

```c
typedef struct {
    uint8_t selected:1;     Whether selected, 1: selected, 0: not selected
    uint8_t visible:1;      Whether visible, 1: show, 0: hide
    uint32_t color;         Icon color, including alpha channel
} T_DjiOpenArIconAttribute;
```

### T_DjiOpenArTouchAttribute

AR touch attribute, used to configure the touch interaction behavior of AR elements.

```c
typedef struct {
    uint8_t action;                             Touch action type, 0: tap, 1: drag along line, 2: long-range drag
    T_DjiOpenArCoordinate normal_vector;        Drag direction normal vector
} T_DjiOpenArTouchAttribute;
```

### T_DjiOpenArIds

AR element unique identifier, used to identify and index AR elements.

```c
typedef struct {
    uint32_t uuid;          Element unique identifier, used for update and delete operations
    uint32_t style_id;      Style ID, used to index resource configuration in widget.json
} T_DjiOpenArIds;
```

### T_DjiOpenArPolygonFaceAttribute

AR polygon face attribute, used to control the display effect of polygon faces.

```c
typedef struct {
    uint8_t dist_alpha_enable:1;    Whether to enable distance-based alpha gradient
    uint8_t face_bottom_enable:1;   Whether to show the bottom face
    uint8_t face_side_enable:1;     Whether to show the side faces
    uint8_t face_top_enable:1;      Whether to show the top face
} T_DjiOpenArPolygonFaceAttribute;
```

### T_DjiOpenArPolygonStrokeAttribute

AR polygon stroke attribute, used to control the display and transparency effects of polygon strokes.

```c
typedef struct {
    uint8_t top_show:1;                 Whether to show top stroke
    uint8_t top_dist_alpha_enable:1;    Whether top stroke enables distance-based alpha gradient
    uint8_t side_show:1;                Whether to show side strokes
    uint8_t side_dist_alpha_enable:1;   Whether side strokes enable distance-based alpha gradient
    uint8_t bottom_show:1;              Whether to show bottom stroke
    uint8_t bottom_dist_alpha_enable:1; Whether bottom stroke enables distance-based alpha gradient
} T_DjiOpenArPolygonStrokeAttribute;
```

### T_DjiOpenArPoint

AR point information, describing the complete attributes of a single AR point.

```c
typedef struct {
    uint32_t uuid;                              Element unique identifier
    uint32_t style_id;                          Style ID, used to index resource configuration in widget.json
    uint32_t resource_id;                       Resource ID
    uint8_t is_always_in_edge;                  Whether to always display at the edge of the screen
    T_DjiOpenArCoordinate coordinate;           Geographic coordinate of the AR point
    T_DjiOpenArTextAttribute text_attr;         Text attribute
    T_DjiOpenArIconAttribute icon_attr;         Icon attribute
    T_DjiOpenArTouchAttribute touch_attr;       Touch attribute
} T_DjiOpenArPoint;
```

### T_DjiOpenArPointArray

AR point array, used for batch setting or updating AR points.

```c
typedef struct {
    uint32_t len;                   Point array length
    T_DjiOpenArPoint points[0];     AR point array, flexible array member
} T_DjiOpenArPointArray;
```

### T_DjiOpenArLine

AR line information, describing an AR line composed of multiple connected points.

```c
typedef struct {
    T_DjiOpenArIds ids;                 Element identification information
    T_DjiOpenArPointArray point_array;  Point array composing the line
} T_DjiOpenArLine;
```

### T_DjiOpenArPolygon

AR polygon information, describing an AR polygon composed of multiple points.

```c
typedef struct {
    T_DjiOpenArIds ids;                             Element identification information
    T_DjiOpenArCoordinate normal_vector;            Polygon normal vector
    T_DjiOpenArPolygonFaceAttribute face;           Face attribute
    T_DjiOpenArPolygonStrokeAttribute stroke;       Stroke attribute
    T_DjiOpenArPointArray point_array;              Point array composing the polygon
} T_DjiOpenArPolygon;
```

### T_DjiOpenArCircle

AR circle information, describing the geometric and display attributes of an AR circle.

```c
typedef struct {
    T_DjiOpenArIds ids;                             Element identification information
    float radius;                                   Circle radius, unit: meters
    T_DjiOpenArCoordinate center;                   Center coordinate
    T_DjiOpenArCoordinate normal_vector;            Circle face normal vector
    T_DjiOpenArPolygonFaceAttribute face;           Face attribute
    T_DjiOpenArPolygonStrokeAttribute stroke;       Stroke attribute
} T_DjiOpenArCircle;
```

### T_DjiOpenArPivotAxis

AR pivot axis information, describing the position and direction of an AR pivot axis.

```c
typedef struct {
    T_DjiOpenArIds ids;                             Element identification information
    uint8_t show_enable;                            Whether to show the pivot axis, 1: show, 0: hide
    T_DjiOpenArCoordinate pivot;                    Pivot axis center point coordinate
    T_DjiOpenArCoordinate normal_vector;            Pivot axis direction normal vector
} T_DjiOpenArPivotAxis;
```

### T_DjiOpenArDeletePointEntry

AR delete point entry, used to specify the AR points to be deleted.

```c
typedef struct {
    uint32_t resource_id;           Resource ID
    uint32_t uuid_len;              UUID array length
    uint32_t uuid_array[0];         UUID array of points to be deleted, flexible array member
} T_DjiOpenArDeletePointEntry;
```

### T_DjiOpenArDeleteCommonEntry

AR common delete entry, used to specify the AR elements to be deleted.

```c
typedef struct {
    uint32_t uuid;      Unique identifier of the element to be deleted
} T_DjiOpenArDeleteCommonEntry;
```

`T_DjiOpenArDeleteLineEntry`, `T_DjiOpenArDeletePolygonEntry`, `T_DjiOpenArDeleteCircleEntry`, and `T_DjiOpenArDeletePovixAxisEntry` are all type aliases of `T_DjiOpenArDeleteCommonEntry`:

```c
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeleteLineEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeletePolygonEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeleteCircleEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeletePovixAxisEntry;
```
