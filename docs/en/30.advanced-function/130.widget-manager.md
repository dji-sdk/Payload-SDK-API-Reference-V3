
## Overview

This document describes the function prototypes and data type definitions in the widget manager module header file `dji_widget_manager.h`. This module is used to manage and control payload widget states on the aircraft. Developers can use this module to subscribe to and set widget states, manage speaker parameters, transfer audio files to speakers, and download widget files from payloads.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

## Function Prototypes

### DjiWidgetManager_Init

- Function: Initialize the widget manager module.

::: tip Note:
This interface initialization needs to be called after DjiCore_Init.
:::

```c
T_DjiReturnCode DjiWidgetManager_Init();
```

- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidgetManager_SubscribePayloadWidgetStates

- Function: Subscribe to the widget states of a payload.

::: tip Note:
Use this interface to be notified when the states of the target payload's widget change.
:::

```c
T_DjiReturnCode DjiWidgetManager_SubscribePayloadWidgetStates(E_DjiMountPosition position,
                                                              RecvWidgetStatesCallback recvStatesCallback);
```

- Parameters
  - position: The mount position of the target payload.
  - recvStatesCallback: The callback function to receive the widget states, see RecvWidgetStatesCallback.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiWidgetManagerSpeakerStates

Speaker system states.

```c
typedef enum {
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IDEL = 0,                      Idle state
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IN_TRANSMISSION = 1,           Audio data is being transmitted
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_PLAYING = 2,                   Audio is being played
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_EXCEPTION = 3,                 Exception state
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IN_TTS_CONVERSION = 4,         TTS conversion is in progress
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_PLAYING_IN_TRANSMISSION = 5,   Playing while transmitting
} E_DjiWidgetManagerSpeakerStates;
```

### T_DjiSpeakerWidgetStates

Speaker widget state information.

```c
typedef struct {
    E_DjiWidgetSpeakerWorkMode workMode;                              Working mode of the speaker
```

### RecvWidgetStatesCallback

- Function: Callback function type for receiving widget states from a payload.

::: tip Note:
It is not recommended to perform blocking operations in the callback, as it may lead to data loss.
:::

```c
typedef void (*RecvWidgetStatesCallback)(E_DjiMountPosition position, T_DjiWidgetStates *statesData, uint8_t widgetNum);
```

- Parameters
  - position: The mount position of the payload from which the widget states originate.
  - statesData: Pointer to the widget states data, see <a href="widget-manager.html#t-djiwidgetstates">T_DjiWidgetStates</a>.
  - widgetNum: Number of widgets.

### DjiWidgetDownloadFileDataCallback

It is not recommended to perform blocking operations in the callback, as it may lead to data loss.
:::

```c

                                                             const uint8_t *data,
                                                             uint16_t dataLen);
```

- Parameters
  - packetInfo: Widget file download progress information, see <a href="widget-manager.html#t-djidownloadwidgetfileinfo">T_DjiDownloadWidgetFileInfo</a>.
  - data: Pointer to the downloaded raw data.
  - dataLen: Length of the downloaded data, unit: bytes.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>
