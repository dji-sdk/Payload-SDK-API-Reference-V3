
## Overview

This document describes the function prototypes and data type definitions in the gimbal management module header file `dji_gimbal_manager.h`. This module is used to control DJI gimbals installed on the aircraft. Developers can use this module to implement gimbal mode setting, rotation control, reset, pitch range extension, speed and smoothness adjustment, factory settings restoration, and other functions.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### DjiGimbalManager_SetPitchRangeExtensionEnabled

- Function: Enable or disable gimbal pitch range extension.

::: tip Note:
When enabled, the gimbal pitch axis Euler angle limit will switch to the extended limit angle; when disabled, it will revert to the default limit angle.
:::

```c
T_DjiReturnCode DjiGimbalManager_SetPitchRangeExtensionEnabled(E_DjiMountPosition mountPosition, bool enabledFlag);
```

- Parameters
  - mountPosition: Gimbal mount position, see <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a> for input constraints.
  - enabledFlag: Specifies whether to enable or disable gimbal pitch range extension.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiGimbalManager_SetControllerMaxSpeedPercentage

- Function: Set the maximum speed percentage of the gimbal controller.

```c
T_DjiReturnCode DjiGimbalManager_SetControllerMaxSpeedPercentage(E_DjiMountPosition mountPosition, E_DjiGimbalAxis axis, uint8_t maxSpeedPercentage);
```

- Parameters
  - mountPosition: Gimbal mount position, see <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a> for input constraints.
  - axis: The axis to set.
  - maxSpeedPercentage: Maximum speed percentage value, range 1~100. Recommended formula: "spd = default_max_spd * x / 100", where x is the set value.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiGimbalManager_SetControllerSmoothFactor

- Function: Set the smooth factor of the gimbal controller.

```c
T_DjiReturnCode DjiGimbalManager_SetControllerSmoothFactor(E_DjiMountPosition mountPosition, E_DjiGimbalAxis axis, uint8_t smoothingFactor);
```

- Parameters
  - mountPosition: Gimbal mount position, see <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a> for input constraints.
  - axis: The axis to set.
  - smoothingFactor: Smooth factor. The larger the value, the smaller the gimbal rotation acceleration. Range 1~30. Recommended formula: "acc = 10000 * (0.8 ^ (1 + x)) deg/s^2", where x is the smooth factor value.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### T_DjiGimbalManagerRotation

Defines gimbal manager rotation attributes.

```c
typedef struct {
    E_DjiGimbalRotationMode rotationMode;    Gimbal rotation mode
    dji_f32_t pitch;                         Pitch angle, unit: degrees
    dji_f32_t roll;                          Roll angle, unit: degrees
    dji_f32_t yaw;                           Yaw angle, unit: degrees
    dji_f64_t time;                          Expected execution time, unit: seconds
} T_DjiGimbalManagerRotation;
```
