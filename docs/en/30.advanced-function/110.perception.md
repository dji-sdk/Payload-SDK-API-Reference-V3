

## Overview

This document describes the function prototypes and data type definitions in the perception data module header file `dji_perception.h`. This module is used to obtain image data from the aircraft's visual perception system, LiDAR point cloud data, and millimeter-wave radar data. Developers can use this module to subscribe to perception images, LiDAR data, and radar data in specified directions for applications such as obstacle detection and environment perception.

::: tip Supported Aircraft Models
For the support scope of each aircraft model, refer to the model matrix in the [Open Capability List](https://developer.dji.com/doc/payload-sdk-tutorial/en/development-preparation/development-platform-overview/open-capability-list.html).
:::

### DjiPerception_SubscribePerceptionImage

- Function: Subscribe to binocular stereo camera raw images in the specified direction.

::: tip Note:
The default subscription frequency is 20 Hz.
:::

```c
T_DjiReturnCode DjiPerception_SubscribePerceptionImage(E_DjiPerceptionDirection direction,
                                                       DjiPerceptionImageCallback callback);
```

- Parameters
  - direction: Specified subscription direction, see <a href="perception.html#e-djiperceptiondirection">E_DjiPerceptionDirection</a>.
  - callback: Perception image data callback function pointer.
- Return Value
  - Returns the corresponding return code depending on the program execution status. For details, please refer to: <a href="../system-base/dji-error.html">DjiErrorCode</a>

## Data Type Definitions

### E_DjiPerceptionDirection

Perception image subscription direction.

```c
typedef enum {
    DJI_PERCEPTION_RECTIFY_DOWN = 0,      Downward
    DJI_PERCEPTION_RECTIFY_FRONT = 1,     Forward
    DJI_PERCEPTION_RECTIFY_REAR = 2,      Rearward
    DJI_PERCEPTION_RECTIFY_UP = 3,        Upward
    DJI_PERCEPTION_RECTIFY_LEFT = 4,      Leftward
    DJI_PERCEPTION_RECTIFY_RIGHT = 5      Rightward
} E_DjiPerceptionDirection;
```

### E_DjiPerceptionCameraPosition

Perception camera position.

```c
typedef enum {
    RECTIFY_DOWN_LEFT = 1,       Downward left camera
    RECTIFY_DOWN_RIGHT = 2,      Downward right camera
    RECTIFY_FRONT_LEFT = 3,      Forward left camera
    RECTIFY_FRONT_RIGHT = 4,     Forward right camera
    RECTIFY_REAR_LEFT = 5,       Rearward left camera
    RECTIFY_REAR_RIGHT = 6,      Rearward right camera
    RECTIFY_UP_LEFT = 21,        Upward left camera
    RECTIFY_UP_RIGHT = 22,       Upward right camera
    RECTIFY_LEFT_LEFT = 23,      Leftward left camera
    RECTIFY_LEFT_RIGHT = 24,     Leftward right camera
    RECTIFY_RIGHT_LEFT = 25,     Rightward left camera
    RECTIFY_RIGHT_RIGHT = 26     Rightward right camera
} E_DjiPerceptionCameraPosition;
```

### E_DjiPerceptionRadarPosition

Perception radar mounting position.

```c
typedef enum {
    RADAR_POSITION_LEFT = 0,     Left
    RADAR_POSITION_RIGHT = 1,    Right
    RADAR_POSITION_DOWN = 2,     Down
    RADAR_POSITION_UP = 3,       Up
    RADAR_POSITION_FRONT = 4,    Front
    RADAR_POSITION_BACK = 5,     Back
    MAX_RADAR_NUM = 6            Maximum number of radars
} E_DjiPerceptionRadarPosition;
```

### T_DjiPerceptionRawImageInfo

Perception raw image information.

```c
typedef struct {
    uint32_t index;        Image index
    uint8_t direction;     Image direction
    uint8_t bpp;           Bits per pixel
    uint32_t width;        Image width, unit: pixels
    uint32_t height;       Image height, unit: pixels
} T_DjiPerceptionRawImageInfo;
```

### T_DjiPerceptionImageInfo

Perception image information.

```c
typedef struct {
    T_DjiPerceptionRawImageInfo rawInfo;    Raw image information
    uint16_t dataId;                        Data ID
    uint16_t sequence;                      Sequence number
    uint32_t dataType;                      Data type, see E_DjiPerceptionCameraPosition
    uint64_t timeStamp;                     Timestamp
} T_DjiPerceptionImageInfo;
```

### T_DjiPerceptionCameraParameters

Single-direction binocular stereo camera parameters.

```c
typedef struct {
    uint8_t direction;                                                  Camera direction
    float leftIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];    Left camera intrinsic parameters
    float rightIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];   Right camera intrinsic parameters
    float rotationLeftInRight[DJI_PERCEPTION_ROTATION_PARAM_ARRAY_NUM];       Rotation matrix of left camera in right camera coordinate system
    float translationLeftInRight[DJI_PERCEPTION_TRANSLATION_PARAM_ARRAY_NUM]; Translation vector of left camera in right camera coordinate system
} T_DjiPerceptionCameraParameters;
```

### T_DjiPerceptionCameraParametersPacket

All-direction binocular stereo camera parameters packet.

```c
typedef struct {
    uint32_t timeStamp;                                                        Timestamp
    uint32_t directionNum;                                                     Number of directions
    T_DjiPerceptionCameraParameters cameraParameters[IMAGE_MAX_DIRECTION_NUM]; Camera parameters array for each direction
} T_DjiPerceptionCameraParametersPacket;
```

### T_DJIPerceptionLidarPoint

LiDAR single point data information.

```c
typedef struct {
    float   x;             X coordinate, unit: meters
    float   y;             Y coordinate, unit: meters
    float   z;             Z coordinate, unit: meters
    uint8_t intensity;     Reflection intensity
    uint8_t label;         Noise filtering result (0: Target; 1: Noise; 2: Unknown; 3: No echo)
} T_DJIPerceptionLidarPoint;
```

### T_DJIPerceptionLidarDataHeader

LiDAR per-packet data header information.

```c
typedef struct {
    uint16_t timeInterval;     Point cloud sampling time interval, unit: 0.1 microseconds
    uint16_t dotNum;           Number of points in the current packet, invalid in non-repetitive scan mode
    uint8_t  dataType;         Data type, upper 4 bits are echo mode (0~4 corresponding to single echo to five echoes), lower 4 bits are data type (1: 32-bit Cartesian point cloud; 2: 16-bit Cartesian point cloud; 3: Spherical coordinate point cloud; 4: 20-bit Cartesian point cloud; 40: IMU data)
    uint8_t  timeType;         Timestamp type (0: Radar running time; 1: gPTP/PTP synchronized time; 2: PPS+ns time synchronization; 3: PPS+UTC)
    uint64_t timeStamp;        Timestamp
} T_DJIPerceptionLidarDataHeader;
```

### T_DjiPerceptionLidarDecodePkg

LiDAR decoded single-packet data.

```c
typedef struct {
    T_DJIPerceptionLidarDataHeader  header;                    Packet header information
    T_DJIPerceptionLidarPoint       points[DJI_PTS_NUM_PER_PKG]; Point cloud data array, up to 96 points per packet
} T_DjiPerceptionLidarDecodePkg;
```

### T_DjiLidarFrame

LiDAR complete frame data.

```c
typedef struct {
    uint64_t  timeStampNs;     Timestamp of the first point in each packet, unit: nanoseconds
    uint32_t  frameCnt;        Frame count, incrementing from 0
    uint16_t  pkgNum;          Number of valid packets per frame
    T_DjiPerceptionLidarDecodePkg pkgs[DJI_LIDAR_PKG_BUFFER_NUM]; Packet data array
    uint32_t  poseTimeMs;      Pose time, unit: milliseconds
    uint16_t  naviFlag;        Navigation status flag bits (see header file comments for bit definitions)
    float     naviPos[3];      Translation vector from aircraft IMU to navigation coordinate system (x, y, z)
    float     naviQuat[4];     Quaternion from aircraft IMU to navigation coordinate system
} T_DjiLidarFrame;
```

### T_DjiRadarDataHeader

Millimeter-wave radar data frame header information.

```c
typedef struct {
    uint16_t dataLen;      Data length
    uint8_t  curPack;      Current packet number, range [1, packNum]
    uint8_t  packNum;      Total number of packets in the current rotation, starting from 1
} T_DjiRadarDataHeader;
```

### T_DjiRadarBaseInfo

Millimeter-wave radar base information.

```c
typedef struct {
    uint64_t velocity  :16;      Target velocity, actual velocity (m/s) = (velocity - 32767) / 100, positive values indicate approaching, negative values indicate receding
    uint64_t snr       :7;       Target signal-to-noise ratio, unit: dB, range 0~127, 0 indicates no echo
    uint64_t beamAngle :10;      Beam emission angle, unit: 0.01 degrees, storage range 0~1023, actual range [-45°, 45°]
    uint64_t radarType :3;       Radar number, invalid on M400
    uint64_t clitterFlag :1;     Clutter flag, 1 for clutter point, 0 for valid point
    uint64_t reserved  :27;      Reserved field
} T_DjiRadarBaseInfo;
```

### T_DjiRadarCloudUnit

Millimeter-wave radar single point data.

```c
typedef struct {
    uint16_t azimuth;              Target azimuth angle, unit: 0.001 radians, actual value = azimuth / 1000 - 2π
    uint16_t elevation;            Target elevation angle, unit: 0.001 radians, actual value = elevation / 1000 - 2π
    uint16_t radius;               Target radial distance, unit: 0.01 meters, range 0~65553
    uint16_t ene;                  Radar target energy, actual value = ene / 100, invalid on M400
    T_DjiRadarBaseInfo base_info;  Radar base information
} T_DjiRadarCloudUnit;
```

### T_DjiRadarDataFrame

Millimeter-wave radar data frame.

```c
typedef struct {
    T_DjiRadarDataHeader headInfo;     Data frame header information
    T_DjiRadarCloudUnit data[1];       Radar point cloud data (flexible array)
} T_DjiRadarDataFrame;
```

### DjiPerceptionImageCallback

- Function: Perception image data callback function prototype.

::: tip Note:
It is not recommended to perform blocking operations in the callback function, as this may cause data loss.
:::

```c
typedef void (*DjiPerceptionImageCallback)(T_DjiPerceptionImageInfo imageInfo,
                                           uint8_t *imageRawBuffer,
                                           uint32_t bufferLen);
```

- Parameters
  - imageInfo: Perception image information.
  - imageRawBuffer: Pointer to the image raw data buffer.
  - bufferLen: Buffer length, unit: bytes.
- Return Value
  - None
