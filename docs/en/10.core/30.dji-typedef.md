#### <font id=4 color="#AAA">typedef function</font> <font color="#44a8f2">DjiReceiveDataOfTopicCallback</font>
Prototype of callback function used to receive data of topic.

@warning User can not execute blocking style operations or functions in the callback function, because that will block PSDK root thread, causing problems such as slow system response, payload disconnection or infinite loop.

```c
typedef T_DjiReturnCode (*DjiReceiveDataOfTopicCallback)(const uint8_t *data, uint16_t dataSize,
                                                         const T_DjiDataTimestamp *timestamp);
```

<font color="#AAA">Parameter</font>   
<br/><font color="#70BF41">data</font>： pointer to data of the topic, user need transfer type of this pointer to the corresponding data structure pointer for getting every item of the topic conveniently.  
<br/><font color="#70BF41">dataSize</font>： the size of memory space pointed by data argument, equal to data structure size corresponding to the topic. 
<br/><font color="#70BF41">timestamp</font>： pointer to timestamp corresponding this data.       
<br/><font color="#AAA">Return</font>
<br/>The details for the return code please refer to: <a href="../core/dji-error.html">DjiErrorCode</a>
