
## 概述

本文档描述了平台移植模块头文件`dji_platform.h`中的函数原型和数据类型定义。该模块定义了 PSDK 与不同硬件平台和操作系统之间的抽象层接口，开发者需要根据自身平台实现 UART、USB Bulk、网络、I2C、OSAL、文件系统和 Socket 等接口的适配，并通过注册函数将实现注册到 SDK 中。

## 函数原型

### DjiPlatform_RegHalUartHandler

- 功能：注册 HAL 层 UART 接口处理程序。

::: tip 说明：
* 在注册 HAL 层接口的回调函数前，请确保接口已完成测试，能够正常工作。
* 请在应用程序初始化阶段调用该接口完成注册，否则后续功能将无法正常运行。
:::

```c
T_DjiReturnCode DjiPlatform_RegHalUartHandler(const T_DjiHalUartHandler *halUartHandler);
```

- 参数
  - halUartHandler：指向平台 HAL 层 UART 接口处理程序的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### T_DjiHalUartHandler

- 功能：HAL 层 UART 接口回调函数集合。

请根据本结构体中的函数构造 UART 接口相关功能的回调函数，其中包括：
* 初始化 UART 接口
* 反初始化 UART 接口
* 通过 UART 写入数据
* 通过 UART 读取数据
* 获取 UART 连接状态
* 获取 UART 设备信息（用于 Eport V2 排线适配器，其他接口类型可不实现）

::: tip 说明：
为防止该函数阻塞 PSDK 的主线程，导致出现程序响应缓慢、断连及死循环等问题，请勿以阻塞的方式在回调函数中执行该函数。
:::

```c
typedef struct {
    @brief 初始化 UART 接口
    @param uartNum: UART 端口编号
    @param baudRate: 波特率
    @param uartHandle: 指向用于存储 UART 句柄的内存空间
    @return 执行结果
    T_DjiReturnCode (*UartInit)(E_DjiHalUartNum uartNum, uint32_t baudRate, T_DjiUartHandle *uartHandle);

    @brief 反初始化 UART 接口
    @param uartHandle: UART 句柄
    @return 执行结果
    T_DjiReturnCode (*UartDeInit)(T_DjiUartHandle uartHandle);

    @brief 通过 UART 写入数据
    @param uartHandle: UART 句柄
    @param buf: 指向待写入数据的缓冲区
    @param len: 待写入数据的长度，单位：字节
    @param realLen: 指向用于存储实际写入长度的内存空间
    @return 执行结果
    T_DjiReturnCode (*UartWriteData)(T_DjiUartHandle uartHandle, const uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief 通过 UART 读取数据
    @param uartHandle: UART 句柄
    @param buf: 指向用于存储读取数据的缓冲区
    @param len: 期望读取的数据长度，单位：字节
    @param realLen: 指向用于存储实际读取长度的内存空间
    @return 执行结果
    T_DjiReturnCode (*UartReadData)(T_DjiUartHandle uartHandle, uint8_t *buf, uint32_t len, uint32_t *realLen);

    @brief 获取 UART 连接状态
    @param uartNum: UART 端口编号
    @param status: 指向用于存储 UART 连接状态的内存空间
    @return 执行结果
    T_DjiReturnCode (*UartGetStatus)(E_DjiHalUartNum uartNum, T_DjiUartStatus *status);

    @brief 获取直连飞行器的 USB 串口设备信息，用于 Eport V2 排线适配器，其他接口类型可不实现
    @param deviceInfo: 指向用于存储 UART 设备信息的内存空间
    @return 执行结果
    T_DjiReturnCode (*UartGetDeviceInfo)(T_DjiHalUartDeviceInfo *deviceInfo);
} T_DjiHalUartHandler;
```
