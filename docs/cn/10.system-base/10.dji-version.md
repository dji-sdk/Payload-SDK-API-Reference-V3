
## 概述

本文档描述了 PSDK 版本信息头文件`dji_version.h`中的宏定义。该头文件定义了当前 PSDK 的版本号信息，开发者可以通过这些宏获取 SDK 的主版本号、次版本号、修订版本号等信息。

## 版本宏定义

### DJI_VERSION_MAJOR

PSDK 主版本号，表示不兼容的 API 变更，取值范围：0～99。

```c
#define DJI_VERSION_MAJOR     3
```

### DJI_VERSION_MINOR

PSDK 次版本号，表示以向后兼容方式新增功能时的变更，取值范围：0～99。

```c
#define DJI_VERSION_MINOR     16
```

### DJI_VERSION_MODIFY

PSDK 修订版本号，表示向后兼容的错误修复变更，取值范围：0～99。

```c
#define DJI_VERSION_MODIFY    0
```

### DJI_VERSION_BETA

PSDK Beta 版本信息，正式发布版本为 0，取值范围：0～255。

```c
#define DJI_VERSION_BETA      0
```

### DJI_VERSION_BUILD

PSDK 构建版本号，表示构建触发时的变更，取值范围：0～65535。

```c
#define DJI_VERSION_BUILD     2338
```
