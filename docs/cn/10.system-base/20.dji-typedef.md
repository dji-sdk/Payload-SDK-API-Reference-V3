
## 概述

本文档描述了 PSDK 公共数据类型头文件`dji_typedef.h`中的宏定义和数据类型定义。该头文件定义了 PSDK 各模块共用的基础数据类型，包括坐标系定义、飞行器型号枚举、相机类型枚举、云台模式枚举、通道地址枚举等，是 PSDK 所有功能模块的基础依赖。

### DJI_SUBSCRIPTION_MODULE_INDEX_OFFSET
订阅模块索引偏移量。
```c

```

### DJI_SUBSCRIPTION_MODULE_INDEX_MASK
订阅模块索引掩码。
```c
#define DJI_SUBSCRIPTION_MODULE_INDEX_MASK      0xFF000000u
```

### DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET
订阅主题编码偏移量。
```c
#define DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET      0u
```

### DJI_SUBSCRIPTION_TOPIC_CODE_MASK
订阅主题编码掩码。
```c
#define DJI_SUBSCRIPTION_TOPIC_CODE_MASK        0x00FFFFFFu
```

### DJI_DATA_SUBSCRIPTION_TOPIC
数据订阅主题组合宏，将订阅模块索引和主题编码组合为一个 uint32 类型的主题值。
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC(subscriptionModule, topicCode) \
    (uint32_t)\
    (((((uint32_t)(subscriptionModule)) << (DJI_SUBSCRIPTION_MODULE_INDEX_OFFSET)) & (DJI_SUBSCRIPTION_MODULE_INDEX_MASK)) | \
    ((((uint32_t)(topicCode)) << (DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET)) & (DJI_SUBSCRIPTION_TOPIC_CODE_MASK)))
```

### DJI_DATA_SUBSCRIPTION_TOPIC_GET_MODULE
从组合主题值中提取订阅模块索引。
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC_GET_MODULE(topic) \
    ((uint32_t)((topic & DJI_SUBSCRIPTION_MODULE_INDEX_MASK) >> DJI_SUBSCRIPTION_MODULE_INDEX_OFFSET))
```

### DJI_DATA_SUBSCRIPTION_TOPIC_GET_CODE
从组合主题值中提取主题编码。
```c
#define DJI_DATA_SUBSCRIPTION_TOPIC_GET_CODE(topic) \
    ((uint32_t)((topic & DJI_SUBSCRIPTION_TOPIC_CODE_MASK) >> DJI_SUBSCRIPTION_TOPIC_CODE_OFFSET))
```

## 回调函数

### DjiReceiveDataOfTopicCallback

- 功能：接收订阅主题数据的回调函数。

::: tip 说明：
用户不能在回调函数中执行阻塞式操作或函数，否则会阻塞 PSDK 根线程，导致系统响应缓慢、负载设备断连或死循环等问题。
:::

```c
typedef T_DjiReturnCode (*DjiReceiveDataOfTopicCallback)(const uint8_t *data, uint16_t dataSize,
                                                         const T_DjiDataTimestamp *timestamp);
```

- 参数
  - data：指向主题数据的指针，用户需将该指针转换为对应主题的数据结构指针以获取各字段。
  - dataSize：data 指针指向的内存空间大小，等于该主题对应数据结构的大小。
  - timestamp：指向该数据对应时间戳的指针。M300 RTK 使用飞控上电时间戳，M30/M30T 使用负载本地时间戳。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>
