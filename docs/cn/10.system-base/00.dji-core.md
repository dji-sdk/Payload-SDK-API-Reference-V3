

## 概述

本文档描述了 PSDK 核心模块头文件`dji_core.h`中的函数原型和数据类型定义。该模块是 PSDK 的核心初始化入口，开发者需要通过该模块完成 SDK 的初始化、应用信息配置、固件版本设置、序列号设置等基础操作，所有其他功能模块必须在核心模块初始化完成后才能使用。

## 函数原型

### DjiCore_Init

- 功能：以阻塞模式初始化 Payload SDK 内核。

::: tip 说明：
* 该接口的调用顺序至关重要，必须在 console/OSAL handler/HAL handler 函数注册完成后调用，同时必须在调用其他功能模块接口之前完成初始化。请正确填写开发者信息以确保初始化成功，详情请参阅教程"PSDK 初始化"。
* 该函数在获得正确的飞行器类型和 PSDK 适配器类型之前不会返回。此逻辑保证飞行器和 PSDK 适配器在功能模块和用户程序运行前已正常启动。该函数的一般执行时间为 2~4 秒。
:::

```c
T_DjiReturnCode DjiCore_Init(const T_DjiUserInfo *userInfo);
```

- 参数
  - userInfo：指向 PSDK 应用程序信息的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetAlias

- 功能：为 DJI 应用或产品设置一个别名。

::: tip 说明：
* 仍然需要将从 DJI SDK 开发者网站获取的正确 DJI APP 名称传递给 DjiCore_Init() 接口，DJI APP 名称将用于绑定和验证。
* 别名设置后会在短暂延迟后生效，最长不超过 1 秒。设置成功后别名将显示在 DJI Pilot 中。
:::

```c
T_DjiReturnCode DjiCore_SetAlias(const char *productAlias);
```

- 参数
  - productAlias：指向产品别名字符串的指针，以 '\0' 结尾，最大长度为 31 个字符。如果别名字符串长度超过 31 个字符，将被截断后传入。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetFirmwareVersion

- 功能：为 DJI 应用或产品设置自定义固件版本号。

::: tip 说明：
负载固件版本号会始终显示在 DJI Pilot 负载设置界面上。
:::

```c
T_DjiReturnCode DjiCore_SetFirmwareVersion(T_DjiFirmwareVersion version);
```

- 参数
  - version：自定义的固件版本号。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetSerialNumber

- 功能：为 DJI 应用或产品设置自定义序列号。

::: tip 说明：
负载自定义序列号会始终显示在 DJI Pilot 负载设置界面上。
:::

```c
T_DjiReturnCode DjiCore_SetSerialNumber(const char *productSerialNumber);
```

- 参数
  - productSerialNumber：自定义的序列号字符串，长度不超过 32 字节。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_ApplicationStart

- 功能：通知 Payload SDK 内核应用程序启动。

::: tip 说明：
该接口的调用顺序需要特别注意，必须在所有功能模块的初始化和回调注册接口调用完成后再调用。
:::

```c
T_DjiReturnCode DjiCore_ApplicationStart(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_DeInit

- 功能：以阻塞模式反初始化 Payload SDK 内核。

```c
T_DjiReturnCode DjiCore_DeInit(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiCore_SetSdkDeviceType

- 功能：设置 SDK 子设备类型。

::: tip 说明：
* 该接口仅适用于需要上报特定 SDK 设备类型的负载，必须在 `DjiCore_Init` 之前调用。
* 目前仅适用于负载类型为运输箱（DJI_SDK_DEVICE_TYPE_TRANSPORT_BOX）的场景。
:::

```c
T_DjiReturnCode DjiCore_SetSdkDeviceType(E_DjiSdkDeviceType type);
```

- 参数
  - type：要设置的设备类型，取值参见 <a href="../system-base/dji-typedef.html#e-djisdkdevicetype">E_DjiSdkDeviceType</a> 枚举。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### T_DjiUserInfo

用于描述基于 PSDK 开发的负载应用信息。

::: tip 说明：
请确认 appName、appId、appKey 等信息与开发者网站一致。更多信息请查看[用户中心](https://developer.dji.com/user/apps/#all)。
:::

```c
typedef struct {
    char appName[32];           PSDK 应用名称，以 '\0' 结尾。通过开发者网站获取
    char appId[16];             PSDK 应用 ID。通过开发者网站获取
    char appKey[32];            PSDK 应用密钥。通过开发者网站获取
    char appLicense[512];       PSDK 应用证书。通过开发者网站获取
    char developerAccount[64];  开发者账号邮箱，以 '\0' 结尾。通过开发者网站获取，需与应用信息对应
    char baudRate[7];           通信串口波特率
} T_DjiUserInfo;
```
