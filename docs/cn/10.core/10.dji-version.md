---
title: 版本信息
---
PSDK 获取版本信息相关功能的头文件为`dji_version.h`，本文档描述了`dji_version.h` 文件中的宏定义。

## 宏定义

* DJI SDK 主版本号

DJI SDK 主版本号，当有不兼容的 API 更改时。 范围从 0 到 99。     

```c
#define DJI_VERSION_MAJOR     3  
```

* DJI SDK 次版本号  

DJI SDK 次版本号，当以向后兼容的方式添加功能时会发生变化。 范围从 0 到 99。  

```c
#define DJI_VERSION_MINOR     1
```
   
* DJI SDK 修改版本号 

DJI SDK 修改版本号，当有向后兼容的错误修复更改时。 范围从 0 到 99。   

```c
#define DJI_VERSION_MODIFY    0
```

* DJI SDK beta版本信息   

DJI SDK beta 版本信息，发布版本为0，当beta版本发布变化时。 范围从 0 到 255。

```c
#define DJI_VERSION_BETA      0 
```

* DJI SDK 构建版本号，范围为0～65535 

DJI SDK 版本构建信息，当 jenkins 触发构建更改时。 范围从 0 到 65535。     

```c
#define DJI_VERSION_BUILD     1503
```
