---
title: SDK 互联互通
---
SDK 互联互通相关功能的头文件为`dji_mop_channel.h`，本文档描述了`dji_mop_channel.h` 文件中结构体和函数原型的关键信息和使用方法。

>**说明：** 仅在Linux 上开发的负载设备支持开发者使用SDK 互联互通功能。

## 宏定义、枚举与结构体

#### MOP 通信通道
```c
typedef void *T_DjiMopChannelHandle;
```
#### <font id=1 color="#AAA">typedef enum</font> <font color="#44a8f2">E_DjiMopChannelTransType</font>

MOP 通道的数据传输类型

```c
typedef enum {
    DJI_MOP_CHANNEL_TRANS_RELIABLE = 0,    可靠传输
    DJI_MOP_CHANNEL_TRANS_UNRELIABLE,      不可靠传输
} E_DjiMopChannelTransType;
```
## 函数原型

> **说明** 
> * 在使用MOP 通道传输信息前，请先使用本接口初始化MOP 通道；

<br/><font color="#AAA">返回值</font>

#### <font id=3 color="#AAA">function</font> <font color="#44a8f2">DjiMopChannel_Create </font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：创建MOP通道 </td>  
      <td>product：all</td>
    </tr>
</table>

创建MOP通道。

> **说明** 
> * MOP 通道创建成功后，请指定需与已创建的通道建立连接的通道ID，等待基于MSDK 开发的移动端App 或基于OSDK开发的应用程序连接该通道；
> * 在成功接受其他设备的连接后，用户可在该通道上发送或接收数据；
> * 若无需使用MOP 通道时，请关闭或销毁已创建的通道，释放通道占用的系统资源。


```c
T_DjiReturnCode DjiMopChannel_Create(T_PsdkMopChannelHandle *channelHandle, E_DjiMopChannelTransType transType);
```
<font color="#AAA">参数</font>        
<br/><font color="#70BF41">channelHandle</font>：指向待创建的MOP 通道句柄       
<br/><font color="#70BF41">transType</font>：MOP 通道的类型，详情请参见E_DjiMopChannelTransType      
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="./core/dji-error.html">PsdkErrorCode</a>

#### <font id=5 color="#AAA">function</font> <font color="#44a8f2">DjiMopChannel_Bind</font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：信道绑定 </td>  
      <td>product：all</td>
    </tr>
</table>

对已创建的的MOP 通道绑定通道ID。     
> **说明：** 创建MOP 通道成功后，开发者可通过指定通道ID与已创建的MOP 通道绑定，在调用接口DjiMopChannel_Accept 后，可以与客户端设备建立连接。

```c
T_DjiReturnCode DjiMopChannel_Bind(T_PsdkMopChannelHandle channelHandle,
                                     uint16_t channelId);
```
<font color="#AAA">参数</font>        
<br/><font color="#70BF41">channelHandle</font>：指向已创建的MOP 通道      
<br/><font color="#70BF41">channelId</font>：指定所需连接的通道ID             
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>    


#### <font id=6 color="#AAA">function</font> <font color="#44a8f2">DjiMopChannel_Accept</font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：接受MOP 通道连接 </td>  
      <td>product：all</td>
    </tr>
</table>

通过已绑定的通道ID接受其他设备的连接请求并建立连接。

> **说明：** MOP 通过channelHandle监听通道接受在队列中等待连接的MOP 通道连接需求，创建一个新的已连接的通道，并通过outChannelHandle 返回通道信息，负载设备能够作为一个服务器端允许多个客户端通过绑定通道ID 与已创建的通道建立连接。

```c
T_DjiReturnCode DjiMopChannel_Accept(T_PsdkMopChannelHandle channelHandle,
                                       T_PsdkMopChannelHandle *outChannelHandle);
```
<font color="#AAA">参数</font>        
<br/><font color="#70BF41">channelHandle</font>：指向已创建的MOP 通道     
<br/><font color="#70BF41">outChannelHandle</font>：指向成功连接后的MOP输出通道       
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>

#### <font id=8 color="#AAA">function</font> <font color="#44a8f2">DjiMopChannel_SendData</font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：发送数据</td>  
      <td>product：all</td>
    </tr>
</table>

使用MOP通道发送数据。
> **说明：** 在成功调用接口DjiMopChannel_Accept 接口后可调用该接口，为提高读写效率，建议每次发送数据时，发送较大的数据，请根据返回值和数据长度判断数据发送的状态。

```c
T_DjiReturnCode DjiMopChannel_SendData(T_DjiMopChannelHandle channelHandle,
                                       uint8_t *data,
                                       uint32_t len,
                                       uint32_t *realLen);
```
<font color="#AAA">参数</font>        
<br/><font color="#70BF41">channelHandle</font>：指向通过调用DjiMopChannel_Accept 后的MOP 句柄outChannelHandle        
<br/><font color="#70BF41">data</font>：指向所需发送的数据       
<br/><font color="#70BF41">len</font>：所需发送的数据长度，单位：byte         
<br/><font color="#70BF41">realLen</font>：指向已发送数据的实际长度     
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>
