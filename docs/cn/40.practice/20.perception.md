#### <font id=5 color="#AAA">typedef struct</font> <font color="#44a8f2"> T_DjiPerceptionCameraParameters </font>

```c
typedef struct {
    uint8_t direction;
    float leftIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];
    float rightIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];
```

#### <font id=10 color="#AAA">function</font> <font color="#44a8f2">DjiPerception_SubscribePerceptionImage</font>

<table style="text-align:left;border:none">
    <tr>
      <td>功能：订阅两个立体相机在同一方向的原始图像。  </td>  
      <td>product：all</td>
    </tr>
</table>
默认频率为 20 Hz。

```c
T_DjiReturnCode DjiPerception_SubscribePerceptionImage(E_DjiPerceptionDirection direction,
                                                       DjiPerceptionImageCallback callback);
```

<font color="#AAA">参数</font>        
<br/><font color="#70BF41">direction</font>：direction 指定订阅的方向，参考 E_DjiPerceptionDirection
<br/><font color="#70BF41">callback</font>：回调到观察者立体相机图像和信息。    
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>
