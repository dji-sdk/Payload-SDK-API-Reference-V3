
## 概述

本文档描述了码流 AR 绘制模块头文件`dji_open_ar.h`中的函数原型和数据类型定义。该模块用于在飞行器相机的实时码流画面上绘制 AR 增强现实元素，开发者可以通过该模块实现点、线、多边形、圆形、旋转轴等 AR 图形的创建、更新和删除操作。

::: tip 说明：
- 该功能仅支持在 DJI Manifold 3 上使用。
- 各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 数据类型定义

### T_DjiOpenArCoordinate

AR 坐标信息，用于描述 AR 元素在地理空间中的位置。

```c
typedef struct {
    float longitude;    经度，单位：度
    float latitude;     纬度，单位：度
    float altitude;     高度，单位：米
} T_DjiOpenArCoordinate;
```

### T_DjiOpenArTextAttribute

AR 文本属性，用于配置 AR 元素的文本显示。

```c
typedef struct {
    uint8_t is_show:1;      是否显示文本，1：显示，0：隐藏
    uint8_t text[30];       文本内容，以 '\0' 结尾
} T_DjiOpenArTextAttribute;
```

### T_DjiOpenArIconAttribute

AR 图标属性，用于配置 AR 元素的图标显示。

```c
typedef struct {
    uint8_t selected:1;     是否选中，1：选中，0：未选中
    uint8_t visible:1;      是否显示，1：显示，0：隐藏
    uint32_t color;         图标颜色，含 alpha 通道
} T_DjiOpenArIconAttribute;
```

### T_DjiOpenArTouchAttribute

AR 触控属性，用于配置 AR 元素的触控交互行为。

```c
typedef struct {
    uint8_t action;                             触控动作类型，0：点击，1：沿线拖拽，2：远距离拖拽
    T_DjiOpenArCoordinate normal_vector;        拖拽方向法向量
} T_DjiOpenArTouchAttribute;
```

### T_DjiOpenArIds

AR 元素唯一标识，用于标识和索引 AR 元素。

```c
typedef struct {
    uint32_t uuid;          元素唯一标识符，用于更新和删除操作
    uint32_t style_id;      样式 ID，用于索引 widget.json 中的资源配置
} T_DjiOpenArIds;
```

### T_DjiOpenArPolygonFaceAttribute

AR 多边形面属性，用于控制多边形各面的显示效果。

```c
typedef struct {
    uint8_t dist_alpha_enable:1;    是否启用距离透明度渐变
    uint8_t face_bottom_enable:1;   是否显示底面
    uint8_t face_side_enable:1;     是否显示侧面
    uint8_t face_top_enable:1;      是否显示顶面
} T_DjiOpenArPolygonFaceAttribute;
```

### T_DjiOpenArPolygonStrokeAttribute

AR 多边形边框属性，用于控制多边形各边框的显示和透明度效果。

```c
typedef struct {
    uint8_t top_show:1;                 是否显示顶部边框
    uint8_t top_dist_alpha_enable:1;    顶部边框是否启用距离透明度渐变
    uint8_t side_show:1;                是否显示侧面边框
    uint8_t side_dist_alpha_enable:1;   侧面边框是否启用距离透明度渐变
    uint8_t bottom_show:1;              是否显示底部边框
    uint8_t bottom_dist_alpha_enable:1; 底部边框是否启用距离透明度渐变
} T_DjiOpenArPolygonStrokeAttribute;
```

### T_DjiOpenArPoint

AR 点信息，描述单个 AR 点的完整属性。

```c
typedef struct {
    uint32_t uuid;                              元素唯一标识符
    uint32_t style_id;                          样式 ID，用于索引 widget.json 中的资源配置
    uint32_t resource_id;                       资源 ID
    uint8_t is_always_in_edge;                  是否始终显示在画面边缘
    T_DjiOpenArCoordinate coordinate;           AR 点的地理坐标
    T_DjiOpenArTextAttribute text_attr;         文本属性
    T_DjiOpenArIconAttribute icon_attr;         图标属性
    T_DjiOpenArTouchAttribute touch_attr;       触控属性
} T_DjiOpenArPoint;
```

### T_DjiOpenArPointArray

AR 点数组，用于批量设置或更新 AR 点。

```c
typedef struct {
    uint32_t len;                   点数组长度
    T_DjiOpenArPoint points[0];     AR 点数组，柔性数组成员
} T_DjiOpenArPointArray;
```

### T_DjiOpenArLine

AR 线信息，描述由多个点连接而成的 AR 线。

```c
typedef struct {
    T_DjiOpenArIds ids;                 元素标识信息
    T_DjiOpenArPointArray point_array;  构成线的点数组
} T_DjiOpenArLine;
```

### T_DjiOpenArPolygon

AR 多边形信息，描述由多个点构成的 AR 多边形。

```c
typedef struct {
    T_DjiOpenArIds ids;                             元素标识信息
    T_DjiOpenArCoordinate normal_vector;            多边形法向量
    T_DjiOpenArPolygonFaceAttribute face;           面属性
    T_DjiOpenArPolygonStrokeAttribute stroke;       边框属性
    T_DjiOpenArPointArray point_array;              构成多边形的点数组
} T_DjiOpenArPolygon;
```

### T_DjiOpenArCircle

AR 圆形信息，描述 AR 圆形的几何和显示属性。

```c
typedef struct {
    T_DjiOpenArIds ids;                             元素标识信息
    float radius;                                   圆形半径，单位：米
    T_DjiOpenArCoordinate center;                   圆心坐标
    T_DjiOpenArCoordinate normal_vector;            圆面法向量
    T_DjiOpenArPolygonFaceAttribute face;           面属性
    T_DjiOpenArPolygonStrokeAttribute stroke;       边框属性
} T_DjiOpenArCircle;
```

### T_DjiOpenArPivotAxis

AR 旋转轴信息，描述 AR 旋转轴的位置和方向。

```c
typedef struct {
    T_DjiOpenArIds ids;                             元素标识信息
    uint8_t show_enable;                            是否显示旋转轴，1：显示，0：隐藏
    T_DjiOpenArCoordinate pivot;                    旋转轴中心点坐标
    T_DjiOpenArCoordinate normal_vector;            旋转轴方向法向量
} T_DjiOpenArPivotAxis;
```

### T_DjiOpenArDeletePointEntry

AR 删除点条目，用于指定要删除的 AR 点。

```c
typedef struct {
    uint32_t resource_id;           资源 ID
    uint32_t uuid_len;              UUID 数组长度
    uint32_t uuid_array[0];         要删除的点的 UUID 数组，柔性数组成员
} T_DjiOpenArDeletePointEntry;
```

### T_DjiOpenArDeleteCommonEntry

AR 通用删除条目，用于指定要删除的 AR 元素。

```c
typedef struct {
    uint32_t uuid;      要删除的元素唯一标识符
} T_DjiOpenArDeleteCommonEntry;
```

`T_DjiOpenArDeleteLineEntry`、`T_DjiOpenArDeletePolygonEntry`、`T_DjiOpenArDeleteCircleEntry`、`T_DjiOpenArDeletePovixAxisEntry` 均为 `T_DjiOpenArDeleteCommonEntry` 的类型别名：

```c
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeleteLineEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeletePolygonEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeleteCircleEntry;
typedef T_DjiOpenArDeleteCommonEntry T_DjiOpenArDeletePovixAxisEntry;
```
