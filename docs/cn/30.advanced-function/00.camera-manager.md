## 概述

本文档描述了相机管理模块头文件`dji_camera_manager.h`中的函数原型和数据类型定义。该模块用于控制和管理飞行器上已安装的 DJI 相机，开发者可以通过该模块实现相机工作模式切换、拍照录像控制、变焦对焦设置、曝光参数调整、存储格式化、媒体文件下载、SD 卡加密管理等功能。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

### DjiCameraManagerDownloadFileDataCallback

- 功能：文件下载数据回调函数，用于接收下载的文件数据。

```c
typedef T_DjiReturnCode (*DjiCameraManagerDownloadFileDataCallback)(T_DjiDownloadFilePacketInfo packetInfo,
                                                                    const uint8_t *data,
                                                                    uint16_t dataLen);
```

- 参数
  - packetInfo：下载文件的包信息，参见 <a href="camera-manager.html#t-djidownloadfilepacketinfo">T_DjiDownloadFilePacketInfo</a>。
  - data：下载的文件数据缓冲区指针。
  - dataLen：数据长度，单位：字节。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>
