
## 概述

本文档描述了控件管理模块头文件`dji_widget_manager.h`中的函数原型和数据类型定义。该模块用于管理负载设备的自定义控件状态，支持订阅和设置负载设备控件状态、喊话器控件状态管理、喊话器音频数据传输，以及控件文件的下载功能。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

- 功能：初始化控件管理模块。

::: tip 说明：
该接口的初始化需要在 DjiCore_Init 之后调用。

## 数据类型定义

### E_DjiWidgetManagerSpeakerStates

喊话器系统状态。

```c
typedef enum {
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IDEL = 0,                    空闲状态
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IN_TRANSMISSION = 1,         数据传输中
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_PLAYING = 2,                 播放中
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_EXCEPTION = 3,               异常状态
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_IN_TTS_CONVERSION = 4,       TTS 转换中
    DJI_WIDGET_MGR_SPEAKER_SYSTEM_STATE_PLAYING_IN_TRANSMISSION = 5, 边播放边传输
} E_DjiWidgetManagerSpeakerStates;
```

typedef enum {

typedef enum {

### T_DjiWidgetStates

```c

    int32_t widgetValue;           控件值
} T_DjiWidgetStates;
```

### T_DjiSpeakerAudioFileInfo

音频文件信息。

```c
typedef struct {
    E_DjiWidgetManagerSpeakerFileType fileType;                        音频文件类型
    E_DjiWidgetManagerSpeakerAudoBitrate fileBitrate;                  音频文件比特率
    uint8_t uuid[WIDGET_MANAGER_MAX_FILE_NAME_LEN];                    音频文件 UUID
    uint8_t fileName[WIDGET_MANAGER_MAX_FILE_NAME_LEN];                音频文件名
    uint8_t filePath[WIDGET_MANAGER_MAX_FILE_PATH_LEN];                音频文件的绝对路径
} T_DjiSpeakerAudioFileInfo;
```

### T_DjiSpeakerWidgetStates

喊话器控件状态信息。

```c
typedef struct {
    E_DjiWidgetSpeakerWorkMode workMode;                               工作模式
    E_DjiWidgetSpeakerPlayMode playMode;                               播放模式
    uint8_t playVloume;                                                音量
    E_DjiWidgetManagerSpeakerStates systemStates;                      系统状态
    uint8_t playFileUuid[WIDGET_MANAGER_MAX_FILE_NAME_LEN];            当前播放文件的 UUID
    uint8_t playFileName[WIDGET_MANAGER_MAX_FILE_NAME_LEN];            当前播放文件名
    uint8_t playQuality;                                               播放质量，每秒丢包率 [0-255] 映射到 0%-100%
    uint8_t actualVolume;                                              喊话器实际音量
    uint8_t limitVolumeOnTheGround;                                    飞行器在地面时的限制音量
} T_DjiSpeakerWidgetStates;
```

### RecvWidgetStatesCallback

- 功能：接收负载设备控件状态的回调函数类型。

::: tip 说明：
不建议在回调中执行阻塞操作，否则可能导致数据丢失。
:::

```c
typedef void (*RecvWidgetStatesCallback)(E_DjiMountPosition position, T_DjiWidgetStates *statesData, uint8_t widgetNum);
```

- 参数
  - position：控件状态所属负载设备的挂载位置。
  - statesData：指向控件状态数据。
  - widgetNum：控件数量。
