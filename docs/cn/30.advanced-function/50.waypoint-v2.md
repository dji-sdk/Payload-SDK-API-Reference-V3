
## 概述

本文档描述了 Waypoint V2 航点任务模块头文件`dji_waypoint_v2.h`和`dji_waypoint_v2_type.h`中的函数原型和数据类型定义。该模块用于规划和执行航点飞行任务，开发者可以通过该模块实现航点任务的上传、启动、停止、暂停和恢复等操作，并支持在航点间配置相机、云台和飞控动作。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

### E_DJIWaypointV2MissionFinishedAction

航点任务完成后飞行器执行的动作。

```c
typedef enum {
    DJI_WAYPOINT_V2_FINISHED_NO_ACTION,                 不执行任何动作，飞行器可由遥控器控制
    DJI_WAYPOINT_V2_FINISHED_GO_HOME,                   返航，若距返航点不足 20 米则直接降落
    DJI_WAYPOINT_V2_FINISHED_AUTO_LANDING,              在最后一个航点自动降落
    DJI_WAYPOINT_V2_FINISHED_GO_TO_FIRST_WAYPOINT,      返回第一个航点并悬停
    DJI_WAYPOINT_V2_FINISHED_CONTINUE_UNTIL_STOP,       在最后一个航点悬停，不结束任务，仅可通过调用停止任务接口结束
} E_DJIWaypointV2MissionFinishedAction;
```

```c
    DJI_WAYPOINT_V2_MISSION_KEEP_EXECUTE_WAYPOINT_V2,                        继续执行航点任务
```

### E_DJIWaypointV2FlightPathMode

```c

    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_ALONG_CURVE,                  沿曲线飞过航点，不停留
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_ALONG_CURVE_AND_STOP,         沿曲线飞往航点并停留
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_GO_TO_POINT_IN_STRAIGHT_AND_STOP,         沿直线飞往航点并停留
    DJI_WAYPOINT_V2_FLIGHT_PATH_MODE_COORDINATE_TURN,                          协调转弯，沿平滑曲线从前一航点飞往下一航点，不在此航点停留，受 dampingDistance 影响
```

### U_DjiWaypointV2EventData

航点任务事件数据联合体，根据不同事件类型包含不同的数据。

```c
typedef union {
    uint8_t interruptReason;       事件 0x01：任务中断原因，0x00 表示遥控器触发中断
    uint8_t recoverProcess;        事件 0x02：恢复过程状态（0x00：暂停恢复完成，0x10：开始从中断恢复，0x11：中断恢复完成，0x12：中断恢复失败）
    uint8_t exitReason;            事件 0x03：退出原因（0x00：成功完成，0x10：用户触发结束，0x20：地面起转时请求航线，0x21：自动起飞超时，0x22：自动起飞未达预定高度，0x23：自动起飞异常，0x24：被高优先级任务抢占，0x25：未知原因，0x26：航线规划失败）
    uint16_t waypointIndex;        事件 0x10：到达的航点索引
    struct T_DjiWaypointV2MissionExecEvent {
        uint8_t currentMissionExecTimes;              当前任务已执行次数
        uint8_t finishedAllMissExecTimes: 1;          0：未完成全部执行次数，1：已完成
        uint8_t reserved: 7;                          保留字段
    } T_DjiWaypointV2MissionExecEvent;                事件 0x11：航线完成事件
    uint8_t avoidState;                               事件 0x12：避障状态
    struct T_DjiWaypointV2ActionExecEvent {
        uint16_t actionId;                            动作 ID
        uint8_t preActuatorState;                     前一执行器状态（0x00：未挂载/未识别，0x01：空闲，0x02：运行中，0x03：已暂停）
        uint8_t curActuatorState;                     当前执行器状态（0x00：未挂载/未识别，0x01：空闲，0x02：运行中，0x03：已暂停）
        uint32_t result;                              错误码
    } T_DjiWaypointV2ActionExecEvent;                 事件 0x30：动作切换事件
} U_DjiWaypointV2EventData;
```
