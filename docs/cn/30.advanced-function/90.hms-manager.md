
## 概述

本文档描述了 HMS 管理模块头文件`dji_hms_manager.h`中的函数原型和数据类型定义。该模块用于获取飞行器的健康管理系统（HMS）信息，开发者可以通过该模块注册回调函数接收 HMS 推送数据，实时监控飞行器各组件的健康状态。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiHmsManager_Init

- 功能：初始化 HMS 管理模块。

::: tip 说明：
用户应在使用 HMS 功能之前调用此函数。
:::

```c
T_DjiReturnCode DjiHmsManager_Init(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiHmsManager_DeInit

- 功能：反初始化 HMS 管理模块。

```c
T_DjiReturnCode DjiHmsManager_DeInit(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiHmsManager_RegHmsInfoCallback

- 功能：注册回调函数以获取 HMS 信息。

::: tip 说明：
数据以 1Hz 的频率推送。
:::

```c
T_DjiReturnCode DjiHmsManager_RegHmsInfoCallback(DjiHmsInfoCallback callback);
```

- 参数
  - callback：HMS 信息回调函数，参见 DjiHmsInfoCallback。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### T_DjiHmsInfo

HMS 信息结构体，描述单条健康管理信息。

```c
typedef struct {
    uint32_t errorCode;        错误码
    uint8_t componentIndex;    组件索引
    uint8_t errorLevel;        错误等级
} T_DjiHmsInfo;
```

### T_DjiHmsInfoTable

HMS 信息表结构体，包含所有 HMS 信息的集合。

```c
typedef struct {
    T_DjiHmsInfo *hmsInfo;     HMS 信息数组指针
    uint32_t hmsInfoNum;       HMS 信息条数
} T_DjiHmsInfoTable;
```

### DjiHmsInfoCallback

- 功能：HMS 信息回调函数，用于接收飞行器健康管理系统的推送数据。

```c
typedef T_DjiReturnCode (*DjiHmsInfoCallback)(T_DjiHmsInfoTable hmsInfoTable);
```

- 参数
  - hmsInfoTable：HMS 信息表，参见 <a href="hms-manager.html#t-djihmsinfotable">T_DjiHmsInfoTable</a>。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>
