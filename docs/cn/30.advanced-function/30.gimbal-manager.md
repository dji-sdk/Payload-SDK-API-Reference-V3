
## 概述

本文档描述了云台管理模块头文件`dji_gimbal_manager.h`中的函数原型和数据类型定义。该模块用于控制飞行器上已安装的 DJI 云台，开发者可以通过该模块实现云台模式设置、转动控制、复位、俯仰角范围扩展、速度和平滑度调整、恢复出厂设置等功能。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

### DjiGimbalManager_SetPitchRangeExtensionEnabled

- 功能：启用或禁用云台俯仰限位扩展。

::: tip 说明：
启用后，云台的俯仰轴欧拉角限制将切换为扩展限制角度；禁用后恢复为默认限制角度。
:::

```c
T_DjiReturnCode DjiGimbalManager_SetPitchRangeExtensionEnabled(E_DjiMountPosition mountPosition, bool enabledFlag);
```

- 参数
  - mountPosition：云台挂载位置，输入限制参见 <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a>。
  - enabledFlag：指定是否启用或禁用云台俯仰限位扩展。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiGimbalManager_SetControllerMaxSpeedPercentage

- 功能：设置云台控制器的最大速度百分比。

```c
T_DjiReturnCode DjiGimbalManager_SetControllerMaxSpeedPercentage(E_DjiMountPosition mountPosition, E_DjiGimbalAxis axis, uint8_t maxSpeedPercentage);
```

- 参数
  - mountPosition：云台挂载位置，输入限制参见 <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a>。
  - axis：要设置的轴。
  - maxSpeedPercentage：最大速度百分比值，范围 1~100。建议计算公式为 "spd = default_max_spd * x / 100"，x 为设定值。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiGimbalManager_SetControllerSmoothFactor

- 功能：设置云台控制器的平滑因子。

```c
T_DjiReturnCode DjiGimbalManager_SetControllerSmoothFactor(E_DjiMountPosition mountPosition, E_DjiGimbalAxis axis, uint8_t smoothingFactor);
```

- 参数
  - mountPosition：云台挂载位置，输入限制参见 <a href="../system-base/dji-typedef.html#e-djimountposition">E_DjiMountPosition</a>。
  - axis：要设置的轴。
  - smoothingFactor：平滑因子，值越大，云台转动加速度越小，范围 1~30。建议计算公式为 "acc = 10000 * (0.8 ^ (1 + x)) deg/s^2"，x 为平滑因子值。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### T_DjiGimbalManagerRotation

定义云台管理旋转属性。

```c
typedef struct {
    E_DjiGimbalRotationMode rotationMode;    云台旋转模式
    dji_f32_t pitch;                         俯仰角，单位：度
    dji_f32_t roll;                          翻滚角，单位：度
    dji_f32_t yaw;                           偏航角，单位：度
    dji_f64_t time;                          预计执行时间，单位：秒
} T_DjiGimbalManagerRotation;
```
