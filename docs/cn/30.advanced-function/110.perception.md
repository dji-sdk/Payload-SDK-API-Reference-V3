

## 概述

本文档描述了感知数据模块头文件`dji_perception.h`中的函数原型和数据类型定义。该模块用于获取飞行器视觉感知系统的图像数据、激光雷达点云数据和毫米波雷达数据，开发者可以通过该模块订阅指定方向的感知图像、LiDAR 数据和雷达数据，用于障碍物检测、环境感知等应用。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

### DjiPerception_SubscribePerceptionImage

- 功能：订阅指定方向的双目立体相机原始图像。

::: tip 说明：
默认订阅频率为 20 Hz。
:::

```c
T_DjiReturnCode DjiPerception_SubscribePerceptionImage(E_DjiPerceptionDirection direction,
                                                       DjiPerceptionImageCallback callback);
```

- 参数
  - direction：指定订阅的方向，参考 <a href="perception.html#e-djiperceptiondirection">E_DjiPerceptionDirection</a>。
  - callback：感知图像数据回调函数指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### E_DjiPerceptionDirection

感知图像订阅方向。

```c
typedef enum {
    DJI_PERCEPTION_RECTIFY_DOWN = 0,      下方
    DJI_PERCEPTION_RECTIFY_FRONT = 1,     前方
    DJI_PERCEPTION_RECTIFY_REAR = 2,      后方
    DJI_PERCEPTION_RECTIFY_UP = 3,        上方
    DJI_PERCEPTION_RECTIFY_LEFT = 4,      左方
    DJI_PERCEPTION_RECTIFY_RIGHT = 5      右方
} E_DjiPerceptionDirection;
```

### E_DjiPerceptionCameraPosition

感知相机位置。

```c
typedef enum {
    RECTIFY_DOWN_LEFT = 1,       下方左相机
    RECTIFY_DOWN_RIGHT = 2,      下方右相机
    RECTIFY_FRONT_LEFT = 3,      前方左相机
    RECTIFY_FRONT_RIGHT = 4,     前方右相机
    RECTIFY_REAR_LEFT = 5,       后方左相机
    RECTIFY_REAR_RIGHT = 6,      后方右相机
    RECTIFY_UP_LEFT = 21,        上方左相机
    RECTIFY_UP_RIGHT = 22,       上方右相机
    RECTIFY_LEFT_LEFT = 23,      左方左相机
    RECTIFY_LEFT_RIGHT = 24,     左方右相机
    RECTIFY_RIGHT_LEFT = 25,     右方左相机
    RECTIFY_RIGHT_RIGHT = 26     右方右相机
} E_DjiPerceptionCameraPosition;
```

### E_DjiPerceptionRadarPosition

感知雷达安装位置。

```c
typedef enum {
    RADAR_POSITION_LEFT = 0,     左方
    RADAR_POSITION_RIGHT = 1,    右方
    RADAR_POSITION_DOWN = 2,     下方
    RADAR_POSITION_UP = 3,       上方
    RADAR_POSITION_FRONT = 4,    前方
    RADAR_POSITION_BACK = 5,     后方
    MAX_RADAR_NUM = 6            雷达最大数量
} E_DjiPerceptionRadarPosition;
```

### T_DjiPerceptionRawImageInfo

感知原始图像信息。

```c
typedef struct {
    uint32_t index;        图像索引
    uint8_t direction;     图像方向
    uint8_t bpp;           每像素比特数
    uint32_t width;        图像宽度，单位：像素
    uint32_t height;       图像高度，单位：像素
} T_DjiPerceptionRawImageInfo;
```

### T_DjiPerceptionImageInfo

感知图像信息。

```c
typedef struct {
    T_DjiPerceptionRawImageInfo rawInfo;    原始图像信息
    uint16_t dataId;                        数据 ID
    uint16_t sequence;                      序列号
    uint32_t dataType;                      数据类型，参考 E_DjiPerceptionCameraPosition
    uint64_t timeStamp;                     时间戳
} T_DjiPerceptionImageInfo;
```

### T_DjiPerceptionCameraParameters

单方向双目立体相机参数。

```c
typedef struct {
    uint8_t direction;                                                  相机方向
    float leftIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];    左相机内参
    float rightIntrinsics[DJI_PERCEPTION_INTRINSICS_PARAM_ARRAY_NUM];   右相机内参
    float rotationLeftInRight[DJI_PERCEPTION_ROTATION_PARAM_ARRAY_NUM];       左相机在右相机坐标系中的旋转矩阵
    float translationLeftInRight[DJI_PERCEPTION_TRANSLATION_PARAM_ARRAY_NUM]; 左相机在右相机坐标系中的平移向量
} T_DjiPerceptionCameraParameters;
```

### T_DjiPerceptionCameraParametersPacket

所有方向双目立体相机参数数据包。

```c
typedef struct {
    uint32_t timeStamp;                                                        时间戳
    uint32_t directionNum;                                                     方向数量
    T_DjiPerceptionCameraParameters cameraParameters[IMAGE_MAX_DIRECTION_NUM]; 各方向相机参数数组
} T_DjiPerceptionCameraParametersPacket;
```

### T_DJIPerceptionLidarPoint

激光雷达单点数据信息。

```c
typedef struct {
    float   x;             x 坐标，单位：米
    float   y;             y 坐标，单位：米
    float   z;             z 坐标，单位：米
    uint8_t intensity;     反射强度
    uint8_t label;         噪声过滤结果（0: 目标; 1: 噪声; 2: 未知; 3: 无回波）
} T_DJIPerceptionLidarPoint;
```

### T_DJIPerceptionLidarDataHeader

激光雷达每包数据的头信息。

```c
typedef struct {
    uint16_t timeInterval;     点云采样时间间隔，单位：0.1 微秒
    uint16_t dotNum;           当前包中包含的点数，非重复扫描时该字段无效
    uint8_t  dataType;         数据类型，高 4 位为回波模式（0~4 对应单回波至五回波），低 4 位为数据类型（1: 32 位直角坐标点云; 2: 16 位直角坐标点云; 3: 球坐标点云; 4: 20 位直角坐标点云; 40: IMU 数据）
    uint8_t  timeType;         时间戳类型（0: 雷达运行时间; 1: gPTP/PTP 同步时间; 2: PPS+ns 时间同步; 3: PPS+UTC）
    uint64_t timeStamp;        时间戳
} T_DJIPerceptionLidarDataHeader;
```

### T_DjiPerceptionLidarDecodePkg

激光雷达解码后的单包数据。

```c
typedef struct {
    T_DJIPerceptionLidarDataHeader  header;                    数据包头信息
    T_DJIPerceptionLidarPoint       points[DJI_PTS_NUM_PER_PKG]; 点云数据数组，每包最多 96 个点
} T_DjiPerceptionLidarDecodePkg;
```

### T_DjiLidarFrame

激光雷达完整帧数据。

```c
typedef struct {
    uint64_t  timeStampNs;     每包第一个点的时间戳，单位：纳秒
    uint32_t  frameCnt;        帧计数，从 0 递增
    uint16_t  pkgNum;          每帧的有效包数量
    T_DjiPerceptionLidarDecodePkg pkgs[DJI_LIDAR_PKG_BUFFER_NUM]; 数据包数组
    uint32_t  poseTimeMs;      姿态时间，单位：毫秒
    uint16_t  naviFlag;        导航状态标志位（各 bit 含义详见头文件注释）
    float     naviPos[3];      无人机 IMU 到导航坐标系的平移向量 (x, y, z)
    float     naviQuat[4];     无人机 IMU 到导航坐标系的四元数
} T_DjiLidarFrame;
```

### T_DjiRadarDataHeader

毫米波雷达数据帧头信息。

```c
typedef struct {
    uint16_t dataLen;      数据长度
    uint8_t  curPack;      当前包编号，范围 [1, packNum]
    uint8_t  packNum;      当前圈的总包数，从 1 开始
} T_DjiRadarDataHeader;
```

### T_DjiRadarBaseInfo

毫米波雷达基础信息。

```c
typedef struct {
    uint64_t velocity  :16;      目标速度，实际速度 (m/s) = (velocity - 32767) / 100，正值为靠近，负值为远离
    uint64_t snr       :7;       目标信噪比，单位：dB，范围 0~127，0 表示无回波
    uint64_t beamAngle :10;      波束发射角，单位：0.01 度，存储范围 0~1023，实际范围 [-45°, 45°]
    uint64_t radarType :3;       雷达编号，M400 上无效
    uint64_t clitterFlag :1;     杂波标志位，1 为杂波点，0 为有效点
    uint64_t reserved  :27;      保留字段
} T_DjiRadarBaseInfo;
```

### T_DjiRadarCloudUnit

毫米波雷达单点数据。

```c
typedef struct {
    uint16_t azimuth;              目标方位角，单位：0.001 弧度，实际值 = azimuth / 1000 - 2π
    uint16_t elevation;            目标俯仰角，单位：0.001 弧度，实际值 = elevation / 1000 - 2π
    uint16_t radius;               目标径向距离，单位：0.01 米，范围 0~65553
    uint16_t ene;                  雷达目标能量，实际值 = ene / 100，M400 上无效
    T_DjiRadarBaseInfo base_info;  雷达基础信息
} T_DjiRadarCloudUnit;
```

### T_DjiRadarDataFrame

毫米波雷达数据帧。

```c
typedef struct {
    T_DjiRadarDataHeader headInfo;     数据帧头信息
    T_DjiRadarCloudUnit data[1];       雷达点云数据（柔性数组）
} T_DjiRadarDataFrame;
```

### DjiPerceptionImageCallback

- 功能：感知图像数据回调函数原型。

::: tip 说明：
不建议在回调函数中执行阻塞操作，否则可能导致数据丢失。
:::

```c
typedef void (*DjiPerceptionImageCallback)(T_DjiPerceptionImageInfo imageInfo,
                                           uint8_t *imageRawBuffer,
                                           uint32_t bufferLen);
```

- 参数
  - imageInfo：感知图像信息。
  - imageRawBuffer：图像原始数据缓冲区指针。
  - bufferLen：缓冲区长度，单位：字节。
- 返回值
  - 无
