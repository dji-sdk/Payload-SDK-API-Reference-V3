
## 概述

本文档描述了获取相机码流模块头文件`dji_liveview.h`中的函数原型和数据类型定义。该模块用于获取飞行器上各相机的实时码流数据，开发者可以通过该模块订阅指定相机位置和码流类型的 H.264 视频流，获取解码后的图像数据，以及进行 H.264 编码、目标识别标注等操作。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

### DjiLiveview_StartH264Stream

- 功能：按选定位置启动 FPV 或相机 H.264 码流。

```c
T_DjiReturnCode DjiLiveview_StartH264Stream(E_DjiLiveViewCameraPosition position, E_DjiLiveViewCameraSource source,
                                            DjiLiveview_H264Callback callback);
```

- 参数
  - position：指定输出 H.264 码流的相机位置。
  - source：指定输出 H.264 码流的子相机源。
  - callback：接收到新的 H.264 帧时在回调线程中调用的回调函数。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_StopH264Stream

- 功能：按选定位置停止 FPV 或相机 H.264 码流。

```c
T_DjiReturnCode DjiLiveview_StopH264Stream(E_DjiLiveViewCameraPosition position, E_DjiLiveViewCameraSource source);
```

- 参数
  - position：指定停止 H.264 码流的相机位置。
  - source：指定停止 H.264 码流的子相机源。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_StartImageStream

- 功能：请求获取指定位置的解码图像数据。

::: tip 说明：
此接口仅在 DJI Manifold 3 上支持。
:::

```c

                                            E_DjiLiveViewPixFormate pixFmt, DjiLiveview_ImageCallback callback);
```

- 参数
  - position：指定 H.264 码流的相机位置。
  - source：指定 H.264 码流的子相机源。
  - pixFmt：请求的图像格式，参见 <a href="liveview.html#e-djiliveviewpixformate">E_DjiLiveViewPixFormate</a>。

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_EncodeAFrameToH264

- 功能：将图像编码为 H.264 码流。

::: tip 说明：
* 如果不需要目标识别相关信息，metaData 参数可填入 NULL。
* 此接口需在 DjiLiveview_RegEncoderCallback 之后使用。
* 此接口仅在 DJI Manifold 3 上支持。
:::

```c
T_DjiReturnCode DjiLiveview_EncodeAFrameToH264(const uint8_t *buf, uint32_t len, T_DjiLiveviewImageInfo imageInfo,
                                               T_DjiLiveViewStandardMetaData *metaData);
```

- 参数
  - buf：图像原始数据。
  - len：图像数据长度。
  - imageInfo：图像信息，参见 <a href="liveview.html#t-djiliveviewimageinfo">T_DjiLiveviewImageInfo</a>。
  - metaData：图像目标识别的结果信息，参见 <a href="liveview.html#t-djiliveviewstandardmetadata">T_DjiLiveViewStandardMetaData</a>。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiLiveview_RegUserAiTargetLableList

:::

```c

```

- 参数
  - lableCount：标签数量。
  - labels：标签字符串数组。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### T_DjiLiveViewTarget2dBox

目标识别结果的画面框信息结构体。

```c
typedef struct {
    uint16_t cx;            中心点 X 坐标，单位：万分之一屏幕宽度
    uint16_t cy;            中心点 Y 坐标，单位：万分之一屏幕高度
    uint16_t w;             框宽度，单位：万分之一屏幕宽度
    uint16_t h;             框高度，单位：万分之一屏幕高度
    uint32_t distance;      距离，单位：毫米
} T_DjiLiveViewTarget2dBox;
```

### T_DjiLiveViewBoundingBox

目标识别边界框信息结构体。

```c
typedef struct {
```


### DjiLiveview_H264Callback

- 功能：H.264 码流数据回调函数，用于接收指定相机的 H.264 视频帧数据。

