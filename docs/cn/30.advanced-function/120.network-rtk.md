

## 概述

本文档描述了网络 RTK 模块头文件`dji_network_rtk.h`中的函数原型和数据类型定义。该模块用于连接网络 RTK 服务（NTRIP 协议），为飞行器提供高精度差分定位数据，开发者可以通过该模块配置 RTK 服务参数、启停服务并监听服务状态。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiNetworkRtk_RegReceiveNetworkRtkStateCallback

- 功能：注册网络 RTK 状态回调函数。

::: tip 说明：
建议在启动服务前注册。
:::

```c
T_DjiReturnCode DjiNetworkRtk_RegReceiveNetworkRtkStateCallback(DjiReceiveNetworkRtkStateCallback callback);
```

- 参数
  - callback：指向状态回调函数的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiNetworkRtk_StartService

- 功能：启动网络 RTK 服务。

::: tip 说明：
* 如果当前 RTK 源非自定义网络源，首次调用后需手动重启设备切换 RTK 源，重启后再次调用该接口。
* DJI_REBOOTING 状态表示需要重启设备。
* DJI_TRANSFER 状态表示数据传输已建立，但不保证 RTK 解已收敛。
:::

```c
T_DjiReturnCode DjiNetworkRtk_StartService(const T_DjiNetworkRtkServiceConfig *config);
```

- 参数
  - config：指向网络 RTK 服务配置的指针，参考 <a href="network-rtk.html#t-djinetworkrtkserviceconfig">T_DjiNetworkRtkServiceConfig</a>。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiNetworkRtk_StopService

- 功能：停止网络 RTK 服务。

```c
T_DjiReturnCode DjiNetworkRtk_StopService(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### E_DjiNetworkRtkOnboardState

网络 RTK 状态。

```c
typedef enum {
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_LOG_IN = 0,        登录中
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_CONNECTING = 1,    连接中
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_TRANSFER = 2,      数据传输中
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_RECONNECT = 3,     重连中
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_BROKEN = 4,        连接断开
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_STOPPING = 5,      停止中
    DJI_NETWORK_RTK_ONBOARD_STATE_DJI_REBOOTING = 6      重启中
} E_DjiNetworkRtkOnboardState;
```

### T_DjiNetworkRtkServiceConfig

网络 RTK 服务配置。

```c
typedef struct {
    char account[16];        账号
    char password[64];       密码
    char host[64];           服务器地址，仅支持 IP，不支持域名
    char port[6];            端口号
    char mountPoint[32];     挂载点
} T_DjiNetworkRtkServiceConfig;
```

### DjiReceiveNetworkRtkStateCallback

- 功能：网络 RTK 状态回调函数原型。

```c
typedef void (*DjiReceiveNetworkRtkStateCallback)(E_DjiNetworkRtkOnboardState state);
```

- 参数
  - state：当前网络 RTK 状态，参考 <a href="network-rtk.html#e-djinetworkrtkonboardstate">E_DjiNetworkRtkOnboardState</a>。
- 返回值
  - 无
