## 概述

本文档描述了飞行控制模块头文件`dji_flight_controller.h`中的函数原型和数据类型定义。该模块用于控制飞行器的飞行行为，开发者可以通过该模块实现起飞降落、返航控制、Joystick 虚拟摇杆控制、飞行参数设置、控制权限管理等功能。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiFlightController_SetAllAvoidAction

- 功能：设置全局雷达避障动作。
- 支持的机型：FlyCart 100

::: tip 说明：
仅支持 FC100。
:::

```c
T_DjiReturnCode DjiFlightController_SetAllAvoidAction(E_DjiFlightControllerCloseAllAvoidCommand allAction);
```

- 参数
  - allAction：全局避障动作，参见 <a href="flight-controller.html#e-djiflightcontrollercloseallavoidcommand">E_DjiFlightControllerCloseAllAvoidCommand</a> 的定义。与 Pilot 参数同步。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiFlightController_SetControlInAttitudeModeEnabled

- 功能：启用或禁用飞行器处于姿态（ATTI）模式时的 PSDK 控制权限。

::: tip 说明：

:::

```c

```

- 参数
  - enabled：启用标志。true：允许在 ATTI 模式下进行 PSDK 控制；false：不允许在 ATTI 模式下进行 PSDK 控制。

### DjiFlightController_ArrestFlying

- 功能：紧急制动飞行。

::: tip 说明：
* 当无人机在地面时，它会停止电机并在 APP 上显示 "hms description"。

* 只有当 GPS 信号良好（health_flag >=3）或高级感应系统与 Autopilot 正常工作时，才可使用与水平速度控制（DJI_FLIGHT_CONTROLLER_HORIZONTAL_VELOCITY_CONTROL_MODE）相关的控制模式。
:::

```c
typedef enum {
/**
 * @brief 控制飞行器的俯仰、横滚角度。
 * @note 参考 E_DjiFlightControllerHorizontalCoordinate 设置的地面或机身坐标系。
 * 限制: -35 度至 35 度
 */
DJI_FLIGHT_CONTROLLER_HORIZONTAL_ANGLE_CONTROL_MODE = 0,
/**
 * @brief 设置控制模式以控制水平速度。
 * @note 参考 E_DjiFlightControllerHorizontalCoordinate 设置的地面或机身坐标系。
 * 限制: -30m/s 至 30m/s
 */
DJI_FLIGHT_CONTROLLER_HORIZONTAL_VELOCITY_CONTROL_MODE = 1,
/**
 * @brief 设置控制模式以控制俯仰和横滚方向的位置偏移。
 * @note 参考 E_DjiFlightControllerHorizontalCoordinate 设置的地面或机身坐标系。
 * 限制: 无
 */
DJI_FLIGHT_CONTROLLER_HORIZONTAL_POSITION_CONTROL_MODE = 2,
/**
 * @brief 设置控制模式以控制飞行器偏航角变化率。
 * @note 参考 E_DjiFlightControllerHorizontalCoordinate 设置的地面或机身坐标系。
 * 限制: -150deg/s 至 150deg/s
 */
DJI_FLIGHT_CONTROLLER_HORIZONTAL_ANGULAR_RATE_CONTROL_MODE = 3
} E_DjiFlightControllerHorizontalControlMode;
```

### E_DjiFlightControllerVerticalControlMode

摇杆模式下的垂直控制方式枚举。

::: tip 说明：
建议开发者在无人机飞行高度超过 3 米的室内环境中不要使用 VERTICAL_POSITION 控制模式。因为在室内环境中，气压计可能不准确，垂直控制器可能无法维持无人机的高度。
:::

```c
typedef enum {
/**
 * @brief 设置控制模式以控制无人机的垂直速度，上升为正。
 * @note 限制: -5m/s 至 5m/s
 */
DJI_FLIGHT_CONTROLLER_VERTICAL_VELOCITY_CONTROL_MODE = 0,

/**
 * @brief 设置控制模式以控制无人机的高度。
 * @note 限制: 0m 至 120m
 */
DJI_FLIGHT_CONTROLLER_VERTICAL_POSITION_CONTROL_MODE = 1,

/**
 * @brief 设置控制模式以直接控制推力。
 * @note 范围: 0% 至 100%
 */
DJI_FLIGHT_CONTROLLER_VERTICAL_THRUST_CONTROL_MODE = 2,
} E_DjiFlightControllerVerticalControlMode;
```

### E_DjiFlightControllerStableControlMode

摇杆模式下的稳定模式枚举。

::: tip 说明：
* 仅在水平速度控制模式中工作。
* 在速度稳定模式中，一旦输入命令为零，无人机将刹车并悬停在一个位置。
* 在速度非稳定模式中，无人机将根据速度命令移动，并在命令为零时不会悬停，这意味着无人机将随风飘移。
:::

```c
typedef enum {
DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_DISABLE = 0,  禁用稳定模式
DJI_FLIGHT_CONTROLLER_STABLE_CONTROL_MODE_ENABLE = 1    启用稳定模式
} E_DjiFlightControllerStableControlMode;
```
