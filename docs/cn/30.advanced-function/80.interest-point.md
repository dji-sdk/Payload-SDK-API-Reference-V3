

## 概述

本文档描述了兴趣点环绕模块头文件`dji_interest_point.h`中的函数原型和数据类型定义。该模块用于控制飞行器围绕指定兴趣点进行环绕飞行，开发者可以通过该模块设置兴趣点位置和环绕速度，并实时获取环绕任务状态。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 数据类型定义

### E_DjiInterestPointActionState

环绕任务动作状态。

```c
typedef enum {
    DJI_INTEREST_POINT_ACTION_STATE_NOT_STARTED = 0,    未启动
    DJI_INTEREST_POINT_ACTION_STATE_PAUSE = 1,          已暂停
    DJI_INTEREST_POINT_ACTION_STATE_RUNNING = 2         运行中
} E_DjiInterestPointActionState;
```

### T_DjiInterestPointMissionState

环绕任务状态。

```c
typedef struct {
    dji_f32_t curSpeed;                        当前环绕速度
    dji_f32_t radius;                          环绕半径
    E_DjiInterestPointActionState state;       当前任务动作状态
} T_DjiInterestPointMissionState;
```

### T_DjiInterestPointSettings

兴趣点环绕配置。

```c
typedef struct {
    dji_f64_t latitude;              兴趣点纬度，单位：度
    dji_f64_t longitude;             兴趣点经度，单位：度
    dji_f32_t speed;                 环绕速度
    uint8_t payloadCameraIndex;      负载相机索引，从 1 开始
} T_DjiInterestPointSettings;
```

### InterestPointMissionStateCallback

- 功能：环绕任务状态回调函数原型。

```c
typedef void (*InterestPointMissionStateCallback)(T_DjiInterestPointMissionState missionState);
```

- 参数
  - missionState：当前环绕任务状态。
- 返回值
  - 无
