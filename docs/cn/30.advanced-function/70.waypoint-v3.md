
## 概述

本文档描述了 Waypoint V3 航点任务模块头文件`dji_waypoint_v3.h`中的函数原型和数据类型定义。该模块用于通过 KMZ 文件规划和执行航点飞行任务，开发者可以通过该模块实现航线任务的上传、执行、暂停、恢复和停止等操作。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 数据类型定义

### E_DjiWaypointV3Action

Waypoint V3 任务动作枚举。

```c
typedef enum {
    DJI_WAYPOINT_V3_ACTION_START = 0,     启动任务
    DJI_WAYPOINT_V3_ACTION_STOP = 1,      停止任务
    DJI_WAYPOINT_V3_ACTION_PAUSE = 2,     暂停任务
    DJI_WAYPOINT_V3_ACTION_RESUME = 3,    恢复任务
} E_DjiWaypointV3Action;
```

### E_DjiWaypointV3MissionState

Waypoint V3 飞行器当前任务状态枚举。

```c
typedef enum {
    DJI_WAYPOINT_V3_MISSION_STATE_IDLE = 0,                空闲状态
    DJI_WAYPOINT_V3_MISSION_STATE_PREPARE = 16,            准备状态
    DJI_WAYPOINT_V3_MISSION_STATE_TRANS_MISSION = 32,      任务传输中
    DJI_WAYPOINT_V3_MISSION_STATE_MISSION = 48,            任务执行中
    DJI_WAYPOINT_V3_MISSION_STATE_BREAK = 64,              任务中断
    DJI_WAYPOINT_V3_MISSION_STATE_RESUME = 80,             任务恢复中
    DJI_WAYPOINT_V3_MISSION_STATE_RETURN_FIRSTPOINT = 98,  返回首航点
} E_DjiWaypointV3MissionState;
```

### E_DjiWaypointV3ActionState

Waypoint V3 飞行器当前动作状态枚举。

```c
typedef enum {
    DJI_WAYPOINT_V3_ACTION_STATE_IDLE = 0,        动作空闲状态
    DJI_WAYPOINT_V3_ACTION_STATE_RUNNING = 1,     动作执行中
    DJI_WAYPOINT_V3_ACTION_STATE_FINISHED = 5,    动作执行完成
} E_DjiWaypointV3ActionState;
```

### T_DjiWaypointV3MissionState

Waypoint V3 任务状态信息结构体。

```c
typedef struct {
    E_DjiWaypointV3MissionState state;          当前任务状态
    uint32_t wayLineId;                         当前航线 ID
    uint16_t currentWaypointIndex;              当前航点索引
} T_DjiWaypointV3MissionState;
```

### T_DjiWaypointV3ActionState

Waypoint V3 动作状态信息结构体。

```c
typedef struct {
    E_DjiWaypointV3ActionState state;           当前动作状态
    uint32_t wayLineId;                         当前航线 ID
    uint16_t currentWaypointIndex;              当前航点索引
    uint16_t actionGroupId;                     当前动作组索引
    uint16_t actionId;                          当前动作索引
} T_DjiWaypointV3ActionState;
```
