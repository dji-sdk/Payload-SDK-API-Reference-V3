## 宏定义、枚举与结构体

#### <font id=1 color="#AAA">typedef struct</font> <font color="#44a8f2">T_DjiGimbalManagerRotation</font>

云台管理器旋转命令属性

```c
typedef struct {
    E_DjiGimbalRotationMode rotationMode;  旋转云台模式 
    dji_f32_t pitch;  以度为单位的俯仰角，单位：度 
    dji_f32_t roll;  以度为单位的横滚角，单位：度 
    dji_f32_t yaw;  以度为单位的偏航角，单位：度 
    dji_f64_t time;  云台旋转预计执行时间，单位：秒 
} T_DjiGimbalManagerRotation;
```
