## 宏定义、枚举与结构体

#### <font id=1 color="#AAA">typedef function</font> <font color="#44a8f2"> DjiGetNewestPpsTriggerLocalTimeUsCallback </font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：获取最新的PPS触发的时间戳 </td>  
      <td>product：all</td>
    </tr>
</table>

用于获取最新 PPS 触发时间戳的回调函数原型。

> **说明：** 用户不能在回调函数中执行阻塞式操作或函数，因为这会阻塞 DJI 根线程，导致系统响应慢、负载断开或死循环等问题。

```c
typedef T_PsdkReturnCode (*GetNewestPpsTriggerLocalTimeUsCallback)(uint64_t *localTimeUs);
```

<font color="#AAA">参数</font>        
<br/><font color="#70BF41">localTimeUs</font>：指向用于存储 PPS 触发时间戳的内存空间的指针。     
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>



#### <font id=2 color="#AAA">typedef struct</font> <font color="#44a8f2">T_DjiTimeSyncAircraftTime</font>

无人机中时间系统的数据结构

```c
typedef struct {
    uint16_t year;          年
    uint8_t month;          月，1～12
    uint8_t day;            日，1～31
    uint8_t hour;           小时，0～23
    uint8_t minute;         分钟，0～59
    uint8_t second;         秒，0～59
    uint32_t microsecond;   微秒，0～999999.
} T_DjiTimeSyncAircraftTime;
```



## 函数原型
#### <font id=3 color="#AAA">function</font> <font color="#44a8f2"> DjiTimeSync_Init </font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：初始化时间同步功能模块 </td>  
      <td>product：all</td>
    </tr>
</table>

在阻塞模式下初始化时间同步模块。 用户应在所有其他时间同步操作之前调用此函数，就像传输时间一样。

> **说明：**
> * 该函数的最大执行时间略大于 2000ms。
> * 该函数必须在用户任务中调用，而不是 main() 函数，并且在调度程序启动后调用。

```c
T_DjiReturnCode DjiTimeSync_Init(void);
```

<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>

#### <font id=4 color="#AAA">function</font> <font color="#44a8f2"> DjiTimeSync_RegGetNewestPpsTriggerTimeCallback </font>
   
<table style="text-align:left;border:none">

      <td>product：all</td>

注册回调函数，用于在检测到 PPS 上升沿信号时获取本地时间系统中的最新时间戳。

```c
T_DjiReturnCode DjiTimeSync_RegGetNewestPpsTriggerTimeCallback(DjiGetNewestPpsTriggerLocalTimeUsCallback callback);
```

<font color="#AAA">参数</font>        
<br/><font color="#70BF41">callback</font>：指向回调函数的指针。
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>

#### <font id=5 color="#AAA">function</font> <font color="#44a8f2"> DjiTimeSync_TransferToAircraftTime </font>
   
<table style="text-align:left;border:none">
    <tr>
      <td>功能：时间转换 </td>  
      <td>product：all</td>
    </tr>
</table>

将负载设备的本地时间转换为无人机上的时间。

> **说明：** 
> 在使用本接口时，请调用PsdkTimeSync_RegGetNewestPpsTriggerTimeCallback() 注册用于获取负载设备检测到PPS 信号上升沿时，负载设备本地最新的时间戳的回调函数。

```c
T_DjiReturnCode DjiTimeSync_TransferToAircraftTime(uint64_t localTimeUs, T_DjiTimeSyncAircraftTime *aircraftTime);
```

<font color="#AAA">参数</font>        
<br/><font color="#70BF41">localTimeUs</font>：负载设备中的本地时间，单位：微秒     
<br/><font color="#70BF41">aircraftTime</font>：指向用于存储无人机系统时间的内存空间     
<br/><font color="#AAA">返回值</font>
<br/>根据程序执行的情况输出对应的返回值，详情请参见：<a href="../core/dji-error.html">DjiErrorCode</a>
