

## 概述

本文档描述了电源管理模块头文件`dji_power_management.h`中的函数原型和数据类型定义。该模块用于管理负载设备的供电与关机流程，开发者可以通过该模块申请高功率供电、注册高功率引脚控制回调函数，以及注册关机通知回调函数以响应飞行器的关机事件。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiPowerManagement_Init

- 功能：初始化电源管理模块。

::: tip 说明：
用户在使用电源管理功能前应调用该函数。
:::

```c
T_DjiReturnCode DjiPowerManagement_Init(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_DeInit

- 功能：反初始化电源管理模块。

::: tip 说明：
用户在不再使用电源管理功能时应调用该函数。
:::

```c
T_DjiReturnCode DjiPowerManagement_DeInit(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_ApplyHighPowerSync

- 功能：以同步阻塞方式从飞机申请高功率供电。

::: tip 说明：
* 在申请高功率之前，用户应先使用 DjiPowerManagement_RegWriteHighPowerApplyPinCallback() 函数注册回调函数，用于设置高功率应用引脚的电平状态。
* 申请高功率后，DJI 适配器的电源引脚将根据预定规格输出大功率。
* 该函数的最大执行时间略大于 600ms。
:::

```c
T_DjiReturnCode DjiPowerManagement_ApplyHighPowerSync(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_ApplyHighPowerSyncV2

- 功能：以同步阻塞方式从飞机申请指定电压的高功率供电。

::: tip 说明：
* 在申请高功率之前，用户应先使用 DjiPowerManagement_RegWriteHighPowerApplyPinCallback() 函数注册回调函数，用于设置高功率应用引脚的电平状态。
* 申请高功率后，DJI 适配器的电源引脚将按照指定电压输出大功率。
* 该函数的最大执行时间略大于 600ms。
:::

```c
T_DjiReturnCode DjiPowerManagement_ApplyHighPowerSyncV2(E_DjiHighPowerVoltage voltage);
```

- 参数
  - voltage：需要施加到 VCC 引脚的电压值，参考 <a href="power-management.html#e-djihighpowervoltage">E_DjiHighPowerVoltage</a>。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_RegWriteHighPowerApplyPinCallback

- 功能：注册回调函数，用于设置高功率应用引脚的电平状态。

::: tip 说明：
必须在申请高功率之前调用。
:::

```c
T_DjiReturnCode DjiPowerManagement_RegWriteHighPowerApplyPinCallback(DjiWriteHighPowerApplyPinCallback callback);
```

- 参数
  - callback：指向回调函数的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_RegPowerOffNotificationCallback

- 功能：注册关机通知回调函数，用于通知负载设备飞机即将关机并获取负载设备的关机准备状态。

::: tip 说明：
* 注册完成后，飞行器关机时会以固定频率调用回调函数。
* 用户在回调函数中填写关机准备标志，一旦负载设备准备好关机，回调函数将不再被调用。
* 在指定时间（10s）后，如果负载未准备好关机，飞行器将立即关机。
:::

```c
T_DjiReturnCode DjiPowerManagement_RegPowerOffNotificationCallback(DjiPowerOffNotificationCallback callback);
```

- 参数
  - callback：指向回调函数的指针，用于通知飞机关机消息并获取负载设备关机准备标志。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerManagement_OutputHighPower

- 功能：Manifold 3 向外部设备输出高压。

::: tip 说明：
* 在请求高压输出前，需将 Manifold 3 的 gpio12 拉低。
* 该接口仅在 DJI Manifold 3 上支持。
:::

```c
T_DjiReturnCode DjiPowerManagement_OutputHighPower(bool stat);
```

- 参数
  - stat：true 表示输出高压，false 表示输出低压。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### E_DjiPowerManagementPinState

高功率引脚的状态。

```c
typedef enum {
    DJI_POWER_MANAGEMENT_PIN_STATE_RESET = 0,    引脚为低电压
    DJI_POWER_MANAGEMENT_PIN_STATE_SET = 1,      引脚为高电压
} E_DjiPowerManagementPinState;
```

### E_DjiHighPowerVoltage

高功率输出电压等级。

```c
typedef enum {
    E_DJI_HIGH_POWER_VOLTAGE_13V6 = 0,    输出电压 13.6V
    E_DJI_HIGH_POWER_VOLTAGE_17V = 1,     输出电压 17V
    E_DJI_HIGH_POWER_VOLTAGE_24V = 2,     输出电压 24V
} E_DjiHighPowerVoltage;
```

### DjiWriteHighPowerApplyPinCallback

- 功能：设置高功率引脚状态的回调函数。

```c
typedef T_DjiReturnCode (*DjiWriteHighPowerApplyPinCallback)(E_DjiPowerManagementPinState pinState);
```

- 参数
  - pinState：高功率引脚的状态。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiPowerOffNotificationCallback

- 功能：通知负载设备无人机将要关机并获取负载设备关机准备状态的回调函数。

::: tip 说明：
为防止该函数阻塞 PSDK 的主线程，导致出现程序响应缓慢、相机类负载设备断连及死循环等问题，请勿以阻塞的方式在回调函数中执行该函数。
:::

```c
typedef T_DjiReturnCode (*DjiPowerOffNotificationCallback)(bool *powerOffPreparationFlag);
```

- 参数
  - powerOffPreparationFlag：指向用于存储关机准备状态的内存空间。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>
