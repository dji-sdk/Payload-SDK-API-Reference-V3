

## 概述

本文档描述了信息管理模块头文件`dji_aircraft_info.h`中的函数原型和数据类型定义。该模块用于获取飞行器系统和移动设备 App 的基础信息，包括当前连接的飞行器类型、适配器类型、负载安装位置、飞行器版本号、连接状态以及增强图传状态等。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiAircraftInfo_GetBaseInfo

- 功能：获取飞行器系统的基本信息。

::: tip 说明：
获取飞行器系统的基本信息，包括飞行器类型和 DJI 适配器类型。
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetBaseInfo(T_DjiAircraftInfoBaseInfo *baseInfo);
```

- 参数
  - baseInfo：指向用于存储飞机系统基本信息的内存空间的指针。
- 返回值
  - 根据程序执行情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetMobileAppInfo

- 功能：获取移动设备 App 的基础信息。

::: tip 说明：
如果遥控器或 App 未连接飞行器系统，移动设备 App 语言和屏幕类型未知。
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetMobileAppInfo(T_DjiMobileAppInfo *mobileAppInfo);
```

- 参数
  - mobileAppInfo：指向用于存储移动 App 相关信息的内存空间的指针。
- 返回值
  - 根据程序执行情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetConnectionStatus

- 功能：获取负载设备与飞行器之间的连接状态。

::: tip 说明：
更新频率为 1Hz。
:::

```c
T_DjiReturnCode DjiAircraftInfo_GetConnectionStatus(bool *isConnected);
```

- 参数
  - isConnected：指向连接状态的指针，true 表示已连接，false 表示未连接。
- 返回值
  - 根据程序执行情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetAircraftVersion

- 功能：获取飞行器的版本信息。

```c
T_DjiReturnCode DjiAircraftInfo_GetAircraftVersion(T_DjiAircraftVersion *aircraftVersion);
```

- 参数
  - aircraftVersion：指向飞行器版本信息的指针。
- 返回值
  - 根据程序执行情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiAircraftInfo_GetEnhancedTransmission

- 功能：获取增强图传状态，该状态在移动端 App 的图传设置中配置。

```c
T_DjiReturnCode DjiAircraftInfo_GetEnhancedTransmission(E_DjiEnhancedTransmissionState *state);
```

- 参数
  - state：指向增强图传状态的指针。
- 返回值
  - 根据程序执行情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### T_DjiMobileAppInfo

移动设备 App 相关信息。

```c
typedef struct {
    E_DjiMobileAppLanguage appLanguage;      移动设备 App 系统语言
    E_DjiMobileAppScreenType appScreenType;  移动设备 App 屏幕尺寸类型
} T_DjiMobileAppInfo;
```

### T_DjiAircraftInfoBaseInfo

飞行器系统的基础信息，主要包括系统的一些常数参数信息。

```c
typedef struct {
    E_DjiAircraftSeries aircraftSeries;      飞行器系列
    E_DjiMountPositionType mountPositionType; 安装位置类型
    E_DjiAircraftType aircraftType;          飞行器类型
    E_DjiSdkAdapterType djiAdapterType;      DJI 适配器类型
    E_DjiMountPosition mountPosition;        负载安装位置
} T_DjiAircraftInfoBaseInfo;
```

### T_DjiAircraftVersion

飞行器版本信息。

```c
typedef struct {
    uint8_t debugVersion;     调试版本号
    uint8_t modifyVersion;    修订版本号
    uint8_t minorVersion;     次版本号
    uint8_t majorVersion;     主版本号
} T_DjiAircraftVersion;
```

### E_DjiEnhancedTransmissionState

增强图传状态。

```c
typedef enum {
    DJI_ENHANCEED_TRANSMISSION_STATE_DISABLED = 0,    增强图传已关闭
    DJI_ENHANCEED_TRANSMISSION_STATE_ENABLED  = 3,    增强图传已开启
} E_DjiEnhancedTransmissionState;
```
