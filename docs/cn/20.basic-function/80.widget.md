
## 概述

本文档描述了自定义控件模块头文件`dji_widget.h`中的函数原型和数据类型定义。该模块用于在 DJI Pilot 或基于 MSDK 开发的移动端 App 上显示开发者自定义的控件界面，支持按钮、开关、范围条、列表、输入框等控件类型，以及浮窗消息展示功能。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiWidget_Init

- 功能：初始化自定义控件模块。

::: tip 说明：
使用自定义控件功能时，请先初始化自定义控件模块。
:::

```c
T_DjiReturnCode DjiWidget_Init(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegDefaultUiConfigByDirPath

- 功能：注册自定义控件配置文件默认的路径。

::: tip 说明：
* 仅基于 Linux 开发的负载设备支持使用本接口。
* 在 Linux 操作系统中可使用 DjiWidget_RegDefaultUiConfigByDirPath() 和 DjiWidget_RegUiConfigByDirPath() 函数设置自定义控件配置文件的路径。
* 当不需要自定义控件配置支持多语言和适配不同大小的屏幕时，只需使用接口 DjiWidget_RegDefaultUiConfigByDirPath() 注册控件的配置文件。
* 当需要支持多语言和适配不同大小屏幕时，需使用接口 DjiWidget_RegUiConfigByDirPath() 指定特定语言和屏幕大小下的控件配置；若 App 语言和屏幕大小没有对应的控件配置，则使用 DjiWidget_RegDefaultUiConfigByDirPath() 注册控件的配置文件。
:::

```c
T_DjiReturnCode DjiWidget_RegDefaultUiConfigByDirPath(const char *widgetConfigDirPath);
```

- 参数
  - widgetConfigDirPath：自定义控件配置文件的路径。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegUiConfigByDirPath

- 功能：注册自定义控件配置文件的路径。

::: tip 说明：
* 仅基于 Linux 开发的负载设备支持使用本接口。
* 不同语言和屏幕尺寸下的控件配置需要有相同的控件类型、索引和数量。
:::

```c
T_DjiReturnCode DjiWidget_RegUiConfigByDirPath(E_DjiMobileAppLanguage appLanguage,
                                               E_DjiMobileAppScreenType appScreenType,
                                               const char *widgetConfigDirPath);
```

- 参数
  - appLanguage：基于 MSDK 开发的移动端 App 的语言类型。
  - appScreenType：终端设备的屏幕类型。
  - widgetConfigDirPath：自定义控件配置文件的路径。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegDefaultUiConfigByBinaryArray

- 功能：通过二进制数组控件文件注册默认控件配置。

::: tip 说明：
* 在无文件管理系统的操作系统中（如 RTOS），请调用该接口和 DjiWidget_RegUiConfigByBinaryArray() 接口设置控件配置参数。
* 若没有使用 DjiWidget_RegUiConfigByBinaryArray() 注册与系统语言和屏幕大小对应的控件配置信息时，将使用此函数中的配置信息。
:::

```c
T_DjiReturnCode DjiWidget_RegDefaultUiConfigByBinaryArray(const T_DjiWidgetBinaryArrayConfig *binaryArrayConfig);
```

- 参数
  - binaryArrayConfig：二进制数组控件配置文件。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidget_RegUiConfigByBinaryArray

### DjiWidgetFloatingWindow_ShowMessage

- 功能：向 DJI Pilot 或基于 MSDK 开发的移动端 App 的浮窗发送消息。

::: tip 说明：
* 消息长度不可超过 DJI_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN 中设置的值。
* 向 DJI Pilot 或基于 MSDK 开发的移动端 App 上的浮窗发送消息的最大带宽为 2KB/s。
:::

```c
T_DjiReturnCode DjiWidgetFloatingWindow_ShowMessage(const char *str);
```

- 参数
  - str：指向所需向 DJI Pilot 或基于 MSDK 开发的移动端 App 的浮窗发送的消息。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiWidgetFloatingWindow_GetChannelState

- 参数

  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 宏定义

```c
#define DJI_WIDGET_FLOATING_WINDOW_MSG_MAX_LEN         255
```

## 数据类型定义

### E_DjiWidgetType

控件类型。

```c
typedef enum {
    PSDK_WIDGET_TYPE_BUTTON = 1,        按钮类型
    PSDK_WIDGET_TYPE_SWITCH = 2,        开关类型
    PSDK_WIDGET_TYPE_SCALE = 3,         范围条类型
    PSDK_WIDGET_TYPE_LIST = 4,          列表类型
    PSDK_WIDGET_TYPE_INT_INPUT_BOX = 5, 整型值输入框
} E_DjiWidgetType;
```

### E_DjiWidgetButtonState

按钮控件的状态。

```c
typedef enum {
    PSDK_WIDGET_BUTTON_STATE_PRESS_DOWN = 1,        按下按钮
    PSDK_WIDGET_BUTTON_STATE_RELEASE_UP = 0,        释放按钮
} E_DjiWidgetButtonState;
```

### E_DjiWidgetSwitchState

开关控件的状态。

```c
typedef enum {
    PSDK_WIDGET_SWITCH_STATE_OFF = 0,        关闭开关
    PSDK_WIDGET_SWITCH_STATE_ON = 1          打开开关
} E_DjiWidgetSwitchState;
```

### T_DjiWidgetFileBinaryArray

二进制数组控件文件。

```c
typedef struct {
    char *fileName;                   控件文件的名称
    uint32_t fileSize;                控件文件的大小，单位：字节
    const uint8_t *fileBinaryArray;   控件文件的二进制数组（C 语言）
} T_DjiWidgetFileBinaryArray;
```

### T_DjiWidgetBinaryArrayConfig

自定义控件二进制配置文件。

```c
typedef struct {
    uint16_t binaryArrayCount;                           二进制数组控件文件数量
    T_DjiWidgetFileBinaryArray *fileBinaryArrayList;    二进制数组控件文件列表
} T_DjiWidgetBinaryArrayConfig;
```

### T_DjiWidgetHandlerListItem

- 功能：控件项处理函数集合，包含控件索引、类型以及设置/获取控件值的回调函数。

```c
typedef struct {
    自定义控件项的索引，该索引从0开始编号且不可重复
    uint32_t widgetIndex;

    自定义控件的类型，详情请参见：E_DjiWidgetType
    E_DjiWidgetType widgetType;

    @brief 用于设置自定义控件的值的回调函数，当用户触发控件时将调用该函数
    @param widgetType: 自定义控件的类型，详情请参见：E_DjiWidgetType.
    @param index: 自定义控件的索引
    @param value: 开发者所设置的自定义控件的值。按钮类型控件值的取值范围，请参
    见：E_DjiWidgetButtonState；开关类型控件值的取值范围，请参
    见：E_DjiWidgetSwitchState；范围条类型控件值的取值范围，请参
    见：PSDK_WIDGET_TYPE_SCALE，范围为0～100；列表类型控件值的取值范围为0～N-1；
    输入框类型控件的值为整型
    @param userData: 用户数据指针
    @return 执行结果
    T_PsdkReturnCode (*SetWidgetValue)(E_DjiWidgetType widgetType, uint32_t index, int32_t value, void *userData);

    @brief 获取自定义控件值的回调函数
    @param widgetType: 自定义控件的类型，详情请参见：E_DjiWidgetType.
    @param 自定义控件的索引
    @param value: 开发者所设置的自定义控件的值。按钮类型控件值的取值范围，请参
    见：E_DjiWidgetButtonState；开关类型控件值的取值范围，请参
    见：E_DjiWidgetSwitchState；范围条类型控件值的取值范围，请参
    见：PSDK_WIDGET_TYPE_SCALE，范围为0～100；列表类型控件值的取值范围为0～N-1；
    输入框类型控件的值为整型
    @param userData: 用户数据指针
    @return 执行结果
    T_PsdkReturnCode (*GetWidgetValue)(E_DjiWidgetType widgetType, uint32_t index, int32_t *value, void *userData);

    用户需要在SetWidgetValue 和GetWidgetValue 中使用的用户数据指针;
} T_DjiWidgetHandlerListItem;
```

### E_DjiWidgetTransmitDataEvent

数据传输事件类型。

```c
typedef enum {
    DJI_WIDGET_TRANSMIT_DATA_EVENT_START,       数据传输开始
    DJI_WIDGET_TRANSMIT_DATA_EVENT_TRANSMIT,    数据传输中
    DJI_WIDGET_TRANSMIT_DATA_EVENT_FINISH,      数据传输完成
```

### T_DjiWidgetTransDataContent

数据传输内容。

```c
typedef struct {
    union {
        当事件为 DJI_WIDGET_TRANSMIT_DATA_EVENT_START 时，包含文件名、UUID 和解码比特率
        struct {
            uint8_t fileName[32];            文件名
            uint8_t fileUuid[32];            文件 UUID
            uint32_t fileDecodeBitrate;      文件解码比特率
        } transDataStartContent;

        当事件为 DJI_WIDGET_TRANSMIT_DATA_EVENT_FINISH 时，包含文件 MD5 校验值
        struct {
            uint8_t md5Sum[16];              文件 MD5 校验值
        } transDataEndContent;
    };
} T_DjiWidgetTransDataContent;
```

### T_DjiWidgetSpeakerState

```c
typedef struct {

    E_DjiWidgetSpeakerWorkMode workMode;       喊话器工作模式
    E_DjiWidgetSpeakerPlayMode playMode;       喊话器播放模式
    uint8_t volume;                            音量
} T_DjiWidgetSpeakerState;
```

### T_DjiWidgetSpeakerHandler

- 功能：喊话器功能回调函数集合。

请根据本结构体中的函数构造喊话器相关功能的回调函数，其中包括：
* 获取喊话器状态
* 设置喊话器工作模式
* 设置喊话器播放模式
* 设置音量
* 开始播放
* 停止播放
* 接收 TTS 数据
* 接收语音数据

::: tip 说明：
为防止该函数阻塞 PSDK 的主线程，导致出现程序响应缓慢、负载设备断连及死循环等问题，请勿以阻塞的方式在回调函数中执行该函数。
:::

```c
typedef struct {

    @brief 获取喊话器当前状态的回调函数
    @param speakerState: 指向用于存储喊话器状态的内存空间
    @return 执行结果
    T_DjiReturnCode (*GetSpeakerState)(T_DjiWidgetSpeakerState *speakerState);

    @brief 设置喊话器工作模式的回调函数
    @param workMode: 喊话器工作模式
    @return 执行结果
    T_DjiReturnCode (*SetWorkMode)(E_DjiWidgetSpeakerWorkMode workMode);

    @brief 设置喊话器播放模式的回调函数
    @param playMode: 喊话器播放模式
    @return 执行结果
    T_DjiReturnCode (*SetPlayMode)(E_DjiWidgetSpeakerPlayMode playMode);

    @brief 设置音量的回调函数
    @param volume: 音量
    @return 执行结果
    T_DjiReturnCode (*SetVolume)(uint8_t volume);

    @brief 开始播放的回调函数
    @return 执行结果
    T_DjiReturnCode (*StartPlay)(void);

    @brief 停止播放的回调函数
    @return 执行结果
    T_DjiReturnCode (*StopPlay)(void);

    @brief 接收 TTS 数据的回调函数
    @param event: 数据传输事件类型
    @param offset: 数据偏移量
    @param buf: 数据缓冲区指针
    @param size: 数据大小
    @return 执行结果
    T_DjiReturnCode (*ReceiveTtsData)(E_DjiWidgetTransmitDataEvent event,
                                      uint32_t offset, uint8_t *buf, uint16_t size);

    @brief 接收语音数据的回调函数
    @param event: 数据传输事件类型
    @param offset: 数据偏移量
    @param buf: 数据缓冲区指针
    @param size: 数据大小
    @return 执行结果
    T_DjiReturnCode (*ReceiveVoiceData)(E_DjiWidgetTransmitDataEvent event,
                                        uint32_t offset, uint8_t *buf, uint16_t size);
} T_DjiWidgetSpeakerHandler;
```
