
## 概述

本文档描述了自定义 HMS 功能模块头文件`dji_hms_customization.h`中的函数原型和数据类型定义。该模块用于向 DJI Pilot 或基于 MSDK 开发的移动端 App 上报和清除自定义 HMS 错误码，并支持通过目录路径或二进制数组注册 HMS 文案配置，实现多语言的自定义健康管理信息展示。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiHmsCustomization_Init

- 功能：初始化自定义 HMS 功能模块。

::: tip 说明：
用户在使用自定义 HMS 功能模块之前应调用此函数。
:::

```c
T_DjiReturnCode DjiHmsCustomization_Init(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_DeInit

- 功能：反初始化自定义 HMS 功能模块。

```c
T_DjiReturnCode DjiHmsCustomization_DeInit(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_InjectHmsErrorCode

- 功能：向应用程序上报自定义 HMS 错误码。

::: tip 说明：
* 如需上报相同的 HMS 错误码，仅需调用一次接口，无需重复调用。
* 司空平台暂不支持三方用户自定义 HMS 文案，因此在司空平台上会显示为未知错误。
:::

```c
T_DjiReturnCode DjiHmsCustomization_InjectHmsErrorCode(uint32_t errorCode, E_DjiHmsErrorLevel errorLevel);
```

- 参数
  - errorCode：HMS 错误码，取值范围：[0x1E020005 ~ 0x1E02FFFF]。
  - errorLevel：HMS 错误等级。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_EliminateHmsErrorCode

- 功能：清除应用程序上显示的自定义 HMS 错误码。

::: tip 说明：
如需清除相同的 HMS 错误码，仅需调用一次接口，无需重复调用。
:::

```c
T_DjiReturnCode DjiHmsCustomization_EliminateHmsErrorCode(uint32_t errorCode);
```

- 参数
  - errorCode：HMS 错误码，取值范围：[0x1E020005 ~ 0x1E02FFFF]。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_RegDefaultHmsTextConfigByDirPath

- 功能：注册 HMS 默认文案配置文件的目录路径。

```c
T_DjiReturnCode DjiHmsCustomization_RegDefaultHmsTextConfigByDirPath(const char *configDirPath);
```

- 参数
  - configDirPath：HMS 默认文案配置文件的目录路径。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_RegHmsTextConfigByDirPath

- 功能：注册指定语言的 HMS 文案配置文件的目录路径。

::: tip 说明：
不同语言的 HMS 文案配置需相同。
:::

```c
T_DjiReturnCode DjiHmsCustomization_RegHmsTextConfigByDirPath(E_DjiMobileAppLanguage appLanguage, const char *configDirPath);
```

- 参数
  - appLanguage：移动端 App 的语言类型。
  - configDirPath：HMS 文案配置文件的目录路径。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_RegDefaultHmsTextConfigByBinaryArray

- 功能：使用二进制数组注册默认 HMS 文案配置。

::: tip 说明：
* 在 RTOS 中通常没有文件系统，因此 HMS 文案配置文件内容可使用 C 语言数组来表示。
* 当 DjiHmsCustomization_RegHmsTextConfigByBinaryArray 中的设置未包括某种语言时，HMS 文案配置将沿用此函数的设置。
:::

```c
T_DjiReturnCode DjiHmsCustomization_RegDefaultHmsTextConfigByBinaryArray(const T_DjiHmsBinaryArrayConfig *binaryArrayConfig);
```

- 参数
  - binaryArrayConfig：指向 HMS 文案二进制数组配置的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_RegHmsTextConfigByBinaryArray

- 功能：使用二进制数组注册指定语言的 HMS 文案配置。

::: tip 说明：
不同语言的 HMS 文案配置需相同。
:::

```c
T_DjiReturnCode DjiHmsCustomization_RegHmsTextConfigByBinaryArray(E_DjiMobileAppLanguage appLanguage, const T_DjiHmsBinaryArrayConfig *binaryArrayConfig);
```

- 参数
  - appLanguage：移动端 App 的语言类型。
  - binaryArrayConfig：指向 HMS 文案二进制数组配置的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHmsCustomization_AlarmEnhancedCtrl

- 功能：控制 App 端增强告警。

::: tip 说明：
该接口仅在 DJI Manifold 3 上支持。
:::

```c
T_DjiReturnCode DjiHmsCustomization_AlarmEnhancedCtrl(E_DjiHmsAlarmEnhancedAction action, T_DjiHmsAlarmEnhancedSetting setting);
```

- 参数
  - action：启动或停止告警的动作。
  - setting：告警信息配置。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### E_DjiHmsErrorLevel

HMS 错误等级。

```c
typedef enum {
    DJI_HMS_ERROR_LEVEL_NONE = 0,         无错误
    DJI_HMS_ERROR_LEVEL_HINT,             提示
    DJI_HMS_ERROR_LEVEL_WARN,             警告
    DJI_HMS_ERROR_LEVEL_CRITICAL,         严重
    DJI_HMS_ERROR_LEVEL_FATAL,            致命
} E_DjiHmsErrorLevel;
```

### T_DjiHmsFileBinaryArray

HMS 文案配置文件的二进制数组。

```c
typedef struct {
    char *fileName;                   HMS 文案配置文件名
    uint32_t fileSize;                HMS 文案配置文件的大小，单位：byte
    const uint8_t *fileBinaryArray;   HMS 文案配置文件的 C 语言数组
} T_DjiHmsFileBinaryArray;
```

### T_DjiHmsBinaryArrayConfig

HMS 文案二进制数组配置。

```c
typedef struct {
    uint16_t binaryArrayCount;                    二进制数组的元素计数
    T_DjiHmsFileBinaryArray *fileBinaryArrayList;  指向二进制数组列表的指针
} T_DjiHmsBinaryArrayConfig;
```

### E_DjiHmsAlarmEnhancedType

增强告警类型。

```c
typedef enum {
    DJI_HMS_ALARM_ENHANCED_TYPE_SHAKE_MOTOR = 1,             通过在遥控器上振动电机触发告警，以振动方式提醒用户注意警告或故障
    DJI_HMS_ALARM_ENHANCED_PLAY_SOUND = 2,                   通过播放声音触发告警
    DJI_HMS_ALARM_ENHANCED_PLAY_SOUND_AND_SHAKE_MOTOR = 3,   在 Pilot App 上同时通过声音和振动提醒用户的告警
} E_DjiHmsAlarmEnhancedType;
```

### E_DjiHmsAlarmEnhancedAction

增强告警动作。

```c
typedef enum {
    DJI_HMS_ALARM_ENHANCED_ACTION_STOP = 0,       停止指定的增强告警（振动电机或播放声音）
    DJI_HMS_ALARM_ENHANCED_ACTION_START = 1,      启动指定的增强告警
    DJI_HMS_ALARM_ENHANCED_ACTION_EXIT_ALL = 2,   退出所有增强告警，包括振动电机和播放声音
} E_DjiHmsAlarmEnhancedAction;
```

### T_DjiHmsAlarmEnhancedSetting

增强告警配置。

```c
typedef struct {
    E_DjiHmsAlarmEnhancedType type;    告警类型，用于指定对哪种增强告警执行 ACTION_STOP 或 ACTION_START 操作。执行 EXIT_ALL 时该字段被忽略
    int8_t times;                      指定告警连续激活的次数
    int16_t interval;                  连续激活告警之间的间隔时间，单位：毫秒
} T_DjiHmsAlarmEnhancedSetting;
```
