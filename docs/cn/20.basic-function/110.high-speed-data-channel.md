
## 概述

本文档描述了高速数据通道模块头文件`dji_high_speed_data_channel.h`中的函数原型和数据类型定义。该模块用于通过网络通道在负载设备与移动端之间进行高速数据传输，支持数据流、视频流和下载流的带宽比例配置，以及数据流的发送和状态查询。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiHighSpeedDataChannel_SetBandwidthProportion

- 功能：设置高速通道的数据流、视频流与下载流的带宽比例。

::: tip 说明：
* 自定义带宽分配机制允许用户自由控制带宽限制。系统将高速通道的总带宽限制乘以相应流的比例以获取特定流的实时带宽限制。
* 如果用户不对每一个流进行带宽比例设置，默认的比例为 33%（数据流）、33%（视频流）和 34%（下载流）。
* 带宽比例会在一段时间后生效，最大时限为 1s。如果用户想使用这个接口，需要先调用 PsdkPlatform_RegHalNetworkHandler() 接口，否则接口将不工作。
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_SetBandwidthProportion(
    T_DjiDataChannelBandwidthProportionOfHighspeedChannel bandwidthProportion);
```

- 参数
  - bandwidthProportion：高速通道的每个流的带宽比例，带宽比例的总和必须为 100。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_GetDataStreamRemoteAddress

- 功能：获取发送数据流的网络远程地址。

::: tip 说明：
* 用户可以获取该信息以便在异构系统中通过其他子系统执行某些操作。
* 本接口应在调用 PsdkCore_Init 之后使用。
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_GetDataStreamRemoteAddress(char *ipAddr, uint16_t *port);
```

- 参数
  - ipAddr：发送数据流的远程 IP 地址。
  - port：发送数据流的远程端口。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_SendDataStreamData

- 功能：通过数据通道的数据流发送数据到移动端。

::: tip 说明：
* 该功能仅在 Linux 操作系统中可用。
* 必须确保实际带宽小于通道或流的带宽限制。用户可以通过 DjiHighSpeedDataChannel_GetDataStreamState() 函数获取 dataStream 通道的状态。如果实际带宽超过限制或设置繁忙状态，用户应停止传输数据或减少数据量，否则数据会被丢弃。
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_SendDataStreamData(const uint8_t *data, uint16_t len);
```

- 参数
  - data：指向要发送数据的指针。
  - len：通过数据流发送数据的长度，必须小于等于 65000，单位：byte。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiHighSpeedDataChannel_GetDataStreamState

- 功能：获取 dataStream 通道的数据传输状态。

::: tip 说明：
* 用户可以使用该状态作为控制数据流数据传输的基础。
* 该功能仅在 Linux 操作系统中可用。
:::

```c
T_DjiReturnCode DjiHighSpeedDataChannel_GetDataStreamState(T_DjiDataChannelState *state);
```

- 参数
  - state：指向 dataStream 通道状态的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### T_DjiDataChannelBandwidthProportionOfHighspeedChannel

高速数据通道带宽比例。

```c
typedef struct {
    uint8_t dataStream;       数据流的带宽比例，范围 0～100
    uint8_t videoStream;      视频流的带宽比例，范围 0～100
    uint8_t downloadStream;   下载流的带宽比例，范围 0～100
} T_DjiDataChannelBandwidthProportionOfHighspeedChannel;
```
