
## 概述

本文档描述了本地升级模块头文件`dji_upgrade.h`中的函数原型和数据类型定义。该模块用于实现负载设备的固件升级功能，开发者可以通过该模块配置固件传输方式、注册升级处理函数、推送升级状态等，使负载设备支持通过 DJI Assistant 2 进行固件升级。

::: tip 说明：
- 仅使用 X-Port 开发的负载设备可使用`dji_upgrade.h`，若使用 SkyPort 开发负载设备，请使用 <a href="./gimbal.html">dji_gimbal.h</a>。
- 各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiUpgrade_Init

- 功能：升级模块初始化，用户在使用升级功能前应调用该函数。

```c
T_DjiReturnCode DjiUpgrade_Init(const T_DjiUpgradeConfig *upgradeConfig);
```

- 参数
  - upgradeConfig：指向升级配置结构体的指针，包含当前固件版本和固件传输信息。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_EnableLocalUpgrade

- 功能：启动本地升级模式，开启后 DJI Assistant 2 将显示负载升级界面，用户可以选择固件文件来升级负载设备。

```c
T_DjiReturnCode DjiUpgrade_EnableLocalUpgrade(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_RegHandler

- 功能：注册升级过程的处理函数。

```c
T_DjiReturnCode DjiUpgrade_RegHandler(const T_DjiUpgradeHandler *upgradeHandler);
```

- 参数
  - upgradeHandler：指向升级过程的处理函数结构体的指针。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

### DjiUpgrade_PushUpgradeState

- 功能：向终端 App 推送升级状态。

```c
T_DjiReturnCode DjiUpgrade_PushUpgradeState(const T_DjiUpgradeState *upgradeState);
```

- 参数
  - upgradeState：指向升级状态结构体的指针，包含升级过程中的状态信息。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>

## 数据类型定义

### E_DjiFirmwareTransferType

固件传输类型。

```c
typedef enum {  
    DJI_FIRMWARE_TRANSFER_TYPE_FTP = 0,  FTP 固件传输类型
    DJI_FIRMWARE_TRANSFER_TYPE_DCFTP,  DCFTP 固件传输类型
} E_DjiFirmwareTransferType;
```

### E_DjiUpgradeStage

升级阶段。

```c
typedef enum {
    DJI_UPGRADE_STAGE_IDLE = 0,  空闲阶段，表示当前不处于升级模式
    DJI_UPGRADE_STAGE_ONGOING = 3,  升级进行中阶段，表示负载设备正在升级
    DJI_UPGRADE_STAGE_DEVICE_REBOOT = 6,  设备重启阶段，表示设备正在重启
    DJI_UPGRADE_STAGE_END = 4,  升级结束阶段，表示升级完成并向终端 App 报告升级结果
} E_DjiUpgradeStage;
```

### E_DjiUpgradeEndState

升级结束状态。

```c
typedef enum {
    DJI_UPGRADE_END_STATE_SUCCESS = 1,  升级成功
    DJI_UPGRADE_END_STATE_UNKNOWN_ERROR = 2,  升级失败
} E_DjiUpgradeEndState;
```

### T_DjiFirmwareVersion

固件版本信息。该类型定义在 `dji_typedef.h` 中，详情请参见：<a href="../system-base/dji-typedef.html#t-djifirmwareversion">T_DjiFirmwareVersion</a>

### T_DjiUpgradeOngoingInfo

升级进行中的状态信息。

```c
typedef struct {
    uint8_t upgradeProgress;  升级进度，范围为 0 ~ 100
} T_DjiUpgradeOngoingInfo;
```

### T_DjiUpgradeRebootInfo

升级过程中设备重启信息。

```c
typedef struct {
    uint8_t rebootTimeout;  重启设备的超时时间，单位：s
} T_DjiUpgradeRebootInfo;
```

### T_DjiUpgradeEndInfo

升级结束信息。

```c
typedef struct {
    E_DjiUpgradeEndState upgradeEndState;  升级结束状态
} T_DjiUpgradeEndInfo;
```

### T_DjiUpgradeFtpFileTransferInfo

FTP 文件传输信息。

```c
typedef struct {
    uint32_t port;  FTP 端口号，用于传输文件，默认为 21
} T_DjiUpgradeFtpFileTransferInfo;
```

### T_DjiUpgradeFileInfo

升级文件信息。

```c
typedef struct {
    uint32_t fileSize;  文件大小
    char fileName[DJI_FILE_NAME_SIZE_MAX];  文件名
} T_DjiUpgradeFileInfo;
```

### T_DjiUpgradeDcftpFileTransferOpt

- 功能：DCFTP 文件传输操作回调函数集合。

请根据本结构体中的函数构造 DCFTP 文件传输相关功能的回调函数，其中包括：
* 开始文件传输
* 传输文件数据
* 完成文件传输

::: tip 说明：
为防止该函数阻塞 PSDK 的主线程，导致出现程序响应缓慢、相机类负载设备断连及死循环等问题，请勿以阻塞的方式在回调函数中执行该函数。
:::

```c
typedef struct {
    @brief 开始文件传输的回调函数
    @param fileInfo: 待传输文件的信息
    @return 执行结果
    T_DjiReturnCode (*start)(const T_DjiUpgradeFileInfo *fileInfo);

    @brief 传输文件数据的回调函数
    @details 在开始传输后，该回调函数将被多次调用以顺序传输文件数据
    @param data: 指向用于存储文件数据的内存空间
    @param dataLen: 数据长度
    @return 执行结果
    T_DjiReturnCode (*transfer)(const uint8_t *data, uint16_t dataLen);

    @brief 完成文件传输的回调函数
    @param md5: 文件的 MD5 值，用于校验文件传输的正确性
    @return 执行结果
    T_DjiReturnCode (*finish)(const uint8_t md5[DJI_MD5_BUFFER_LEN]);
} T_DjiUpgradeDcftpFileTransferOpt;
```

### T_DjiFirmwareTransferInfo

固件传输信息。

```c
typedef struct {
    E_DjiFirmwareTransferType transferType;  固件传输类型

    T_DjiUpgradeFtpFileTransferInfo ftpTransferInfo;  当 transferType 为 DJI_FIRMWARE_TRANSFER_TYPE_FTP 时，需提供 FTP 传输信息
    T_DjiUpgradeDcftpFileTransferOpt dcftpFileTransferOpt;  当 transferType 为 DJI_FIRMWARE_TRANSFER_TYPE_DCFTP 时，需提供 DCFTP 文件传输操作
} T_DjiFirmwareTransferInfo;
```

### T_DjiUpgradeState

升级状态信息。

```c
typedef struct {
    E_DjiUpgradeStage upgradeStage;  升级过程中的升级阶段

    union {
        T_DjiUpgradeOngoingInfo upgradeOngoingInfo;  当 upgradeStage 为 DJI_UPGRADE_STAGE_ONGOING 时，需提供升级进行中信息
        T_DjiUpgradeRebootInfo upgradeRebootInfo;  当 upgradeStage 为 DJI_UPGRADE_STAGE_DEVICE_REBOOT 时，需提供设备重启信息
        T_DjiUpgradeEndInfo upgradeEndInfo;  当 upgradeStage 为 DJI_UPGRADE_STAGE_END 时，需提供升级结束信息
    };
} T_DjiUpgradeState;
```

### T_DjiUpgradeConfig

升级配置信息。

```c
typedef struct {
    T_DjiFirmwareVersion currentFirmwareVersion;  负载设备当前的固件版本
    T_DjiFirmwareTransferInfo firmwareTransferInfo;  负载设备的固件传输信息
} T_DjiUpgradeConfig;
```

### T_DjiUpgradeHandler

- 功能：升级处理回调函数集合。

请根据本结构体中的函数构造升级处理相关功能的回调函数，其中包括：
* 进入升级模式
* 校验已传输的固件
* 开始固件升级
* 完成固件升级

::: tip 说明：
为防止该函数阻塞 PSDK 的主线程，导致出现程序响应缓慢、相机类负载设备断连及死循环等问题，请勿以阻塞的方式在回调函数中执行该函数。
:::

```c
typedef struct {
    @brief 进入升级模式的回调函数
    @param waitTime: 进入升级模式的等待时间。终端 App 将在此时间内等待，之后再执行后续升级操作。可利用该时间在其他任务中为固件升级做准备，如清除固件存储区域。单位：s
    @return 执行结果
    T_DjiReturnCode (*EnterUpgradeMode)(uint16_t *waitTime);

    @brief 校验已传输固件的回调函数
    @details 可在该回调函数中进行固件签名验证和固件解密
    @return 执行结果
    T_DjiReturnCode (*CheckFirmware)(void);

    @brief 开始固件升级的回调函数
    @note 开始升级后，升级阶段需切换为 DJI_UPGRADE_STAGE_ONGOING
    @return 执行结果
    T_DjiReturnCode (*StartUpgrade)(void);

    @brief 完成固件升级的回调函数
    @note 调用完成升级后，升级阶段需从 DJI_UPGRADE_STAGE_END 切换为 DJI_UPGRADE_STAGE_IDLE
    @return 执行结果
    T_DjiReturnCode (*FinishUpgrade)(void);
} T_DjiUpgradeHandler;
```
