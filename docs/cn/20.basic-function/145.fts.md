
## 概述

本文档描述了紧急降落功能（FTS）模块头文件`dji_fts.h`中的函数原型和数据类型定义。该模块用于选择和管理飞行器的 FTS PWM 触发端口，开发者可以在地面状态下启用指定的 PWM 触发端口，并通过外部 PWM 硬件发送停机信号实现紧急降落。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiFts_SelectFtsPwmTrigger

- 功能：选择 FTS PWM 触发端口。
- 支持的机型：M400 系列（仅支持 DJI_MOUNT_POSITION_EXTENSION_PORT_V2_NO4）

::: tip 说明：
* 该接口必须在飞行器处于地面状态时调用，飞行中调用将失败或被拒绝。
* 该接口仅在飞控侧选择/启用 PWM 触发端口，不会发射 PWM 信号或执行停机动作。实际停机需要通过外部 PWM 控制器向该端口发送 PWM 信号。
* 推荐流程：1）在地面调用 DjiFts_SelectFtsPwmTrigger(position) 启用端口；2）通过外部 PWM 控制器向该端口发送停机 PWM 信号。
:::

```c
T_DjiReturnCode DjiFts_SelectFtsPwmTrigger(E_DjiMountPosition position);
```

- 参数
  - position：负载安装位置。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiFts_GetFtsPwmTriggerStatus

- 功能：获取 FTS PWM 触发状态。
- 支持的机型：M4 系列

::: tip 说明：
* 该接口已弃用，将在未来版本中移除，不建议使用。
* 推荐替代方案：使用 DJI_FC_SUBSCRIPTION_TOPIC_ESC_DATA 数据订阅来确认停机（FTS）效果。
:::

```c
T_DjiReturnCode DjiFts_GetFtsPwmTriggerStatus(T_DjiFtsPwmEscTriggerStatus *trigger_status);
```

- 参数
  - trigger_status：指向用于存储 FTS PWM ESC 触发状态的内存空间。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### E_DjiFtsStatus

FTS 触发状态。

```c
typedef enum {
    DJI_FTS_NOT_TRIGGERD = 0,    未触发
    DJI_FTS_TRIGGERD = 1,        已触发
} E_DjiFtsStatus;
```

### T_DjiFtsPwmTriggerStatus

FTS PWM 触发状态。

```c
typedef struct {
    E_DjiMountPosition fts_select;    FTS 选择的安装位置
    E_DjiFtsStatus fts_status;        FTS 触发状态
    uint8_t fts_pwm_cnt;              已接收的正确 PWM 信号数量
} T_DjiFtsPwmTriggerStatus;
```

### T_DjiFtsPwmEscTriggerStatus

FTS PWM ESC 触发状态。

```c
typedef struct {
    T_DjiFtsPwmTriggerStatus ESC[4];    4 个 ESC 的触发状态
} T_DjiFtsPwmEscTriggerStatus;
```
