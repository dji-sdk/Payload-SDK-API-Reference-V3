
## 概述

本文档描述了系留电池模块头文件`dji_tethered_battery.h`中的函数原型和数据类型定义。该模块用于向 DJI Pilot 2 推送系留线缆的实时长度信息，使飞行员能够在移动端界面上查看系留线缆的使用状态。

::: tip 支持的机型说明
各机型对功能模块的支持范围请参见 [开放功能列表](https://developer.dji.com/doc/payload-sdk-tutorial/cn/development-preparation/development-platform-overview/open-capability-list.html) 机型矩阵表。
:::

## 函数原型

### DjiTetheredBattery_Init

- 功能：初始化系留电池模块。

::: tip 说明：
用户在使用系留电池功能前应调用该函数。
:::

```c
T_DjiReturnCode DjiTetheredBattery_Init(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiTetheredBattery_DeInit

- 功能：反初始化系留电池模块。

```c
T_DjiReturnCode DjiTetheredBattery_DeInit(void);
```

- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


### DjiTetheredBattery_PushTetherLineStatus

- 功能：向 DJI Pilot 2 推送实时系留线缆长度信息。

::: tip 说明：
* 建议推送频率不超过数据更新频率。
* 最大推送频率不应超过 10Hz。
:::

```c
T_DjiReturnCode DjiTetheredBattery_PushTetherLineStatus(T_DjiTetherLineStatus tetherLineStatus);
```

- 参数
  - tetherLineStatus：系留线缆状态。
- 返回值
  - 根据程序执行的情况输出对应的返回值，详情请参见：<a href="../system-base/dji-error.html">DjiErrorCode</a>


## 数据类型定义

### T_DjiTetherLineStatus

系留线缆状态。

```c
typedef struct {
    dji_f32_t totalLength;    系留线缆总长度，范围：0～300，单位：米
    dji_f32_t usedLength;     已使用的系留线缆长度，范围：0～300，单位：米。该值必须小于等于线缆总长度
} T_DjiTetherLineStatus;
```
